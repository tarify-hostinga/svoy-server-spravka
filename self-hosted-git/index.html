Self hosted Git: свой сервер для репозиториев, коротко и с данными

Конспект страницы: 6 разделов коротко, данные на 14 октября 2026 и ответы на 3 вопроса. Полный разбор с примерами: Self hosted Git: свой сервер для репозиториев.

Коротко

Главная / Self-hosted / Self hosted Git Self hosted Git это сервер для репозиториев кода на вашей машине: веб-интерфейс, запросы на слияние, задачи и сборки без облачного GitHub или GitLab.com. Выбор сводится к двум полюсам: тяжёлый GitLab CE со всем DevOps внутри или лёгкие Gitea и Forgejo, которым хватает младшего VPS. Для команды до 20 человек хватит Gitea или Forgejo на младшем сервере.

Конспект по разделам

Self hosted Git: сравнение пяти серверов

Gitea, Forgejo и Gogs умеют работать на SQLite, поэтому их можно запустить одним контейнером и подключить PostgreSQL позже. GitLab сразу тянет за собой PostgreSQL, Redis и несколько фоновых сервисов, зато ставится одним пакетом Omnibus или образом Docker. Все пять бесплатны.

Какой self hosted Git выбрать для команды

Два ответа: размер команды и нужны ли сборки Перенос с GitHub или GitLab.com у Gitea и GitLab встроенный: мастер миграции забирает репозитории вместе с задачами и запросами на слияние, если указать токен доступа к старому аккаунту.

Self hosted GitLab: сколько ресурсов и когда он оправдан

Документация GitLab называет базой для установки на одном сервере 8 vCPU. В условиях нехватки памяти GitLab запускается и на 8 ГБ, но разработчики советуют отключить подкачку или дать столько памяти, чтобы до неё не доходило: под нагрузкой своп резко замедляет работу. Такой сервер окупается, когда команда пользуется GitLab целиком: задачи, ревью, пайплайны, реестр образов, окружения.

Self hosted GitHub и раннеры CI на своём сервере

Сам GitHub на свой сервер не поставить: для этого есть только коммерческий GitHub Enterprise Server. Зато у GitHub Actions есть self-hosted runner, программа, которая забирает задания из ваших репозиториев и выполняет их на вашей машине. Так сборки получают доступ к внутренним серверам и нужному железу, а минуты Actions не тратятся.

  • GitHub советует подключать свои раннеры только к приватным репозиториям: в публичном чужой запрос на слияние может выполнить код на вашем сервере.
  • Для GitLab тот же механизм называется GitLab Runner, у Gitea это act_runner.
  • Раннер удобно запускать в Docker, чтобы каждая сборка шла в чистом контейнере и не оставляла мусор на хосте.

Запуск self hosted Git: SSH, домен и резервные копии

Git-серверу нужны два входа: HTTPS для веб-интерфейса и SSH для git push. Порт 22 обычно занят SSH самого сервера, поэтому Gitea и Forgejo в Docker часто вешают на 2222 или пробрасывают SSH через хост. Веб-часть закройте обратным прокси с сертификатом, например Caddy.

Вопросы и ответы

Можно ли установить GitHub на свой сервер?

Только коммерческую версию GitHub Enterprise Server. Бесплатно у себя запускают раннеры GitHub Actions, а сам Git-сервер заменяют на Gitea, Forgejo или GitLab CE.

Сколько памяти нужно self hosted GitLab?

Документация называет минимумом для экономного режима 8 ГБ, базой для одного сервера 8 vCPU. Подкачку разработчики советуют отключать.

Чем Forgejo отличается от Gitea?

Forgejo это ответвление Gitea, которое развивает сообщество вокруг Codeberg, с лицензией GPL-3.0. Интерфейс и настройки у них очень похожи, Gitea остаётся под MIT.
