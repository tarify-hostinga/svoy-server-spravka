Коротко

Главная / Разработка / Directus Установка Directus на своём сервере сводится к одному контейнеру directus/directus, который слушает порт 8055, и базе данных рядом. Directus подключается к обычной SQL-базе и сразу даёт веб-панель для редакторов, REST и GraphQL для приложений. Он заменяет самодельную админку над таблицами и годится как headless CMS.

Конспект по разделам

Что заменяет Directus и кому он нужен

Directus это слой над SQL-базой. Вы описываете таблицы (или подключаете уже существующие), а он строит вокруг них панель управления, систему ролей и программный интерфейс. Контент можно править в панели, а сайт или приложение читают его по REST и GraphQL.

  • Самодельная админка.
  • Headless CMS, то есть система, которая хранит контент и отдаёт его, а выводом занимается отдельный сайт.
  • Простой бэкенд.

Сколько памяти и какая база нужны Directus

Directus работает с PostgreSQL, MySQL, MariaDB и SQLite, есть и коммерческие базы вроде MS SQL. На странице развёртывания жёстких минимумов по железу нет, поэтому ориентиры ниже редакционные, из практики небольших проектов. SQLite лежит в файле внутри контейнера и подходит, чтобы посмотреть панель за вечер.

Установка Directus: compose с PostgreSQL

Вам понадобится сервер с Docker и Docker Compose. В документации образ называется directus/directus на Docker Hub, а для рабочих проектов советуют указывать конкретный тег версии вместо latest, чтобы обновления не приходили сами. Тег 11.1.1 взят из примера в документации.

  • Сгенерируйте секрет командой openssl rand -base64 32 и придумайте пароль базы.
  • Создайте compose-файл и подставьте актуальный тег образа со страницы Directus на Docker Hub.
  • Запустите командой docker compose up -d и откройте порт 8055: при первом входе панель предложит создать администратора.

Домен и HTTPS для Directus: адрес и CORS

Панель управления и API Directus отвечают на одном адресе. Поэтому в compose порт привязан к 127.0.0.1, а наружу сервис выставляет обратный прокси, то есть программа, которая принимает HTTPS и передаёт запросы контейнеру. Для двух строк конфигурации подойдёт Caddy, настроенный на cms.example.com, либо Nginx с сертификатом.

Файлы Directus, S3 и копии: что сохранять

Всё состояние Directus лежит в трёх местах: база, каталог /directus/uploads и расширения. Копировать нужно как минимум базу ( pg_dump ) и том с загрузками. Схему можно выгружать отдельно через снимок схемы, это удобно для переноса на другой стенд.

Вопросы и ответы

Какой порт использует Directus при установке в Docker?

Контейнер directus/directus слушает порт 8055. В примере порт привязан к 127.0.0.1, а наружу сервис публикует прокси с HTTPS.

Нужна ли отдельная база для Directus на VPS?

Для пробы хватит SQLite в файле, но рабочий проект лучше держать на PostgreSQL или MySQL. Базу можно взять управляемую у провайдера.

Где в Directus хранятся загруженные файлы на своём сервере?

По умолчанию в томе /directus/uploads внутри контейнера, его нужно подключить к диску сервера. Для большой библиотеки переключите хранилище на S3.
