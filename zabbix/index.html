Установка Zabbix на свой сервер: коротко и с данными

Конспект страницы: 7 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Установка Zabbix на свой сервер.

Коротко

Установка Zabbix состоит из трёх частей: сервер с базой данных, веб-интерфейс и агенты на наблюдаемых машинах. Сервер слушает порт 10051, агент отвечает на 10050, а проще всего собрать сервер, базу и интерфейс одним compose-файлом. Для первых двадцати хостов хватит 1 ядра и 2 ГБ памяти вместе с PostgreSQL в Docker.

Конспект по разделам

Из чего состоит Zabbix и что ставить на сервер

Базой может быть PostgreSQL (в том числе с расширением TimescaleDB), MySQL или MariaDB. Ниже взят PostgreSQL: его же можно позже перенести на управляемую базу (у Таймвеб Клауд такие стартуют от 790 ₽ в месяц на 14 октября 2026), см. установку PostgreSQL. Графики из Zabbix можно вывести и в Grafana.

Сколько памяти и диска нужно Zabbix

Документация Zabbix не называет жёсткого минимума памяти и советует закладывать диск как минимум на пару гигабайт под историю. Практичнее считать от числа показателей, то есть отдельных измеряемых значений вроде загрузки процессора. Формула без сюрпризов: значений в сутки равно числу показателей, умноженному на 86 400 и делённому на интервал опроса в секундах.

Установка Zabbix через Docker Compose с PostgreSQL

  • Поставьте Docker и создайте каталог zabbix с файлом.env, в котором одна строка: ZBX_DB_PASSWORD=длинный_пароль.
  • Выберите ветку.
  • Сохраните compose-файл, выполните docker compose up -d и подождите минуту: сервер создаёт таблицы при первом запуске.
  • Откройте интерфейс по SSH-туннелю на порт 8080 и войдите как Admin с паролем zabbix.

Установка Zabbix agent на наблюдаемые серверы

На каждую машину ставится пакет zabbix-agent2 из репозитория Zabbix. В файле /etc/zabbix/zabbix_agent2.conf заполняют три параметра: Server (адрес Zabbix server для пассивных проверок), ServerActive (куда агент сам шлёт данные) и Hostname (имя, совпадающее с именем хоста в интерфейсе). Затем в интерфейсе создайте хост и привяжите шаблон Linux by Zabbix agent.

HTTPS для интерфейса Zabbix и порты наружу

Веб-интерфейс в примере привязан к 127.0.0.1:8080, поэтому наружу его выводят через Caddy строкой reverse_proxy 127.0.0.1:8080 для своего домена. Порт 10051 приходится открывать, но лучше только для адресов ваших агентов. Правило ufw здесь не сработает: Docker публикует порты в обход ufw.

Очистка истории и копии базы Zabbix

Срок хранения задают в разделе Administration, Housekeeping: отдельно для сырой истории и для трендов, то есть почасовых минимумов, средних и максимумов. История занимает основной объём, тренды дешевы и позволяют смотреть графики за годы. Копировать всю базу целиком дорого.

Установите приложение без консоли

Маркетплейс ставит готовый образ на новый сервер: Docker, GitLab, Nextcloud, n8n и другие.

Вопросы и ответы

Как развернуть Zabbix на сервере с нуля?

Поставить Docker, сохранить compose-файл с PostgreSQL, сервером и веб-интерфейсом, запустить его и войти в интерфейс. Затем на наблюдаемые машины ставится zabbix-agent2.

Какой пароль по умолчанию у Zabbix после установки?

Логин Admin с паролем zabbix. Его меняют при первом входе, потому что пара указана в документации и известна ботам.

В чём разница между Zabbix и Prometheus с Grafana?

Zabbix приносит агентов, шаблоны, триггеры и уведомления в одном пакете. Prometheus с Grafana собирается из частей и ближе к контейнерам и коду приложений.

Какие порты нужно открыть для Zabbix?

На сервере 10051 для агентов и 443 для интерфейса через прокси. На агентах 10050, но только для адреса сервера.
