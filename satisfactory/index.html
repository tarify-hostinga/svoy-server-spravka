Свой сервер для Satisfactory: коротко и с данными

Конспект страницы: 6 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Свой сервер для Satisfactory.

Коротко

Сервер для Satisfactory Coffee Stain выпускает для 64-битных Windows и Linux: SteamCMD скачивает его под app 1690800 без входа в Steam. Настраивается он не файлами, а прямо из игры через Server Manager, и с версии 1.1 ему нужны два порта. Для четырёх человек и новой игры берите 4 ядра и 8 ГБ, большая фабрика или компания побольше просит 16 ГБ.

Конспект по разделам

Сколько памяти и ядер нужно серверу Satisfactory

По той же вики сервер использует несколько ядер, но сильно зависит от скорости одного. На поздних фазах фабрика из тысяч конвейеров и поездов нагружает его заметно сильнее, чем стартовая площадка, поэтому запас по памяти закладывайте сразу. Установка сервера Satisfactory на Ubuntu через SteamCMD

Сервер стартует пустым и ждёт, пока его захватит первый администратор. Запускайте его службой systemd, чтобы фабрика поднималась после перезагрузки, общая схема есть в разделе об игровых серверах. Для Docker популярен образ сообщества wolveix/satisfactory-server: том с сохранениями выносите наружу.

Как захватить сервер Satisfactory и задать пароли

Пароль администратора храните отдельно: с ним любой может удалить сохранение или сменить настройки прямо из игры.

  • Откройте Server Manager в главном меню игры и добавьте сервер по IP.
  • Захватите сервер: вики прямо пишет, что до этого он не начнёт игру.
  • Задайте пароль игроков в том же интерфейсе, если сервер не для всех.
  • Создайте новую игру или загрузите сохранение, после чего друзья добавляют сервер у себя тем же способом.

Порты сервера Satisfactory: 7777 по TCP и UDP и 8888

API на 7777 появились с выходом 1.0, второй порт добавил патч 1.1.0.0. Старые инструкции, где открыт один UDP-порт, к нынешним версиям не подходят.

Где сервер Satisfactory хранит фабрику и как быть с модами

На Linux сохранения лежат в ~/.config/Epic/FactoryGame/Saved/SaveGames/server, там же автосохранения. Копируйте папку перед каждым обновлением игры: откатить фабрику на сотни часов к прошлой версии без копии не получится. Архивы держите вне VPS, порядок разобран на странице о бэкапах.

Вопросы и ответы

Сколько стоит сервер Satisfactory в месяц?

На 14 октября 2026 конфигурация с 4 ядрами и 8 ГБ стоит 10 120 ₽ в месяц, с 8 ядрами и 16 ГБ для большой фабрики стоит 20 040 ₽. Оплата почасовая.

Как перенести сохранение Satisfactory с компьютера на сервер?

Server Manager умеет загрузить сохранение на сервер прямо из игры. Второй путь: скопировать файл.sav в папку SaveGames/server на VPS и выбрать его в менеджере.

Почему не подключиться к серверу Satisfactory после обновления?

С патча 1.1 серверу нужен ещё TCP-порт 8888 помимо 7777 по TCP и UDP. Если в фаерволе открыт только старый набор портов, подключение не проходит.

Сколько игроков выдержит сервер Satisfactory?

Вики описывает требования для четырёх игроков, а для компании больше советует 16 ГБ памяти. Больше всего на нагрузку влияет не число игроков, а размер фабрики.
