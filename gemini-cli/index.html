Установка Gemini CLI на свой сервер: коротко и с данными

Конспект страницы: 6 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Установка Gemini CLI на свой сервер.

Коротко

Установка Gemini CLI на сервер сводится к пакету npm и Node.js 20 или новее. На удалённой машине удобнее входить по ключу GEMINI_API_KEY: вход через аккаунт Google ждёт браузер на той же машине, где работает терминал. Для коротких задач хватит 2 ядер и 4 ГБ памяти, для долгих сессий на большом коде Google советует 16 ГБ.

Конспект по разделам

Gemini CLI на удалённом сервере: что получится

Gemini CLI: открытый агент Google для терминала. Он отвечает на вопросы по коду, правит файлы, запускает команды и работает с моделями Gemini. Его можно запустить и без установки через npx, но на сервере удобнее глобальная установка.

Какой сервер нужен для Gemini CLI

Разница в памяти объясняется контекстом: чем больше файлов агент держит в работе, тем больше расходует процесс Node.js. Если вы открываете монорепозиторий на сотни тысяч строк, сразу закладывайте старшую конфигурацию. Отметьте, как вы будете работать, и получите конфигурацию

Установка Gemini CLI на Ubuntu через npm

Обновление: npm install -g @google/gemini-cli@latest. Кроме стабильной ветки есть @preview и @nightly, на рабочем сервере их лучше не ставить.

  • Поставьте Node.js 20 или новее.
  • Поставьте пакет глобально командой ниже.
  • Положите ключ API в файл ~/.gemini/.env.
  • Запустите gemini в каталоге проекта.

Как Gemini CLI входит в аккаунт без браузера

У Gemini CLI три способа входа: В режиме без интерфейса Gemini CLI берёт сохранённый вход, а если его нет, читает переменные окружения. Поэтому ключ в ~/.gemini/.env работает и в скриптах, и в cron. Gemini API работает только в доступных регионах из списка Google, России в нём на 14 октября 2026 нет.

  • Аккаунт Google.
  • Ключ Gemini API из AI Studio в переменной GEMINI_API_KEY.
  • Vertex AI через GOOGLE_API_KEY и GOOGLE_GENAI_USE_VERTEXAI=true: для команд с проектом в Google Cloud.

Песочница и долгие сессии Gemini CLI

Флаг --sandbox запускает команды агента в контейнере Docker или Podman, Google публикует готовый образ песочницы. Это полезно, если вы даёте агенту запускать установку пакетов и скрипты из интернета. Чтобы задача не прервалась при обрыве SSH, откройте окно в tmux ( tmux new -s gemini ), запустите агента и отцепитесь сочетанием Ctrl+B, D.

Вопросы и ответы

Какая версия Node.js нужна для Gemini CLI?

Node.js 20.0.0 или новее. Проверьте командой node -v до установки пакета @google/gemini-cli.

Как войти в Gemini CLI на сервере без браузера?

Задайте переменную GEMINI_API_KEY, удобнее всего в файле ~/.gemini/.env. В режиме без интерфейса агент берёт ключ из окружения.

Как установить Gemini CLI на Windows?

Той же командой npm при Node.js 20 или новее, Google рекомендует Windows 11 24H2 и новее. Для удалённой работы агента всё равно удобнее Linux-сервер.

Сколько памяти нужно Gemini CLI на VPS?

По рекомендации Google от 4 ГБ для коротких задач и от 16 ГБ для долгих сессий на больших кодовых базах.
