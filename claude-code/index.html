Установка Claude Code на свой сервер: коротко и с данными

Конспект страницы: 6 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Установка Claude Code на свой сервер.

Коротко

Установка Claude Code на сервер занимает одну команду: официальный скрипт кладёт в систему готовую программу, Node.js для неё не нужен. Дальше агент живёт в терминале по SSH, а сессия в tmux продолжает работу, даже когда вы закрыли ноутбук. Для одного проекта на Python или Node.js хватит 2 ядер и 4 ГБ памяти.

Конспект по разделам

Зачем запускать Claude Code на удалённом сервере

Claude Code: агент Anthropic для программирования, который читает репозиторий, правит файлы и сам запускает команды в терминале. Ему нужна машина, где можно ставить зависимости, гонять тесты и собирать проект. Ноутбук для этого подходит плохо по трём причинам.

Сколько памяти и какая система нужны Claude Code

Четыре гигабайта нужны самому агенту. Сборка фронтенда, компилятор или база для тестов добавляют своё, поэтому считайте память по проекту, а не по агенту. Ответьте про проект, и калькулятор подберёт готовую конфигурацию

Установка Claude Code на Ubuntu по шагам

Через npm тоже можно: npm install -g @anthropic-ai/claude-code, нужен Node.js 22 или новее. Документация отдельно просит не запускать эту команду через sudo: это ведёт к ошибкам прав и рискам безопасности. Обновление вручную: claude update.

  • Создайте обычного пользователя и работайте под ним, а не под root: агент запускает команды с вашими правами.
  • Поставьте Claude Code официальным скриптом (команда ниже).
  • Проверьте установку: claude --version печатает номер версии, claude doctor показывает состояние установки и ошибки настроек.
  • Откройте каталог проекта и запустите claude.

Как Claude Code входит в аккаунт на сервере без браузера

При первом запуске Claude Code предлагает войти через браузер. На сервере браузера нет, поэтому порядок такой: нажмите c, чтобы скопировать ссылку, откройте её на своём компьютере, а код, который покажет страница после входа, вставьте в терминал. Документация прямо называет этот путь для SSH и контейнеров.

Работа с Claude Code через SSH, tmux и VS Code

tmux держит терминальную сессию на сервере, когда SSH-соединение оборвалось. Для агента это главный инструмент: задачу на час можно запустить и уйти. Если удобнее смотреть на код в редакторе, подключите VS Code к серверу расширением Remote-SSH: оно само ставит на сервер серверную часть редактора, а Claude Code работает во встроенном терминале.

Вопросы и ответы

Как развернуть Claude Code на VPS, если на нём нет браузера?

Запустите claude, скопируйте ссылку для входа клавишей c, откройте её на своём компьютере и вставьте в терминал код со страницы. Либо задайте переменную ANTHROPIC_API_KEY с ключом из Claude Console.

Нужен ли Node.js для установки Claude Code?

Для официального скрипта не нужен: он ставит готовую программу. Node.js 22 или новее нужен только при установке через npm.

Можно ли работать с Claude Code на сервере из VS Code?

Да. Подключите VS Code к серверу через Remote-SSH и запускайте claude во встроенном терминале, файлы проекта будут открыты в редакторе.

Сколько памяти нужно серверу под Claude Code?

Документация называет минимум 4 ГБ. Сверху добавьте память под сборку и тесты проекта: для фронтенда со сборкой разумно 8 ГБ.
