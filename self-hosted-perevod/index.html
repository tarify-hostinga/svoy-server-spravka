Self hosted перевод: свой переводчик на сервере, коротко и с данными

Коротко

Главная / Self-hosted / Self hosted перевод Self hosted перевод работает целиком на вашем сервере: текст не уходит в Google, DeepL или другой облачный сервис. Основной готовый вариант это LibreTranslate с офлайн-моделями Argos Translate, а для сложных текстов к нему добавляют языковую модель через Ollama. Для перевода в браузере и через API ставьте LibreTranslate: он работает без видеокарты и без внешних сервисов.

Конспект по разделам

Self hosted перевод: сравнение движков

Существуют и открытые интерфейсы к Google Переводчику, которые ставятся на свой сервер. Это не self hosted перевод: текст всё равно уходит в Google, просто через ваш сервер.

LibreTranslate: свой переводчик с API

LibreTranslate это открытый API машинного перевода, который по словам разработчиков не зависит от проприетарных сервисов вроде Google или Azure. Переводит движок Argos Translate: модели для пар языков скачиваются на сервер и дальше работают без интернета. Через API LibreTranslate подключают боты, системы поддержки и скрипты: запрос с текстом, исходным и целевым языком, в ответ перевод.

  • Поставьте пакет libretranslate из PyPI или запустите официальный образ в Docker.
  • Ограничьте языки при запуске: каждая пара занимает место на диске и память, а русский с английским обычно покрывают основные задачи.
  • Включите ключи API, если переводчиком будут пользоваться программы или другие люди, и задайте лимиты запросов.
  • Закройте сервис обратным прокси с HTTPS, например Caddy, а наружу отдавайте только его.

Какой self hosted переводчик выбрать

Два ответа: что переводить и на каком железе По железу LibreTranslate скромен: для пары языков и небольшой команды для старта хватит 2 ядер и 4 ГБ памяти, а при первом запуске он скачает модели, поэтому сервису нужен доступ в интернет хотя бы один раз. Каждая новая языковая пара добавляет загрузку и расход памяти, так что список языков лучше держать коротким. Если перевод нужен внутри других сервисов, например в чате поддержки или в сценарии n8n, разместите.

Перевод нейросетью на своём сервере

Языковые модели переводят иначе, чем компактные модели Argos: они видят весь абзац, держат стиль и понимают инструкции вроде «не переводи названия продуктов». В запрос можно вложить глоссарий компании, и термины будут переводиться одинаково во всех документах. Цена этого подхода в железе.

Когда своего переводчика достаточно, а когда нет

Свой переводчик закрывает две задачи: понять смысл чужого текста и не отдавать конфиденциальные документы внешнему сервису. Обращения клиентов, внутреннюю переписку, черновики инструкций он переводит приемлемо, особенно с английского и на английский. Финальный текст проверяет человек Машинный перевод ошибается в числах, отрицаниях и терминах, причём уверенно.

Вопросы и ответы

Нужна ли видеокарта для LibreTranslate?

Нет, LibreTranslate работает на процессоре обычного сервера. Видеокарта нужна, если переводить большими языковыми моделями через Ollama.

Можно ли перевести документ целиком своим переводчиком?

LibreTranslate переводит текст через веб-интерфейс и API, для документов текст сначала извлекают. Для длинных документов с терминологией удобнее языковая модель с глоссарием в запросе.

Уходит ли текст куда-то при self hosted переводе?

Нет, если движок и модели стоят на вашем сервере: LibreTranslate и Argos Translate работают офлайн. Исключение: интерфейсы к Google Переводчику, которые только пересылают текст.
