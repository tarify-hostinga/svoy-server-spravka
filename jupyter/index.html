Установка Jupyter на свой сервер: коротко и с данными

Конспект страницы: 5 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Установка Jupyter на свой сервер.

Коротко

Установка Jupyter на сервер занимает пару команд: JupyterLab ставится через pip или запускается готовым образом Docker и открывается в браузере на порту 8888. Для команды вместо отдельных копий ставят JupyterHub, который выдаёт каждому свой сервер блокнотов. Для одного аналитика хватит 1 ядра и 2 ГБ памяти, дальше память растёт вместе с данными.

Конспект по разделам

Зачем держать Jupyter на сервере, а не на ноутбуке

Jupyter: среда, где код на Python, результаты и графики живут в одном документе-блокноте. JupyterLab: современный интерфейс для таких блокнотов, Jupyter Notebook: классический. На сервере блокнот считает, пока вы спите: долгая обработка данных или обучение не зависят от ноутбука.

Запуск Jupyter Notebook на сервере через pip

Без пароля Jupyter пускает по токену из ссылки, которую печатает при старте. После первого входа по токену сервер сам предложит задать пароль. Чтобы сессия пережила отключение SSH, запускайте jupyter lab в tmux или оформите службу systemd.

  • Создайте окружение и поставьте JupyterLab: python3 -m venv ~/jl && ~/jl/bin/pip install jupyterlab.
  • Задайте пароль командой jupyter server password: хэш пароля запишется в ~/.jupyter/jupyter_server_config.json.
  • Запустите сервер без браузера и только на локальном адресе.
  • Откройте туннель со своего компьютера и работайте по адресу http://127.0.0.1:8888.

Jupyter в Docker: образы Jupyter Docker Stacks

Проект Jupyter Docker Stacks публикует готовые образы в реестре quay.io, от минимального до научного набора. Пример из документации со сборкой scipy-notebook: Порт привязан к локальному адресу, а каталог с блокнотами подключён томом: без тома всё, что вы напишете, пропадёт вместе с контейнером. Ссылку с токеном контейнер печатает в журнал при старте.

Установка JupyterHub для команды

JupyterHub запускает отдельный сервер блокнотов для каждого пользователя и пускает по логину. Для установки нужен Linux, Python 3.10 или новее и Node.js 12 или новее с npm. По умолчанию вход идёт по учётным записям Linux на сервере.

Вопросы и ответы

Как поставить пароль на Jupyter на сервере?

Выполните jupyter server password: команда спросит пароль и запишет его хэш в ~/.jupyter/jupyter_server_config.json. После перезапуска сервер будет пускать по паролю.

Какой логин по умолчанию у JupyterHub в Docker?

Отдельного пароля по умолчанию нет: JupyterHub по умолчанию пускает по системным учётным записям Linux, внутри контейнера пользователей нужно создать или подключить другой способ входа.

Сколько памяти нужно JupyterHub на группу?

TLJH ставится от 1 ГБ, но память считают по пользователям: каждый открытый блокнот держит свои данные. Для 10-20 студентов с pandas закладывайте 16 ГБ и больше.

Можно ли запустить Jupyter с видеокартой в Docker?

Да, если на хосте стоят драйвер NVIDIA и NVIDIA Container Toolkit: добавьте к docker run флаг --gpus all и возьмите образ с PyTorch или TensorFlow.
