Установка Label Studio на свой сервер: коротко и с данными

Конспект страницы: 6 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Установка Label Studio на свой сервер.

Коротко

Установка Label Studio на сервер делается через pip или одной командой Docker, после чего интерфейс разметки открывается на порту 8080. Для команды разметчиков документация советует от 8 ГБ памяти (лучше 16 ГБ) и 50 ГБ диска. Для небольшой команды берите сервер на 8 ГБ памяти и запускайте Label Studio в Docker с томом /label-studio/data.

Конспект по разделам

Label Studio: зачем разметке данных свой сервер

Label Studio: открытый инструмент для разметки данных под машинное обучение. В нём выделяют объекты на картинках, размечают тексты, аудио и видео, а результат выгружают в форматах для обучения моделей. Свой сервер нужен, когда размечают несколько человек и данные нельзя отдавать во внешний сервис: медицинские снимки, документы клиентов, записи звонков.

Какой сервер нужен Label Studio

Сами файлы для разметки занимают больше, чем база задач. Картинки и видео удобнее хранить в S3 и подключать к проекту как внешнее хранилище, тогда диск сервера не растёт вместе с датасетом. Документация называет минимум 8 ГБ памяти, дальше считаем по данным и команде

Как открыть Label Studio разметчикам по HTTPS

Разметчики работают из браузера, поэтому сервису нужен домен и сертификат. Направьте поддомен на сервер и поставьте перед Label Studio обратный прокси, то есть сервер, который принимает HTTPS и передаёт запросы приложению: Caddy получит сертификат сам, с Nginx сертификат выдаёт Certbot. Первым зарегистрируйте свою учётную запись и сразу настройте приглашения для остальных: открытая регистрация на публичном адресе пускает в проект кого угодно.

CVAT вместо Label Studio: когда выбрать

CVAT: открытый инструмент разметки, заточенный под изображения и видео: рамки, полигоны, ключевые точки, трекинг объектов по кадрам. Разворачивается он через docker compose из репозитория проекта и состоит из нескольких контейнеров, поэтому ресурсов просит не меньше. Размеченные данные обычно уходят в обучение на видеокарте: сервер для этого подбирается на странице аренды видеокарты, а эксперименты удобно вести в MLflow.

Вопросы и ответы

Сколько памяти нужно Label Studio на сервере?

Документация называет минимум 8 ГБ и рекомендует 16 ГБ, а диск от 50 ГБ для рабочей установки.

Почему Label Studio в Docker не может записать данные?

Контейнер работает от пользователя с UID 1001. Сделайте его владельцем каталога тома командой chown 1001 и перезапустите контейнер.

Как сменить порт Label Studio?

Укажите другой порт при запуске label-studio или поменяйте левую часть параметра -p в docker run, например 127.0.0.1:9090:8080.

Что выбрать для разметки видео: Label Studio или CVAT?

Для длинных видео и задач компьютерного зрения удобнее CVAT, для смешанных данных и текстов Label Studio.
