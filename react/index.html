Коротко

Главная / Разработка / React и Vue React хостинг сводится к раздаче статических файлов: команда npm run build складывает приложение в каталог dist, а отдать его может платформа деплоя из Git, Nginx на VPS или любой файловый хостинг. Серверного процесса не нужно, поэтому Vue-приложение размещают точно так же. Нужны три вещи: HTTPS, правило для маршрутов и отдельное решение для API.

React на VPS: Nginx, try_files и кэширование

Приложение с маршрутами (React Router, Vue Router) отдаёт один файл index.html, а страницу выбирает скрипт в браузере. Поэтому на сервере нужно правило: если файла нет, вернуть index.html. Файлам из assets можно выставить долгий срок хранения: хэш в имени меняется при каждой сборке.

Адрес API и переменные окружения в React и Vue

Фронтенд выполняется в браузере, поэтому всё, что попало в сборку, видно любому посетителю. Переменные Vite с префиксом VITE_ вшиваются в код при сборке, и менять их без пересборки нельзя. Пароли и ключи в них не кладут.

React в Docker: сборка на Node и раздача через Nginx

Файл nginx.conf содержит блок из раздела выше с корнем /usr/share/nginx/html. Итоговый образ несёт только Nginx и статику, без Node.js. Тег node подберите под версию из файла package.json.

Вопросы и ответы

Как развернуть React приложение на сервере?

Выполнить npm run build, загрузить каталог dist на сервер и раздавать его через Nginx с правилом try_files на index.html. Или подключить репозиторий платформе деплоя из Git.

Нужен ли Node.js на сервере для React-приложения?

Нет, если приложение собрано в статику: достаточно веб-сервера. Node.js нужен для сборки и для фреймворков с серверным рендерингом.

Почему после обновления страницы React-приложение показывает 404?

Сервер ищет файл по адресу маршрута. Добавьте правило try_files с возвратом index.html, как в разделе про Nginx.

Чем хостинг для Vue отличается от хостинга для React?

Ничем: после сборки это тоже каталог dist. Для режима history в Vue Router нужно то же правило возврата index.html.

Подойдёт ли такой хостинг для React Native?

Нет. React Native собирает мобильное приложение, которое ставят из магазина. Серверу нужен только бэкенд, см. страницу про мобильное приложение.
