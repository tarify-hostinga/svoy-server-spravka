Конспект по разделам

Что такое Stirling PDF и зачем свой сервер для работы с PDF

Stirling PDF это веб-приложение с открытым кодом для действий с PDF: собрать несколько файлов в один, вырезать страницы, сжать скан, поставить пароль, заштриховать данные или распознать текст на скане. Пользоваться им могут несколько человек через браузер без установки программ. Основной довод за свой сервер один: онлайн-сервисы для PDF получают ваш файл целиком.

Какой образ Stirling PDF выбрать: latest, latest-fat или ultra-lite

Документация предлагает три образа в реестре docker.stirlingpdf.com, те же есть на Docker Hub и в GitHub Container Registry. Образы собраны для amd64 и arm64. Для первой установки подойдёт latest: вход нужен всегда, когда сервис виден из интернета.

Установка Stirling PDF через Docker Compose

В документации пример для порта выглядит как 8080:8080. Здесь он привязан к 127.0.0.1, чтобы сервис не стал виден всему интернету до настройки домена. Ограничение mem_limit: 4g взято оттуда же.

  • Подготовьте Docker с Compose на чистом Ubuntu и создайте каталог stirling-pdf.
  • Положите compose.yaml из примера ниже и создайте рядом папку stirling-data.
  • Запустите docker compose up -d и откройте http://127.0.0.1:8080 через туннель SSH или через прокси.
  • Войдите под admin с паролем stirling и сразу задайте свой.

Пароль admin, вход и HTTPS в Stirling PDF

В образах latest и latest-fat вход включён, а учётная запись по умолчанию называется admin с паролем stirling. Эти данные опубликованы в документации, поэтому сервис с неизменённым паролем уязвим для любого. Сменить пароль нужно до публикации по домену.

Распознавание русского текста в Stirling PDF: языки и tessdata

Распознавание сканов (OCR) использует базу языков Tesseract. Файлы языков лежат в каталоге /usr/share/tessdata, и в примере выше он вынесен на диск сервера. Чтобы Stirling PDF узнавал русский текст, положите в папку stirling-data/tessdata файл rus.traineddata из репозитория Tesseract и перезапустите контейнер.

Документы с персональными данными в Stirling PDF и обновления

Если вы обрабатываете документы клиентов, помните о 152-ФЗ: он требует использовать базы на территории России при сборе и хранении персональных данных граждан России, а детали лучше уточнить у юриста. Серверы линейки MSK Ultra расположены в Москве. Каталог logs просматривайте сами: что именно пишет журнал, зависит от версии и настроек.

Вопросы и ответы

Какой пароль по умолчанию у Stirling PDF?

В образах latest и latest-fat это admin и пароль stirling. Смените его при первом входе, потому что данные описаны в открытой документации.

Сколько памяти нужно Stirling PDF?

Документация советует 4 ГБ для образа latest, 2 ГБ для ultra-lite и от 6 ГБ для latest-fat с включённым модулем ИИ.

Как отключить вход в Stirling PDF?

Задайте переменную окружения SECURITY_ENABLELOGIN=false или параметр security.enableLogin: false в settings.yml. Тогда закройте доступ паролем на прокси.

Безопасно ли загружать паспорта и договоры в Stirling PDF?

На своём сервере файл остаётся у вас, но безопасность зависит от настройки: пароль, HTTPS, закрытые порты и обновления образа.
