AutoGen в Docker на своём сервере: коротко и с данными

Конспект страницы: 6 разделов коротко, данные на 14 октября 2026 и ответы на 3 вопроса. Полный разбор с примерами: AutoGen в Docker на своём сервере.

Коротко

AutoGen в Docker нужен в двух местах: контейнер с вашим приложением и отдельные контейнеры, где агенты исполняют сгенерированный код. AutoGen Studio, визуальная оболочка фреймворка, запускается на порту 8080, но Microsoft называет её прототипом, а не продуктом для продакшена. AutoGen перешёл в режим поддержки: для существующих проектов он работает, новые Microsoft советует начинать на Agent Framework.

Конспект по разделам

В каком состоянии AutoGen на 2026 год

AutoGen это многоагентный фреймворк Microsoft Research на Python. Сейчас он в режиме поддержки: новых функций не будет, проект ведёт сообщество, принимаются только исправления ошибок, уязвимостей и документации. Новым пользователям Microsoft рекомендует Microsoft Agent Framework и публикует руководство по переходу.

Как AutoGen исполняет код агентов в Docker

Агент, который пишет программы, должен где-то их запускать. Для этого в AutoGen есть исполнитель DockerCommandLineCodeExecutor из пакета autogen-ext[docker]: на каждую сессию он создаёт контейнер и выполняет команды внутри него. Образ по умолчанию python:3-slim, свой подойдёт, если в нём есть sh и python.

  • Перечислите зависимости в requirements.txt: autogen-agentchat, autogen-ext[openai,docker].

  • Запустите с ключами в.env и сокетом Docker, если агенты исполняют код.

AutoGen Studio на сервере: где её место

AutoGen Studio ставится командой pip install -U autogenstudio и запускается как autogenstudio ui --port 8080 --appdir./my-app. По умолчанию она слушает localhost и хранит базу SQLite и файлы в каталоге ~/.autogenstudio; параметр --database-uri переключает её на PostgreSQL. В заметке о безопасности авторы пишут прямо: Studio это исследовательский прототип, в нём нет защиты от обхода ограничений модели и разграничения доступа к данным.

Чем AutoGen отличается от AutoGPT и как поднять AutoGPT

AutoGPT это другой проект от команды Significant Gravitas, не связанный с Microsoft. Его платформа разворачивается через Docker Compose: интерфейс на порту 3000, WebSocket-сервер на 8001, REST API исполнения на 8006, база PostgreSQL с расширением pgvector. Лицензии у частей разные: платформа ( autogpt_platform ) под Polyform Shield, то есть бесплатно для личного и внутреннего использования, но без права продавать её как конкурирующий облачный сервис.

Вопросы и ответы

Стоит ли начинать новый проект на AutoGen?

Microsoft советует новым пользователям Microsoft Agent Framework: AutoGen получает только исправления ошибок и уязвимостей. Для действующих проектов на AutoGen есть официальное руководство по переходу.

Как запустить AutoGen Studio в Docker?

Официального образа Studio в документации нет: поставьте autogenstudio в образ на python:3.12-slim, внутри контейнера запускайте с --host 0.0.0.0, а порт 8080 публикуйте только на 127.0.0.1.

Почему AutoGen внутри контейнера не может запустить контейнер для кода?

У контейнера нет доступа к Docker хоста. Смонтируйте /var/run/docker.sock: так исполнитель создаёт соседние контейнеры на сервере.
