Activepieces в Docker на своём сервере: коротко и с данными

Конспект страницы: 6 разделов коротко, данные на 14 октября 2026 и ответы на 3 вопроса. Полный разбор с примерами: Activepieces в Docker на своём сервере.

Коротко

Activepieces в Docker ставится двумя способами: один контейнер со встроенной базой PGLite для личных задач или Docker Compose с PostgreSQL и Redis, который разработчики рекомендуют для работы. Во втором случае серверу нужно от 2 vCPU и 4 ГБ памяти, а редактор сценариев открывается на порту 8080. Если сценарии нужны не только вам, сразу ставьте Docker Compose с PostgreSQL и Redis на сервер от 2 vCPU и 4 ГБ: перейти с одноконтейнерной версии потом можно только заново.

Конспект по разделам

Что автоматизирует Activepieces и чем он похож на n8n

Activepieces это конструктор автоматизаций: сценарий начинается с триггера (вебхук, расписание, новая строка в таблице) и выполняет действия в сервисах. Есть ИИ-агенты, встроенные таблицы и сборка сценария по описанию в чате. Интеграции называются pieces, их больше 280, и все они доступны ИИ-клиентам как MCP-серверы.

Установка Activepieces через Docker Compose

У каждой из трёх переменных должно быть значение. AP_ENCRYPTION_KEY шифрует подключения к сервисам, поэтому копию.env храните вместе с дампом PostgreSQL.

  • Проверьте Docker Compose v2 командой docker compose version: старый docker-compose не подойдёт.
  • Запустите установщик curl -fsSL https://get.activepieces.com | sh в выбранной папке.
  • Или соберите вручную: склонируйте репозиторий и выполните sh tools/deploy.sh, он создаст.env из примера и сгенерирует пароли.
  • Проверьте ключи.

Домен, HTTPS и вебхуки Activepieces

Вебхукам и триггерам сторонних сервисов нужен адрес, доступный из интернета. Документация описывает HTTPS через Nginx как обратный прокси с сертификатом Let's Encrypt от Certbot; подойдёт и Caddy.

  • Пропишите публичный адрес в AP_FRONTEND_URL, например https://flows.example.com.
  • Воркеру в compose-файле задайте свой AP_FRONTEND_URL=http://app: внутри контейнера внешний домен указывает не туда, и воркер не подключится к приложению.
  • Режим исполнения кода выбирается переменной AP_EXECUTION_MODE.

Вопросы и ответы

Можно ли перенести Activepieces с PGLite на PostgreSQL?

Документация прямо пишет, что уход с одноконтейнерной версии означает начать заново. Если сценарии будут рабочими, ставьте compose-вариант с PostgreSQL сразу.

Почему вебхуки Activepieces не срабатывают?

Чаще всего в AP_FRONTEND_URL остался localhost, и сервис-отправитель не может достучаться до сервера. Нужен публичный домен с HTTPS; ngrok разработчики допускают только для тестов.

Как обновить Activepieces в Docker?

Скачать новый образ activepieces/activepieces:latest и пересоздать контейнеры той же командой или через docker compose up -d. Для отката у разработчиков есть отдельная инструкция.
