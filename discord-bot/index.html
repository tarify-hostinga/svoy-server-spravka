Коротко

Бесплатный хостинг для бота Дискорд найти можно, но с подвохом: бот держит постоянное WebSocket-соединение с Discord Gateway, а бесплатные тарифы платформ рассчитаны на сайты, которые можно усыпить без трафика. Для пробы хватит домашнего компьютера, а боту, которым пользуется сообщество, нужен процесс 24/7 на VPS. Бесплатные варианты годятся для тестов и бота для друзей.

Конспект по разделам

Почему боту Discord нужен постоянно работающий процесс

Discord-бот на discord.py или discord.js подключается к Gateway, это WebSocket-канал, по которому Discord присылает события: сообщения, нажатия кнопок, вход людей на сервер. Пока соединение живо, бот в сети. Остановился процесс, и через короткое время бот становится серым в списке участников.

Бесплатные варианты для Discord-бота и их ограничения

Подробный разбор бесплатных площадок с их условиями: бесплатный хостинг для бота. Два вопроса о том, кто и как им пользуется

Intents в Discord: что включить в Developer Portal

Intents определяют, какие события Discord присылает боту. Три из них привилегированные: Presence, Server Members и Message Content. Их включают вручную в Developer Portal, в разделе Privileged Gateway Intents вашего приложения, и дублируют в коде.

Запуск Discord-бота на VPS: discord.py и discord.js

Свежий discord.py 2.7.1 требует Python 3.8 и новее, discord.js 14.27.0 работает на Node.js 18 и новее и распространяется под Apache 2.0. Python на Ubuntu уже есть, Node.js ставят из репозитория дистрибутива или с nodejs.org, проверив версию командой node -v. После проверки запустите бота службой с автоперезапуском: пример для Python есть в разборе бот на Python на сервере, общий подход для любых языков и Docker на странице как запустить бота 24/7.

Токен Discord-бота: хранение и утечки

Токен даёт полный доступ к боту на всех его серверах. Храните его в файле.env с правами 600 или в переменной окружения службы, и добавьте.env в.gitignore до первого коммита. Если токен попал в публичный репозиторий или чат, сразу сгенерируйте новый кнопкой Reset Token в разделе Bot в Developer Portal: старый перестанет работать, и бот надо будет перезапустить с новым значением.

Вопросы и ответы

Почему Discord-бот не видит текст сообщений?

Не включён Message Content intent. Его нужно включить и в Developer Portal в разделе Privileged Gateway Intents, и в коде: intents.message_content = True.

Какая версия Python нужна для discord.py?

discord.py 2.7.1 требует Python 3.8 и новее. На Ubuntu 22.04 и 24.04 системного Python достаточно, ставьте библиотеку в виртуальное окружение.

Сколько памяти нужно Discord-боту на сервере?

Боту со слеш-командами и модерацией хватает младшего VPS с 1 ГБ памяти. Музыкальному боту с ffmpeg и нескольким ботам на одном сервере лучше взять 2 ГБ.
