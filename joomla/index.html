Коротко

Хостинг для Joomla 6 должен давать PHP не ниже 8.3, базу MySQL, MariaDB или PostgreSQL и около 256 МБ памяти на процесс PHP. Для одного сайта подойдёт и обычный виртуальный хостинг, а свой VPS нужен, когда требуется управлять версией PHP, кэшем, несколькими сайтами и копиями. Ниже требования из документации и порядок установки на Ubuntu.

Обычный хостинг или VPS для Joomla: что выбрать

Виртуальный хостинг удобен, когда сайт один, а PHP нужной версии включается в панели. Его ограничения видны, когда требуется свой cron для очередей, нестандартные расширения PHP, кэш в Redis или перенос копий на сторонний сервер.   • Виртуальный хостинг: сайт и база в одной панели, обслуживание на провайдере.
  • VPS: вы выбираете версии PHP и базы, ставите кэш и сами делаете копии.

Установка Joomla на VPS с Ubuntu: стек и мастер установки

В Ubuntu 24.04 версия PHP в репозитории 8.3, то есть подходит для Joomla 6. Ниже вариант на Apache и MariaDB. Имя архива подставьте то, которое скачали.

  • Поставьте стек и нужные расширения PHP.
  • Создайте базу и пользователя в MariaDB для сайта.
  • Скачайте архив Joomla с официального сайта downloads.joomla.org, распакуйте в каталог сайта и выдайте права пользователю веб-сервера.
  • Откройте адрес сайта в браузере: мастер попросит название сайта, учётную запись администратора и данные базы.

Joomla в Docker: официальный образ и база

У Joomla есть официальный образ joomla на Docker Hub, внутри Apache и PHP. Вторым контейнером запускают MariaDB, данные сайта хранят в томе. Тег latest годится для пробы, для рабочего сайта закрепите версию Joomla и PHP, чтобы не получить скачок на новую ветку.

Где на хостинге лежат данные сайта Joomla

Сайт Joomla состоит из файлов в корне сайта (на хостинге это обычно папка public_html или www) и базы данных. Это две отдельные части, и копировать нужно обе. При переносе сайта на другой сервер копируют каталог и дамп базы, затем правят configuration.php: имя базы, пользователя, пароль и путь к временным каталогам.

HTTPS и резервные копии сайта на Joomla

Сертификат для сайта выпускает Certbot для Apache или Nginx. Если перед Joomla стоит прокси, например Caddy, сертификат получит он, а контейнеру останется порт 8080 на локальном адресе. После включения HTTPS откройте в админ-панели глобальную конфигурацию и включите принудительный HTTPS на всём сайте.

Вопросы и ответы

Какая версия PHP нужна для Joomla 6?

Минимум PHP 8.3.0, рекомендуют 8.4. Для базы подойдёт MySQL от 8.0.13, MariaDB от 10.4 или PostgreSQL от 12.

Где на хостинге в Joomla лежат данные сайта?

Файлы находятся в корневой папке сайта, а статьи, меню и пользователи в базе данных. Реквизиты базы записаны в файле configuration.php.

Хватит ли для Joomla обычного виртуального хостинга?

Для одного небольшого сайта да, если можно выбрать PHP 8.3 или новее. VPS нужен, когда требуются свои расширения PHP, кэш или несколько сайтов.

Как установить Joomla на Ubuntu?

Поставьте Apache, MariaDB и PHP с расширениями gd, xml и mysql, создайте базу, распакуйте архив Joomla в каталог сайта и откройте адрес в браузере: дальше ведёт мастер установки.
