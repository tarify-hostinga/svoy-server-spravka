Установка LM Studio на компьютер и сервер: коротко и с данными

Конспект страницы: 6 разделов коротко, данные на 14 октября 2026 и ответы на 3 вопроса. Полный разбор с примерами: Установка LM Studio на компьютер и сервер.

Коротко

Установка LM Studio на Windows и macOS это обычный установщик, на Linux файл AppImage, а для сервера без экрана есть демон llmster. Программа скачивает модели с Hugging Face, запускает их на процессоре или видеокарте и по запросу включает OpenAI-совместимый API на порту 1234. Для LM Studio нужен ПК с 16 ГБ памяти и, на x64, процессором с AVX2.

Конспект по разделам

Требования LM Studio к компьютеру

На Mac с 8 ГБ программа запустится, но документация советует ограничиться малыми моделями и коротким контекстом. Версии Ubuntu новее 22 разработчики отмечают как слабо проверенные. После скачивания моделей LM Studio работает без интернета.

Установка LM Studio и первых моделей

Движки LM Runtimes обновляются в отдельном окне, его открывает сочетание Ctrl+Shift+R на Windows и Linux. Если файлы GGUF уже скачаны, их подключают командой lms import, а не качают заново.

  • Скачайте установщик с lmstudio.ai для своей системы.
  • Откройте вкладку Discover и найдите модель по имени, например Qwen3.5 или Gemma 4.
  • Загрузите модель в окне чата или из терминала командой lms load.

LM Studio как сервер API: порт, сеть и токены

Сервер включается переключателем Start server на вкладке Developer или командой lms server start. Примеры документации используют порт 1234, другой задают флагом --port. Программы подключаются к http://localhost:1234/v1 как к OpenAI; есть и совместимость с API Anthropic.

  • --bind 0.0.0.0 или настройка Serve on Local Network открывает сервер другим устройствам; по умолчанию он слушает только 127.0.0.1.
  • Токены API появились в версии 0.4.0.
  • Режим JIT подгружает модель по первому запросу, если она ещё не загружена.

LM Studio на VPS без экрана: llmster вместо Docker

Образа Docker в документации LM Studio нет. Для серверов разработчики выпустили llmster: ядро LM Studio без графического интерфейса, которое работает на Linux-серверах и машинах с GPU. Для автозапуска после перезагрузки в документации есть отдельная инструкция по задаче запуска на Linux.

LM Studio, Ollama или llama.cpp: что выбрать

LM Studio удобнее всего на личном компьютере, где хочется видеть модели и настройки. Для бота и общего сервера обычно берут Ollama или llama.cpp: их проще обновлять и встраивать в Docker.

Возьмите сервер с видеокартой под модель

Облачный GPU-сервер запускается за 1-2 минуты, оплата почасовая.

  • RTX 4090, A5000, A6000, A100, H100
  • От 1 до 4 карт на сервер
  • Почасовая оплата
  • Дата-центры уровня Tier III

Вопросы и ответы

Можно ли пользоваться LM Studio в компании бесплатно?

Условия использования разрешают LM Studio для личных и внутренних рабочих целей без оплаты. Изменять программу и делать на её основе производные условия запрещают, поэтому для сервиса клиентам берут движок с открытой лицензией.

Почему LM Studio не запускается на старом процессоре?

На x64 программе нужны инструкции AVX2. Процессоры без них не поддерживаются; в этом случае подойдёт llama.cpp, собранный под ваш процессор.

Как подключить LM Studio к Open WebUI или n8n?

Включите сервер в LM Studio и укажите в программе адрес http://IP:1234/v1 как OpenAI-совместимый. Если интерфейс в Docker на том же компьютере, адрес будет http://host.docker.internal:1234/v1.
