Установка LangChain-приложения на свой сервер: коротко и с данными

Конспект страницы: 6 разделов коротко, данные на 14 октября 2026 и ответы на 3 вопроса. Полный разбор с примерами: Установка LangChain-приложения на свой сервер.

Коротко

Установка LangChain на сервер это установка вашего приложения: библиотека ставится командой uv add langchain, а на VPS круглосуточно работает Python-сервис, который её использует. Готового сервера LangServe больше нет в рекомендациях: проект объявлен устаревшим с 18 ноября 2024 года. Упакуйте приложение в Docker и отдавайте его через свой API на FastAPI: для бота по API хватит 1 ядра и 2 ГБ памяти.

Конспект по разделам

Что ставят на сервер, когда говорят про LangChain

LangChain это библиотека с открытым кодом (MIT) для приложений на языковых моделях: единый интерфейс к моделям разных провайдеров, инструменты, поиск по документам и готовые агенты. Вокруг неё выросла экосистема: LangGraph для сложной оркестрации агентов, Deep Agents для агентов с планированием и подагентами, LangSmith для трассировки и деплоя. Сервера у самой библиотеки нет.

Почему LangServe больше не подходит для LangChain-приложений

LangServe долго был стандартным способом отдать цепочку LangChain по HTTP. С 18 ноября 2024 года он объявлен устаревшим: сообщество принимает только исправления ошибок, а для новых проектов разработчики рекомендуют платформу LangGraph, которая теперь входит в LangSmith Deployment. На практике у вас два пути.

Docker Compose для LangChain-приложения с Ollama

Порт Ollama 11434 здесь не публикуется вовсе: приложение видит её по внутренней сети Docker, а снаружи модель недоступна. Подробно о самой Ollama и размерах моделей: Ollama на сервере.

  • Соберите образ приложения на python:3.12-slim: зависимости из pyproject.toml, команда запуска uvicorn.
  • Добавьте Ollama отдельным сервисом с томом для моделей.
  • Скачайте модель командой docker compose exec ollama ollama pull имя-модели.
  • В коде обращайтесь к Ollama по имени сервиса: ChatOllama(model=..., base_url="http://ollama:11434").

Вопросы и ответы

Подойдёт ли для LangChain обычный хостинг сайтов?

Обычно нет: виртуальный хостинг рассчитан на PHP и короткие запросы, а LangChain-приложению нужен постоянно работающий Python-процесс. Подойдёт VPS или платформа, которая запускает Docker-образы из Git.

Чем LangChain отличается от LangGraph?

LangChain даёт компоненты и готовых агентов, LangGraph отвечает за оркестрацию: граф шагов, состояние, долгие запуски. У LangGraph есть свой сервер Agent Server, у LangChain его нет.

Можно ли запустить LangChain с Ollama без видеокарты?

Да, если модель небольшая: на процессоре она отвечает, но заметно медленнее. Для моделей на десятки миллиардов параметров нужен сервер с видеокартой.
