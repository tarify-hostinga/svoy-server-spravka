Установка AdGuard Home на VPS: коротко и с данными

Конспект страницы: 7 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Установка AdGuard Home на VPS.

Коротко

Главная / Self-hosted / AdGuard Home Установка AdGuard Home на VPS делается одним контейнером adguard/adguardhome: он принимает DNS-запросы на порту 53, а мастер первой настройки открывается на порту 3000. На сервере в интернете AdGuard Home нужен для шифрованного DNS (DoT и DoH) своим устройствам и семье. Он фильтрует рекламу и трекеры по спискам и не меняет ни ваш IP-адрес, ни доступность сайтов.

Конспект по разделам

Что делает AdGuard Home и чего он не делает

AdGuard Home это DNS-сервер с фильтрами. Когда устройство обращается к сайту, оно сначала спрашивает DNS, какой у сайта адрес. AdGuard Home сверяет домен со списками рекламы, трекеров и вредоносных сайтов и для запрещённых отвечает отказом.

Где ставить AdGuard Home: дома, на роутере или на VPS

Часто выбирают комбинацию: дома AdGuard Home на роутере или мини-ПК (см. сервер для умного дома ), а VPS нужен для телефона вне Wi-Fi. Повторные запросы кэшируются, поэтому медленный первый ответ заметен только на новых сайтах.

Сколько ресурсов нужно AdGuard Home

AdGuard Home написан на Go и сам по себе занимает мало памяти. Прирост даёт журнал запросов и статистика: чем больше устройств и чем дольше вы храните историю, тем больше места нужно под данные. Для семьи хватает самого младшего тарифа, офису и журналу на месяцы добавляйте по калькулятору.

Установка AdGuard Home в Docker на Ubuntu

Порты 67 и 68 для DHCP на VPS не нужны. Панель управления привязана к 127.0.0.1: так мастер не виден из интернета, пока вы не задали пароль. Вместо туннеля можно поставить Caddy и открыть панель по домену с HTTPS.

  • Освободите порт 53.
  • Установите Docker уже после освобождения порта: curl -fsSL https://get.docker.com | sh.
  • Запустите контейнер по compose-файлу ниже.
  • Откройте мастер через туннель SSH на порт 3000 ( ssh -L 3000:127.0.0.1:3000 user@IP ), создайте администратора и выберите порты.

Как защитить DNS AdGuard Home на VPS от посторонних

Резолвер, отвечающий всем подряд, называют открытым. Открытые резолверы применяют для усиления DDoS-атак, поэтому хостер может ограничить такой сервер. Свой DNS нужно закрыть от чужих.

  • Файрвол.
  • Список разрешённых клиентов.
  • DoT на домене.

Обновление и копии AdGuard Home в Docker

Образ обновляют командами docker compose pull и docker compose up -d. Сохраняется всё, что лежит в смонтированных каталогах, поэтому контейнер можно пересоздавать без потерь. Копируйте каталог conf: в нём файл AdGuardHome.yaml с пользователями, списками фильтров и правилами.

Вопросы и ответы

Какие порты нужны AdGuard Home в Docker?

53 по TCP и UDP для DNS, 3000 для мастера первой настройки, 853 для DNS-over-TLS. Для DoH используют 443, для панели после настройки порты 80 или 3000.

Почему AdGuard Home не запускается на Ubuntu из-за порта 53?

Порт занимает systemd-resolved. Отключите его заглушку параметром DNSStubListener=no в отдельном файле resolved.conf.d и перезапустите службу.

Безопасно ли открывать AdGuard Home на VPS в интернет?

Только с ограничениями: разрешите свои адреса в списке клиентов, закройте порт 53 файрволом и подключайте устройства по DoT. Открытый резолвер используют для DDoS-атак.

Подходит ли AdGuard Home для доступа к закрытым сайтам?

Нет. Он фильтрует рекламу и трекеры по спискам доменов и не меняет ни ваш адрес, ни маршрут трафика.
