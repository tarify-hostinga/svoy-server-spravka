Установка DeepSeek на компьютер и свой сервер: коротко и с данными

Конспект страницы: 6 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Установка DeepSeek на компьютер и свой сервер.

Коротко

Установка DeepSeek у себя почти всегда означает дистиллированную версию R1 на 1,5-70 млрд параметров: она ставится через Ollama одной командой и работает на ПК или сервере с картой. Полные модели DeepSeek V4 открыты под лицензией MIT, но даже младшая весит 284 млрд параметров и требует нескольких серверных GPU. На домашнем ПК с картой 8-12 ГБ запускают DeepSeek-R1 8B или 14B.

Конспект по разделам

Какие версии DeepSeek можно поставить у себя

Под названием DeepSeek ходят модели очень разного размера. Дистилляты R1 это небольшие модели Qwen и Llama, дообученные на рассуждениях большой R1: они думают похожим образом, но знают меньше. Серия V4 вышла в 2026 году и построена на смеси экспертов (MoE).

Сколько памяти нужно DeepSeek: дистилляты и MoE

У дистиллятов всё просто: память примерно равна размеру файла плюс кэш контекста. С MoE-моделями путаются чаще. На каждый токен V4-Flash задействует 13 млрд параметров, поэтому отвечает быстро, но держать в памяти приходится все 284 млрд: эксперт может понадобиться на любом следующем слове.

Установка DeepSeek-R1 через Ollama на ПК и сервер

В Docker команда та же, только внутри контейнера: docker exec -it ollama ollama run deepseek-r1:14b. Модель потом доступна по API на порту 11434 для ботов и n8n. Дистилляты лежат на Hugging Face в обычном формате, поэтому их можно отдать и через vLLM, когда запросов много.

  • Поставьте Ollama: на Linux скриптом curl -fsSL https://ollama.com/install.sh | sh, на Windows и macOS установщиком с сайта.
  • Запустите модель по размеру памяти: ollama run deepseek-r1:8b для карты на 8 ГБ, deepseek-r1:14b для 12 ГБ, deepseek-r1:32b для 24 ГБ.
  • Подключите интерфейс, если терминала мало: Open WebUI даст чат в браузере для нескольких человек.

Полная DeepSeek V4 на своём железе: когда это оправдано

Веса V4-Flash, V4-Pro и вышедшей в сентябре 2026 года V4.1-Flash опубликованы под MIT: их можно ставить у себя и использовать в коммерческих продуктах. Модельная карточка отсылает к своей папке inference с инструкцией по конвертации весов и запуску. Даже в сжатии 284 млрд параметров не помещаются в одну H200 на 141 ГБ, а V4-Pro на 1,6 трлн требует нескольких серверов.

Вопросы и ответы

Как развернуть DeepSeek локально на своём ПК?

Поставить Ollama и выполнить ollama run deepseek-r1:8b. Для карты на 12 ГБ подойдёт 14b, для 24 ГБ версия 32b. Без видеокарты 8B работает на процессоре, но медленно.

Можно ли запустить DeepSeek R1 671B на одном сервере?

Файл в Ollama весит 404 ГБ в сжатии. Нужен сервер с несколькими картами по 80-141 ГБ или очень много оперативной памяти с медленными ответами.

Разрешено ли использовать DeepSeek в коммерческом проекте?

Веса R1 и V4 выпущены под MIT. Дистилляты на основе Llama дополнительно подчиняются лицензии Llama 3.1 или 3.3, на основе Qwen 2.5 лицензии Apache 2.0.

Как запустить DeepSeek в Docker?

Через контейнер движка: ollama/ollama для моделей из каталога Ollama или vllm/vllm-openai для весов с Hugging Face. Модель указывают при запуске, том с весами подключают отдельно.
