Главная / Разработка / PeerTube Установка PeerTube на своём сервере сводится к официальному файлу docker-compose из каталога support/docker/production: в нём веб-сервер Nginx, сам PeerTube, PostgreSQL, Redis и контейнер Certbot. Это собственный видеохостинг, который умеет обмениваться роликами с другими такими же серверами. Главные ресурсы здесь процессор для перекодирования роликов и диск под видео.

Конспект по разделам

Что такое PeerTube и когда нужен свой видеосервер

PeerTube это программа для собственного видеохостинга. Вы запускаете сайт, где можно загружать ролики, делать каналы и плейлисты, а зрители смотрят видео в браузере. Серверы PeerTube могут подписываться друг на друга по открытому протоколу, поэтому ролики видны и на чужих серверах.

Сколько процессора и диска нужно PeerTube

Каждый загруженный ролик сервер перекодирует в несколько разрешений, и для этого используется FFmpeg. Процессор поэтому занят дольше, чем обычным сайтом, и скорость обработки видео зависит от числа ядер. Диск занимают исходный файл и его варианты, итоговый объём больше размера загруженного.

Установка PeerTube через Docker Compose

Пароль пользователя root появляется в журнале при первом запуске: Первая команда показывает пароль, вторая сбрасывает его, если вы его потеряли. В документации прямо сказано, что PeerTube не поддерживает смену домена после первого запуска. Купите и направьте домен на сервер до установки.

  • Проверьте Docker: команда docker compose version должна показывать вторую версию.
  • Скачайте два файла из каталога support/docker/production репозитория PeerTube: docker-compose.yml и.env.
  • Заполните.env: имя пользователя и пароль PostgreSQL, домен без https://, почту администратора и секрет PeerTube.
  • Выпустите сертификат и запустите стек: docker compose up.

HTTPS для PeerTube: встроенный Nginx и Certbot

В compose-файле уже есть веб-сервер Nginx, его шаблон скачивается в каталог docker-volume/nginx/peertube. Первый сертификат Let’s Encrypt выпускают контейнером Certbot в автономном режиме: ему нужен свободный порт 80. Дальше отдельный контейнер Certbot сам продлевает сертификат и перезагружает Nginx.

Где хранить видео PeerTube: диск или S3

По умолчанию файлы лежат в томе на диске сервера, поэтому с ростом библиотеки приходится увеличивать диск. PeerTube умеет складывать видео в S3-совместимое хранилище. Обновление PeerTube в Docker по шагам

Перед обновлением прочитайте раздел «IMPORTANT NOTES» в списке изменений проекта: там отмечены несовместимые правки. По документации порядок такой: Для обновления основной версии PostgreSQL планируйте простой сервиса: базу выгружают командой pg_dumpall, пересоздают том и загружают данные обратно.

  • Скачайте новые образы: docker compose pull.
  • Остановите стек: docker compose down -v.
  • Замените конфигурацию Nginx свежим шаблоном, сохранив копию своей.
  • Запустите: docker compose up -d.

Вопросы и ответы

Как установить PeerTube через Docker Compose?

Скачайте docker-compose.yml и.env из каталога support/docker/production репозитория PeerTube, заполните домен, пароли и секрет, выпустите сертификат и выполните docker compose up.

Где взять пароль root после установки PeerTube?

Он выводится в журнал при первом запуске: docker compose logs peertube | grep -A1 root. Если пароль потерян, его сбрасывает команда npm run reset-password в контейнере.

Можно ли поменять домен PeerTube после установки?

Нет. Документация предупреждает, что смена домена веб-сервера не поддерживается, поэтому домен выбирают до первого запуска.
