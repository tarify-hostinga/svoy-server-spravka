Установка Vaultwarden на свой сервер: коротко и с данными

Конспект страницы: 6 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Установка Vaultwarden на свой сервер.

Коротко

Главная / Self-hosted / Vaultwarden Установка Vaultwarden на свой сервер это один контейнер vaultwarden/server с томом /data и обратный прокси с HTTPS: без сертификата веб-хранилище не откроется. После этого к серверу подключаются официальные приложения и расширения Bitwarden на всех устройствах. Vaultwarden ставится одним контейнером на сервер с 1 ГБ памяти.

Конспект по разделам

Что такое Vaultwarden и чем он отличается от Bitwarden

Vaultwarden это неофициальный сервер, совместимый с API Bitwarden. Он написан на Rust, распространяется под AGPL-3.0 и работает с официальными клиентами Bitwarden: расширениями для браузеров, приложениями для телефонов и компьютеров. С компанией Bitwarden проект не связан, и за помощью с ним идут в сообщество Vaultwarden, а не в поддержку Bitwarden.

Почему Vaultwarden не работает без HTTPS

Веб-хранилище Bitwarden шифрует данные в браузере через Web Crypto API, а браузеры дают доступ к нему только на страницах с HTTPS. Поэтому вики Vaultwarden называет HTTPS практически обязательным: по http страница входа откроется, но работать хранилище не будет. Рекомендуемый способ из документации: Vaultwarden слушает только локальный адрес, а сертификат получает обратный прокси.

Установка Vaultwarden через Docker Compose

Caddyfile для того же сервера:

  • Направьте поддомен на IP сервера и запустите docker compose up -d, затем Caddy.
  • Откройте https://vw.example.com и зарегистрируйте учётные записи для себя и семьи.
  • Закройте регистрацию: поменяйте SIGNUPS_ALLOWED на "false" и пересоздайте контейнер.
  • В клиентах Bitwarden выберите «свой сервер» и укажите адрес из DOMAIN.

Страница /admin в Vaultwarden и токен на argon2

Панель администратора включается переменной ADMIN_TOKEN и открывается по адресу /admin. В ней приглашают пользователей, настраивают почту для уведомлений и смотрят состояние сервера. Токен в открытом виде лежит в конфигурации, поэтому вики советует хранить его хэшем argon2id.

Что копировать из каталога /data Vaultwarden

Базу SQLite снимайте командой sqlite3 с.backup, а не копированием файла на ходу. Вместо SQLite можно подключить PostgreSQL или MySQL через DATABASE_URL. Отдельных бинарных файлов для установки без Docker проект не выпускает: их извлекают из Alpine-образа или берут пакеты сообщества.

Вопросы и ответы

Можно ли установить Vaultwarden без Docker?

Да, но официальных отдельных сборок нет. Вики описывает, как извлечь статический бинарный файл из образа vaultwarden/server:latest-alpine и запустить его как службу systemd.

Почему Vaultwarden не открывается по http?

Веб-хранилище использует Web Crypto API, а браузеры разрешают его только по HTTPS. Поставьте перед Vaultwarden обратный прокси с сертификатом.

Чем Vaultwarden отличается от HashiCorp Vault?

Vaultwarden хранит пароли людей и работает с приложениями Bitwarden. HashiCorp Vault выдаёт секреты программам и сервисам: ключи, токены, пароли баз.

Как обновить Vaultwarden в Docker?

Сделайте копию /data, выполните docker compose pull и docker compose up -d. Тег latest следует за последним выпуском, тег testing за свежими изменениями в репозитории.
