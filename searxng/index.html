Установка SearXNG на свой сервер: коротко и с данными

Конспект страницы: 7 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Установка SearXNG на свой сервер.

Коротко

Главная / Self-hosted / SearXNG Установка SearXNG на свой сервер делается одним контейнером searxng/searxng: он слушает порт 8080 и рассылает ваш запрос по десяткам поисковиков, а потом склеивает ответы в одну выдачу. Своя копия нужна тем, кто хочет метапоиск без профиля пользователя и без рекламы, а также ИИ-агентам и Open WebUI, которым нужен поиск по интернету через JSON. SearXNG ставится одним контейнером и занимает мало памяти, поэтому подойдёт и младший тариф.

Конспект по разделам

Что такое SearXNG и кому нужен свой метапоиск

SearXNG это метапоисковик с открытым кодом. Своего индекса у него нет: он отправляет запрос другим поисковикам, убирает дубли и показывает общий результат. Для поисковиков вы выглядите как сервер SearXNG, а не как конкретный человек со своей историей запросов.

Сколько ресурсов нужно SearXNG

Основная нагрузка SearXNG это ожидание ответов от внешних поисковиков, а не вычисления. Поэтому личному экземпляру хватает младшего тарифа. Больше памяти требует Valkey, если включён лимитер, и соседние сервисы, например интерфейс для нейросетей.

Установка SearXNG через Docker Compose

Порт 8080 в контейнере проброшен на 8888 только на локальный адрес, как в примере из документации. Если нужен готовый набор с Valkey и прокси, в документации SearXNG есть официальный файл docker-compose.yml с копией.env.example.

  • Docker на сервере.
  • Создайте каталог searxng с папками config и data и положите рядом файл compose.yaml.
  • Напишите config/settings.yml по образцу из следующего раздела: без него контейнер возьмёт настройки по умолчанию.
  • Запустите docker compose up -d и откройте адрес через прокси с паролем.

settings.yml в SearXNG: secret_key, формат JSON и лимитер

Три строки здесь важны. use_default_settings оставляет все стандартные настройки и меняет только перечисленное. secret_key подписывает служебные данные, замените его случайной строкой, например из openssl rand -hex 32. Формат json по умолчанию выключен, а без него ИИ-агент получит отказ при обращении к API. Лимитер SearXNG это защита от ботов для открытого экземпляра, и работает он вместе с Valkey.

Почему SearXNG на VPS получает капчи от поисковиков

Поисковики видят запросы с одного адреса сервера. Если их много или они похожи на автоматические, часть движков временно отвечает капчей или блокирует адрес. В интерфейсе SearXNG такие движки помечаются как недоступные, а выдача становится короче.

  • Не публикуйте экземпляр без пароля.
  • Отключите ненужные движки в настройках: меньше источников, меньше шанс получить капчу.
  • Не гоняйте агентов без пауз.

Домен, пароль и обновления SearXNG

Поставьте перед контейнером Caddy и закройте адрес паролем: блок basic_auth с хэшем из команды caddy hash-password даёт вход по имени и паролю, сертификат Caddy выпустит сам. Если SearXNG нужен ИИ-агентам на этом же сервере, им не нужно ходить через интернет: контейнеры в общей сети Docker обращаются к http://searxng:8080. Обновление такое же, как у других контейнеров: docker compose pull и docker compose up -d.

Вопросы и ответы

Какой порт использует SearXNG в Docker?

Контейнер слушает порт 8080. В примере документации его пробрасывают на 8888 хоста, а наружу публикуют через прокси с HTTPS.

Как включить JSON в SearXNG для ИИ-агентов?

В settings.yml добавьте json в список search.formats рядом с html и перезапустите контейнер. После этого запросы вида /search?q=текст&format=json вернут данные.

Зачем SearXNG нужен Valkey?

Для лимитера: защиты открытого экземпляра от ботов. В личном экземпляре за паролем лимитер выключают, и Valkey не нужен.

Почему в SearXNG пишет, что движок недоступен или показывает капчу?

Поисковики ограничивают запросы с адресов дата-центров. Отключите лишние движки, закройте экземпляр паролем и не отправляйте много запросов подряд.
