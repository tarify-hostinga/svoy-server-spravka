Установка Jenkins на свой сервер: коротко и с данными

Конспект страницы: 6 разделов коротко, данные на 14 октября 2026 и ответы на 5 вопросов. Полный разбор с примерами: Установка Jenkins на свой сервер.

Коротко

Установка Jenkins на свой сервер сводится к образу jenkins/jenkins из Docker Hub: веб-интерфейс открывается на порту 8080, а все настройки и история сборок лежат в каталоге /var/jenkins_home. Jenkins это сервер автоматизации сборок, который запускает ваши проверки и выкладки по расписанию или после каждого коммита. Если нужна более готовая из коробки система, смотрите раздел про TeamCity.

Конспект по разделам

Что выбрать для CI: Jenkins или TeamCity

Оба сервера решают одну задачу: берут код из репозитория, прогоняют сборку и тесты, выкладывают результат. Различаются они подходом. Jenkins стоит брать, когда нужна свобода и вы готовы следить за плагинами.

Сколько памяти и диска нужно Jenkins на VPS

Память Jenkins съедает не сам контроллер, а сборки: каждое задание открывает процессы, и при выполнении на контроллере они борются за ту же память. Порт 50000 нужен только агентам, которые подключаются по протоколу TCP. Агенты через WebSocket обходятся веб-портом, поэтому 50000 можно не открывать.

Установка Jenkins через Docker Compose на Ubuntu

Образ содержит текущий долгосрочный выпуск (LTS), но не содержит Docker CLI: для сборок в контейнерах нужны агенты, где Docker уже стоит. Копии и обновления Jenkins Копируйте весь том jenkins_home: в нём сборки, учётные данные и плагины. Для обновления смените тег образа на новый LTS, но перед этим сделайте копию тома и проверьте совместимость плагинов: именно они чаще всего ломаются при обновлении.

  • Поставьте Docker с плагином Compose.
  • Создайте файл docker-compose.yml ниже и запустите docker compose up -d.
  • Возьмите пароль администратора: docker compose exec jenkins cat /var/jenkins_home/secrets/initialAdminPassword.
  • Откройте интерфейс (первый раз удобно через SSH-туннель на порт 8080), вставьте пароль, поставьте рекомендуемые плагины и создайте своего администратора.

Домен, HTTPS и агенты Jenkins за обратным прокси

Перед интерфейсом ставят обратный прокси, то есть программу, которая принимает HTTPS и передаёт запросы контейнеру. Подойдут Nginx или Caddy; важно передать заголовки X-Forwarded-For и X-Forwarded-Proto, иначе Jenkins покажет предупреждение об ошибке прокси в настройках. Сборки выносят на агентов: отдельные серверы, которые подключаются к контроллеру и выполняют задания.

Установка TeamCity на сервер: сервер и агенты в Docker

TeamCity ставится так же, парой контейнеров: сервер jetbrains/teamcity-server принимает веб-запросы на порту 8111, а сборки выполняют агенты jetbrains/teamcity-agent. Каталог данных вынесите в том, пути указаны на странице образа в Docker Hub. При первом открытии мастер предложит выбрать базу.

Вопросы и ответы

Сколько памяти нужно Jenkins для небольшой команды?

Документация называет минимумом 256 МБ, а для небольшой команды 4 ГБ и более, диск от 50 ГБ. Память растёт от числа одновременных сборок, особенно на самом контроллере.

Где посмотреть пароль администратора после установки Jenkins?

В файле /var/jenkins_home/secrets/initialAdminPassword внутри контейнера и в журнале контейнера между двумя рядами звёздочек при первом запуске.

Зачем Jenkins порт 50000 и нужно ли его открывать?

Он нужен агентам, которые подключаются к контроллеру по TCP. Агентам по WebSocket порт 50000 не нужен, поэтому закрывайте его, если такие агенты не используются.

Как обновить Jenkins в Docker?

Сделать копию тома jenkins_home, выбрать новый тег lts-jdk21, выполнить docker compose pull и docker compose up -d, затем проверить плагины на странице обновлений.

Чем TeamCity отличается от Jenkins при установке на VPS?

TeamCity состоит из сервера на порту 8111 и агентов, больше возможностей уже встроено, лицензия коммерческая с бесплатным уровнем. Jenkins бесплатен, но многое подключается плагинами.
