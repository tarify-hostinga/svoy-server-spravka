Установка Dokploy в Docker на свой сервер: коротко и с данными

Коротко

Главная / Разработка / Dokploy и Dokku Dokploy в Docker ставится одной командой: она разворачивает на сервере панель на порту 3000 и обратный прокси Traefik, а по документации нужно минимум 2 ГБ памяти и 30 ГБ диска. Dokploy выкладывает приложения из Git или из готового образа и поднимает базы данных, а Dokku решает ту же задачу без панели, командой git push. Для Dokploy нужно 2 ГБ памяти и 30 ГБ диска, число ядер документация не называет, берите два.

Конспект по разделам

Чем Dokploy отличается от Dokku и Coolify

Dokploy это панель для выкладки приложений на свой сервер. Вы подключаете репозиторий Git или указываете образ, выбираете способ сборки, задаёте домен, и панель выпускает сертификат и запускает контейнер. Внутри работают Docker, режим Docker Swarm и обратный прокси Traefik, поэтому установщик включает Swarm на хосте.

Сколько ресурсов и какие порты нужны для Dokploy

Эти цифры относятся к самой панели. Приложения, базы данных и сборки образов на том же сервере требуют отдельного запаса памяти и диска. Три ответа, и калькулятор подберёт готовую конфигурацию

Установка Dokploy на Ubuntu: команда и первый запуск

Приложение из нескольких сервисов можно описать обычным compose-файлом и добавить как сервис типа Compose, домены тогда назначаются в соответствующей вкладке панели: Обновляют панель той же командой с ключом: curl -sSL https://dokploy.com/install.sh | sh -s update. Перед обновлением сделайте снимок сервера.

  • Подготовьте чистый сервер и подключитесь к нему по SSH как root.
  • Выполните установку: curl -sSL https://dokploy.com/install.sh | sh.
  • Откройте http://IP-сервера:3000 и создайте учётную запись администратора: пока вы этого не сделали, панель открыта любому.
  • Укажите домен панели в настройках и включите HTTPS, затем закройте порт 3000.

Установка Dokku на Ubuntu и выкладка командой git push

Dokku ставится скриптом bootstrap.sh со страницы установки в документации, версия подставляется в адрес, поэтому берите команду оттуда. После установки добавьте свой публичный ключ и создайте приложение: На своём компьютере в папке проекта добавьте удалённый репозиторий и отправьте код. Dokku сам соберёт образ и запустит контейнер: Готовый образ из Docker Hub можно запустить без исходников командой dokku git:from-image myapp nginx:stable.

Домен, HTTPS и данные Dokploy

Для каждого приложения заведите A-запись на IP сервера или одну подстановочную запись на поддомен. В панели домен добавляют на вкладке приложения: Traefik сам запросит сертификат Let's Encrypt, а в настройках панели тот же прокси можно использовать и для её адреса. Настройки панели хранит каталог /etc/dokploy, а данные приложений лежат в томах Docker.

Вопросы и ответы

Какой сервер нужен для Dokploy по документации?

Минимум 2 ГБ памяти и 30 ГБ диска, число ядер не указано. Проверены Ubuntu, Debian, Fedora и CentOS; порты 80, 443 и 3000 должны быть свободны.

Какой командой ставится и обновляется Dokploy?

Установка: curl -sSL https://dokploy.com/install.sh | sh. Обновление та же команда с ключом: curl -sSL https://dokploy.com/install.sh | sh -s update.

Почему установка Dokploy завершается ошибкой?

Чаще всего заняты порты 80, 443 или 3000: на сервере уже работает Nginx, Apache или другой контейнер. Остановите их или возьмите чистый сервер.

Чем Dokku отличается от Dokploy?

Dokku управляется из консоли и выкладывает приложения командой git push, у него нет веб-панели. Dokploy имеет интерфейс, работает на Docker Swarm и Traefik и умеет выкладывать из Git и из образа.

Как выложить приложение в Dokku через git push?

Добавить ключ SSH командой dokku ssh-keys:add, создать приложение dokku apps:create, добавить удалённый репозиторий dokku и выполнить git push dokku main.
