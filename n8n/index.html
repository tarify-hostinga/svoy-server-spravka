Установка n8n на свой сервер: коротко и с данными

Конспект страницы: 7 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Установка n8n на свой сервер.

Коротко

Установка n8n на свой сервер сводится к одной команде Docker: n8n слушает порт 5678 и хранит сценарии в томе n8n_data. Остальная работа нужна, чтобы n8n жил долго: домен с HTTPS для вебхуков, резервная копия ключа шифрования и вовремя сделанный переход с SQLite на PostgreSQL. Для старта хватит 1 ядра и 2 ГБ памяти.

Конспект по разделам

Где запускать n8n: облако, VPS или свой компьютер

У n8n три способа жить: облачная версия от разработчиков, свой сервер или домашний компьютер. Разница не в функциях, а в том, кто отвечает за работу сценариев ночью. Для рабочих сценариев выбирают сервер: вебхук от CRM или платёжной системы приходит в любое время суток, и n8n должен его принять.

Сколько памяти и ядер нужно n8n

Документация n8n не называет минимальную конфигурацию, зато прямо перечисляет, от чего растёт память: объём JSON и файлов в одном запуске, количество узлов, узел Code, ручные запуски из редактора (n8n копирует данные для интерфейса) и параллельные сценарии. Отсюда практическое правило: ядра нужны для частоты запусков, а память для объёма данных. Сценарий, который раз в час переносит заявку из формы в таблицу, проживёт на младшем сервере.

Установка n8n через Docker на Ubuntu

Флаг --restart unless-stopped поднимет n8n после перезагрузки сервера. Без него сценарии молчат до первого ручного запуска контейнера.

  • Поставьте Docker.
  • Создайте том для данных.
  • Запустите контейнер командой ниже, указав свой часовой пояс: от него зависят узлы расписания.
  • Откройте редактор по адресу http://IP-сервера:5678 и создайте учётную запись владельца.

Домен, HTTPS и вебхуки n8n

Вебхукам n8n нужен постоянный адрес с HTTPS: большинство сервисов не отправят уведомление на голый IP с портом. В официальной инструкции для Docker Compose рядом с n8n ставится Traefik, он сам получает сертификат Let's Encrypt и продлевает его. Если на сервере уже работает другой веб-сервер, вместо Traefik подойдёт Caddy или Nginx с сертификатом от Certbot.

  • Направьте A-запись поддомена, например n8n.example.com, на IP сервера.
  • Оставьте порт n8n только на локальном адресе: 127.0.0.1:5678:5678.
  • Пропишите внешний адрес в переменной N8N_WEBHOOK_URL (с версии 2.30.0; в старых версиях она называлась WEBHOOK_URL ), иначе n8n будет выдавать ссылки на вебхуки с localhost.

Когда переводить n8n на PostgreSQL

По умолчанию n8n хранит сценарии, доступы и историю запусков в SQLite: один файл в томе, никакой настройки. Для одного человека и десятка сценариев этого достаточно. PostgreSQL стоит подключить заранее, если история запусков большая, сценариев много или вы планируете очередь с несколькими исполнителями.

Как обновить n8n и не потерять сценарии

Обновление в Docker это новая версия образа поверх того же тома: docker pull docker.n8n.io/n8nio/n8n, затем остановить и удалить старый контейнер и запустить его заново той же командой. Данные остаются в томе. Перед крупным обновлением сделайте копию тома или снимок сервера: откатиться на снимок быстрее, чем чинить базу.

Вопросы и ответы

Какой сервер нужен для n8n?

Для старта 1 ядро и 2 ГБ памяти. Память добавляют, когда сценарии гоняют файлы или большие ответы API, ядра, когда запусков становится много.

Как обновить n8n на сервере, если он стоит в Docker?

Скачать новый образ, пересоздать контейнер той же командой с тем же томом n8n_data. Перед этим сделать снимок сервера.

Можно ли поставить n8n на Windows вместо сервера?

Да, через Docker Desktop или npm, но сценарии работают только пока включён компьютер, а вебхукам нужен внешний адрес.

Где n8n хранит пароли от подключённых сервисов?

В своей базе в зашифрованном виде. Ключ шифрования лежит в каталоге /home/node/.n8n, поэтому этот каталог обязательно сохранять.
