Сложность не в установке, а в перекодировании: на обычном VPS нет видеокарты, и всё, что клиент не умеет играть сам, ложится на процессор. Конспект по разделам

Что такое Jellyfin и чем он отличается от Emby и Plex

Jellyfin это медиасервер с открытым кодом для вашей собственной коллекции: оцифрованные фильмы и сериалы, домашнее видео, музыка, книги. Он раскладывает файлы по библиотекам, подтягивает обложки и описания, а смотреть можно в браузере, на телевизоре и в приложениях для телефонов. Проект вырос из Emby 3.5.2: в декабре 2018 года Emby закрыл код четвёртой версии, и часть сообщества сделала свободную ветку.

Какое железо советует документация Jellyfin

Общее для всех вариантов: SSD на 100 ГБ под систему, данные Jellyfin и кэш перекодирования, гигабитная сеть и от 20 Мбит/с исходящего канала для просмотра вне дома. Видеокарты AMD документация для Jellyfin не советует.

Jellyfin на VPS без видеокарты: что будет работать

На облачном сервере без GPU работает всё, кроме тяжёлого перекодирования. Если телевизор или приложение умеет играть файл в исходном формате, Jellyfin отдаёт его как есть, и сервер почти не нагружен. Перекодирование включается, когда клиент не понимает кодек или субтитры приходится вшивать в картинку.

  • Держите медиатеку в распространённых форматах, например H.264 со звуком AAC: их понимают почти все клиенты.
  • Используйте внешние текстовые субтитры (SRT) вместо графических, которые требуют вшивания.
  • Ограничьте битрейт для удалённых зрителей в панели, чтобы перекодирование не съедало процессор.

Установка Jellyfin через Docker Compose

Порт 7359/UDP нужен только для поиска сервера в локальной сети, на VPS его не открывают. Обновление: docker compose pull и docker compose up -d, настройки остаются в томе config.

  • Положите медиатеку в /srv/media и выдайте права пользователю с UID 1000.
  • Запустите docker compose up -d и откройте мастер настройки на порту 8096.
  • Создайте администратора и добавьте библиотеки: фильмы, сериалы, музыка, каждая в своей папке.
  • Подключите домен через обратный прокси Caddy или Nginx: встроенный HTTPS на порту 8920 по умолчанию выключен.

Аппаратное ускорение Jellyfin в Docker

Jellyfin перекодирует видео своей сборкой jellyfin-ffmpeg, она уже есть в официальных образах. Поддерживаемые методы: Intel Quick Sync (QSV), NVIDIA NVENC, AMD AMF, VA-API на Linux, VideoToolbox на macOS и Rockchip RKMPP. В Docker видеокарту нужно передать контейнеру: для Intel и AMD это устройство /dev/dri, для NVIDIA установленный на хосте NVIDIA Container Toolkit.

Вопросы и ответы

Нужна ли видеокарта для Jellyfin на VPS?

Для прямого воспроизведения нет. Видеокарта нужна, когда клиенты не поддерживают формат файлов и сервер должен перекодировать 4K или несколько потоков одновременно.

Чем Jellyfin отличается от Emby?

Jellyfin вырос из открытого кода Emby 3.5.2 и полностью бесплатен. Emby закрыл код с четвёртой версии, а аппаратное перекодирование в нём входит в платную подписку Emby Premiere.

Какие порты использует Jellyfin в Docker?

8096/TCP для веб-интерфейса, 8920/TCP для встроенного HTTPS, если его включить, и 7359/UDP для поиска сервера в локальной сети.

Где Jellyfin хранит настройки и как их сохранить?

В томе /config: там база, пользователи и метаданные. Кэш в /cache можно не сохранять, а медиатеку копируйте отдельно.
