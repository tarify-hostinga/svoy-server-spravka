Коротко

Главная / Self-hosted / Self hosted Jira Self hosted Jira в виде Data Center доживает свой срок: Atlassian перестала продавать его новым клиентам 30 марта 2026 года, а 28 марта 2029 года подписки истекут и продукт станет доступен только для чтения. Поэтому под «своей Jira» сейчас понимают открытый трекер задач на собственном сервере. Для Scrum-команды смотрите Plane или OpenProject, для проектов со сроками и трудозатратами OpenProject или Redmine.

Конспект по разделам

Можно ли держать Jira на своём сервере после 2026 года

По официальной странице Atlassian о завершении Data Center график такой: До конца срока Atlassian обещает поддержку, исправления критических уязвимостей и инструменты переноса в облако. После него у Jira останется только облачная версия, а значит, данные задач уйдут к Atlassian. Кто хочет держать трекер у себя, выбирает замену сейчас.

Какой self hosted таск трекер выбрать вместо Jira

Два ответа: как команда ведёт работу и какая лицензия допустима Самая частая ошибка при переезде: переносить в новый трекер все поля и схемы Jira как есть. Сначала выпишите, какие поля и статусы команда действительно заполняет, и настройте только их.

Перенос задач из Jira в открытый трекер

REST API Jira Data Center работает до самого конца срока, и это главный инструмент переноса: через него забирают задачи вместе с историей изменений, комментариями и вложениями, чего не даёт выгрузка CSV. Скрипт переноса стоит запускать несколько раз на копии, пока результат не устроит команду, и только потом переключать людей на новый трекер. Отдельно решите судьбу интеграций: вебхуки в CI, связи с репозиториями и ботами в мессенджерах.

  • Выгрузите данные из Jira: задачи, комментарии, вложения и пользователей.
  • Проверьте импорт выбранного трекера: у части есть готовый импорт из Jira, у остальных импорт CSV или API.
  • Сопоставьте статусы и типы задач, прежде чем запускать перенос, и проверьте его на одном проекте.
  • Оставьте старую Jira в режиме чтения на время перехода, чтобы ссылки на старые задачи не потерялись.

Self hosted трекер, MCP и API для ИИ-агентов

ИИ-ассистенты подключаются к трекерам по протоколу MCP. Для Jira и Confluence сообщество поддерживает открытый сервер mcp-atlassian под лицензией MIT. У открытых замен Jira есть REST API, поэтому для них MCP-сервер собирается на основе API или уже есть в каталогах.

Вопросы и ответы

Можно ли ещё купить Jira Data Center для своего сервера?

Новым клиентам нет: продажи остановлены 30 марта 2026 года. Текущие клиенты могут продлевать подписки до 30 марта 2028 года, а 28 марта 2029 года продукт перейдёт в режим только для чтения.

Какая открытая замена Jira ближе всего по функциям?

По набору функций для больших проектов ближе всех OpenProject: Scrum, Kanban, сроки и учёт времени. Если допустим закрытый продукт, похожую гибкость даёт YouTrack.

Есть ли MCP-сервер для своей Jira?

Да, открытый mcp-atlassian от сообщества под лицензией MIT подключает ИИ-ассистентов к Jira и Confluence. Для открытых трекеров MCP-серверы строят поверх их REST API.
