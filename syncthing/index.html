Конспект по разделам

Зачем Syncthing узел на VPS, если сервер ему не нужен

Syncthing синхронизирует папки между устройствами напрямую, без облака посередине. Данные передаются зашифрованными всегда, а каждое устройство само решает, с кем делиться какой папкой. У прямой схемы одна слабость: файл, изменённый на ноутбуке, дойдёт до телефона только когда оба включены одновременно.

Какие порты открыть для Syncthing на сервере

Если порт 22000 закрыт, устройства всё равно найдут друг друга, но трафик пойдёт через публичные ретрансляторы, которые держат добровольцы. Это медленнее, поэтому на сервере порт лучше открыть в файрволе. Узел на сервере хранит полную копию папок, поэтому главное здесь диск

Установка Syncthing через Docker Compose

Разработчики советуют сеть host: в режиме bridge Syncthing видит только внутренний адрес контейнера. Файл compose.yaml: Без консоли Syncthing ставится из маркетплейса: на 14 октября 2026 года его выбрали 96 раз. Почему такой узел удобнее держать в облаке, а не дома, разобрано на странице домашний сервер или облако.

  • Запустите docker compose up -d.
  • Откройте панель через SSH-туннель: ssh -L 8384:127.0.0.1:8384 user@IP-сервера, затем http://localhost:8384 у себя в браузере.
  • Задайте логин и пароль панели и скопируйте ID устройства.
  • Добавьте ID на ноутбуке и телефоне, подтвердите на сервере и поделитесь папками.

Недоверенный узел: Syncthing хранит на VPS только шифр

Папку можно отдать серверу как «недоверенному» устройству: при общем доступе задаётся пароль, и на VPS попадают только зашифрованные данные. Другие ваши устройства с тем же паролем синхронизируются через сервер, даже если первое устройство выключено. Функция пока в статусе бета Документация Syncthing помечает зашифрованные устройства как тестовую функцию.

Вопросы и ответы

Нужен ли Syncthing центральный сервер?

Нет, устройства обмениваются данными напрямую. Сервер добавляют, чтобы всегда был онлайн-узел и изменения доходили, даже когда остальные устройства выключены.

Заменяет ли Syncthing резервную копию?

Нет. Удаление или порча файла на одном устройстве уйдёт на все. Включите версионирование файлов в настройках папки и держите отдельную копию.

Почему Syncthing в Docker не находит устройства в локальной сети?

В режиме сети bridge контейнер видит только свой внутренний адрес. Используйте network_mode: host, как советует README образа, или пропишите адреса устройств вручную.

Сколько памяти нужно Syncthing на VPS?

Для пары устройств и десятков гигабайт хватит 1 ГБ. Память и процессор растут с числом файлов, особенно при первом сканировании.
