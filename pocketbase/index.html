PocketBase на своём сервере: бинарник или Docker, коротко и с данными

Конспект страницы: 7 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: PocketBase на своём сервере: бинарник или Docker.

Коротко

Главная / Разработка / PocketBase PocketBase в Docker или без него это один исполняемый файл с базой SQLite, API, входом пользователей, хранилищем файлов и админ-панелью. Официального образа Docker у проекта нет, но запускается он и просто бинарником с командой serve. Для небольших проектов такой бэкенд заменяет Firebase и Supabase и умещается на самый младший сервер.

Конспект по разделам

Что заменяет PocketBase и когда его хватает

PocketBase это бэкенд в одном файле на языке Go с открытым кодом под лицензией MIT. Внутри: база SQLite, REST API, подписки на изменения в реальном времени, регистрация и вход, загрузка файлов, панель администратора и расширения на JavaScript или Go. Установка сводится к тому, чтобы положить файл на сервер и запустить.

Сколько памяти нужно PocketBase на VPS

Внешней базы не требуется, поэтому процесс скромен. Для старта хватит 1 ядра и 1 ГБ: MSK Ultra 15 в Таймвеб Клауд (1 vCPU, 1 ГБ, 15 ГБ NVMe) стоит 1 920 ₽ в месяц на 14 октября 2026. Диск растёт от файлов пользователей и истории запросов.

Установка PocketBase на Ubuntu без Docker

Файл кладут в /lib/systemd/system/pocketbase.service и включают командами systemctl enable pocketbase и systemctl start pocketbase. Это вариант из документации проекта, запуск от root упрощён для примера. Для рабочего сервера заведите отдельного пользователя.

  • Скачайте архив под Linux со страницы релизов PocketBase на GitHub и распакуйте в рабочий каталог, например /root/pb.
  • Запустите./pocketbase serve: без домена он слушает локальный адрес на порту 8090.
  • Создайте суперпользователя командой./pocketbase superuser create почта пароль или по ссылке установщика из журнала.
  • Оформите службу systemd, чтобы PocketBase поднимался после перезагрузки и перезапускался при сбое.

PocketBase в Docker: Dockerfile и том pb_data

Официального образа у PocketBase нет, документация предлагает собрать минимальный образ самим. Данные нужно вынести в том, подключённый к /pb/pb_data, иначе при пересоздании контейнера база пропадёт. Номер версии 0.40.5 взят из документации на 15 октября 2026, подставьте актуальный с GitHub.

Домен и HTTPS для PocketBase

У PocketBase есть встроенный HTTPS: команда./pocketbase serve yourdomain.com сама получает сертификат Let's Encrypt и продлевает его. Для этого свободны порты 80 и 443, под root они доступны, под обычным пользователем нужны права на привязку, например setcap. Если на сервере уже работает другой сайт, ставьте перед PocketBase обратный прокси, то есть программу, которая принимает HTTPS и передаёт запросы дальше: Caddy или Nginx.

Копии и защита PocketBase: pb_data, S3 и ограничитель запросов

Копию делают копированием каталога pb_data, пока приложение остановлено, чтобы запись не прервалась. Есть и встроенные копии в панели: настройки, раздел Backups. Они сохраняют ZIP-архив с данными и файлами локально или в S3-совместимое хранилище.

  • Почта: по умолчанию письма идут через sendmail, и в рабочей среде они попадают в спам.
  • Ограничитель запросов появился в панели с версии 0.23: включите его, чтобы защитить вход и создание записей.
  • Адреса администраторов: можно ограничить вход суперпользователей списком IP.

Вопросы и ответы

Есть ли официальный образ PocketBase для Docker?

Нет. Документация проекта даёт пример минимального Dockerfile на основе Alpine: он скачивает бинарник нужной версии. Данные хранятся в каталоге /pb/pb_data, его подключают томом.

Можно ли запустить PocketBase на бесплатном хостинге?

Для постоянной работы нужен сервер с возможностью запускать собственный процесс и хранить файлы. Подходит младший VPS, а виртуальный хостинг сайтов с PHP обычно не подходит.

Как перенести PocketBase на другой VPS?

Остановите приложение, скопируйте каталог pb_data вместе с pb_migrations и pb_hooks и бинарник той же версии, затем запустите на новом сервере. База SQLite и файлы лежат внутри pb_data.

Чем PocketBase отличается от Supabase?

PocketBase это один файл с SQLite для небольших проектов, Supabase набор сервисов вокруг PostgreSQL. Первый ставится за минуту, второй требует от 4 ГБ памяти.
