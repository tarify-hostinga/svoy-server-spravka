Установка Grafana на свой сервер: коротко и с данными

Конспект страницы: 6 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Установка Grafana на свой сервер.

Коротко

Установка Grafana на свой сервер занимает один compose-файл: панель слушает порт 3000, а её настройки лежат в каталоге /var/lib/grafana. Сама Grafana метрики не хранит, она рисует графики по данным из Prometheus, Loki, баз данных и других источников, поэтому сервер под неё нужен небольшой. Для самой Grafana достаточно 1 ядра и 1 ГБ памяти, больше потребуют хранилища рядом.

Конспект по разделам

Что показывает Grafana и откуда берёт данные

Grafana запрашивает данные у источников в момент, когда вы открываете дашборд, и сама их не копит. Поэтому её можно поставить отдельно от хранилищ, а на небольшом проекте проще держать всё рядом на одном сервере.

Сколько памяти и ядер нужно Grafana на сервере

В документации Grafana названы минимумы: 512 МБ памяти и 1 ядро. Это нижняя граница для панели, которую открывают несколько человек. Нагрузку создают не сами графики, а запросы к источникам: длинные периоды, десятки панелей на экране и автообновление каждые несколько секунд.

Установка Grafana через Docker Compose на Ubuntu

Готовый сервер с уже установленной Grafana можно взять в маркетплейсе Таймвеб Клауд (37 установок на 14 октября 2026). Если нужен контроль над версией и настройками, поставьте её сами. Переменная с паролем срабатывает только при первом запуске, когда Grafana создаёт свою базу.

  • Поставьте Docker Engine с плагином Compose: дальше везде используется команда docker compose.
  • Создайте каталог grafana и в нём файл.env со строкой GRAFANA_PASSWORD=ваш_пароль.
  • Сохраните compose-файл из примера ниже рядом с.env.
  • Запустите docker compose up -d и проверьте docker compose logs grafana.

Домен и HTTPS для Grafana за Caddy

Чтобы открывать Grafana по адресу вида grafana.example.com, направьте A-запись поддомена на IP сервера и поставьте перед панелью обратный прокси, то есть программу, которая принимает HTTPS и передаёт запросы контейнеру. Для одной панели хватит двух строк в Caddyfile: Caddy сам получит сертификат и будет его продлевать, подробности в разборе установки Caddy. С Nginx понадобятся заголовки Upgrade для WebSocket, который использует живое обновление графиков.

Что копировать и как обновлять Grafana

Дашборды, пользователи, источники данных и правила алертов лежат в базе grafana.db внутри тома grafana_data. Метрик и логов там нет, они остаются в Prometheus и Loki. Поэтому резервная копия Grafana небольшая: достаточно копии тома или выгрузки дашбордов в JSON, которую удобно хранить в Git рядом с compose-файлом.

Вопросы и ответы

Какой сервер нужен для Grafana?

Документация называет минимум 512 МБ памяти и 1 ядро. Для панели вместе с Prometheus на одном сервере берите 2-4 ГБ памяти и диск под метрики.

Чем Grafana отличается от Prometheus?

Prometheus собирает метрики и хранит их, Grafana только показывает данные из него и из других источников. Одна без другой для мониторинга не работает.

Нужна ли Grafana, если уже стоит Zabbix?

Не обязательно: у Zabbix есть собственные графики. Grafana подключают, когда хотят собрать на одном экране данные Zabbix, Prometheus и логи из Loki.

Можно ли держать Grafana и Prometheus на одном сервере?

Да, для небольшого числа серверов под наблюдением это обычная схема. Когда Prometheus разрастается, его выносят на отдельную машину, а Grafana остаётся прежней.
