Коротко

Хостинг для Laravel должен давать PHP не ниже 8.3 (по документации Laravel 13.x на 15 октября 2026), SSH, Composer и возможность направить корень сайта в каталог public. Всё это есть на VPS: ставите Nginx, PHP-FPM и базу, а очереди и расписание запускаете через systemd и cron. Для Laravel берите VPS с Ubuntu, Nginx и PHP-FPM: так работают очереди, расписание и свои расширения PHP.

Установка Laravel на Ubuntu: PHP-FPM, Composer и Nginx

На Ubuntu 24.04 PHP 8.3 есть в штатных репозиториях. На 22.04 версия ниже, там понадобится сторонний репозиторий с новыми сборками PHP. Команда php artisan optimize собирает кэш настроек, маршрутов и шаблонов, её запускают при каждом обновлении.

  • Поставьте пакеты.
  • Создайте проект через Composer в каталоге сайта.
  • Настройте.env.
  • Выдайте права пользователю веб-сервера на два каталога и выполните миграции.

Очереди и расписание Laravel на сервере

Письма, отчёты и обработка файлов выносят в очередь, а запуск задач по времени отдают планировщику Laravel. Оба механизма работают отдельно от Nginx и требуют своей настройки. Планировщику хватает одной строки в crontab, которая раз в минуту вызывает schedule:run: Исполнитель очереди, команду php artisan queue:work, оформляют службой systemd с параметром Restart=always.

Laravel в Docker: Sail для разработки и свой образ для сервера

Laravel Sail рассчитан на локальную разработку. На сервер обычно кладут собственную сборку, и вариантов два: База и Redis в обоих случаях живут отдельными контейнерами с томами, а storage тоже выносят в том, иначе загруженные файлы пропадут вместе с контейнером. Для платформы деплоя из Git подходит тот же образ, но базу берите управляемую, а файлы кладите в S3.

  • Два контейнера: php-fpm с кодом и Nginx, которые делят каталог public.
  • Один контейнер с FrankenPHP: документация Laravel называет этот сервер приложений на Go вариантом для запуска, команда frankenphp php-server -r public/.

Вопросы и ответы

Какая версия PHP нужна для Laravel на хостинге?

По документации Laravel 13.x на 15 октября 2026 нужен PHP 8.3 и выше с набором расширений. Для другой версии фреймворка смотрите её страницу требований.

Почему Laravel на сервере показывает 403 или 500 после установки?

Три частые причины: корень сайта указывает не на public, у веб-сервера нет прав на storage и bootstrap/cache или не создан файл.env с ключом приложения.

Как запустить Laravel на сервере без Docker?

Поставить Nginx, PHP-FPM и Composer, создать проект, настроить.env, выдать права на два каталога, выполнить migrate и optimize и подключить Nginx с корнем в public.

Нужен ли Laravel Forge, чтобы развернуть Laravel на VPS?

Нет. По описанию в документации Forge настраивает Nginx, MySQL и Redis на вашем сервере, но то же делается вручную по шагам выше.

Как проверить, что Laravel на сервере жив?

В проект встроен адрес /up: он отвечает кодом 200, если приложение запустилось без ошибок. Его удобно отдать монитору доступности.
