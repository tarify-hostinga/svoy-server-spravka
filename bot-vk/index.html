Коротко

Хостинг для бота ВКонтакте нужен, чтобы бот отвечал и тогда, когда ваш компьютер выключен. Бот на Bots Long Poll API сам забирает события сообщества, и ему хватит любого VPS без домена; для Callback API нужен публичный адрес, который отвечает строкой ok на каждое уведомление. Для одного сообщества проще всего Bots Long Poll API на младшем VPS: ни домена, ни сертификата.

Long Poll или Callback API: как бот ВКонтакте получает события

События в обоих способах одинаковые по структуре, поэтому бот можно перевести с одного на другой без переписывания логики. Почему постоянный процесс плохо живёт на хостинге сайтов, объяснено в обзоре аренда сервера для бота.

Ответ failed означает, что сессию надо обновить: при failed 1 берут новый ts из ответа, при failed 2 заново получают key, при failed 3 запрашивают и key, и ts. Библиотеки для ботов, например vkbottle на Python, делают это сами, ваша задача только держать процесс запущенным.

  • Ждите события запросом с параметром wait.

Callback API ВКонтакте: подтверждение адреса и ответ ok

При добавлении сервера ВКонтакте присылает запрос на подтверждение, и адрес должен вернуть строку подтверждения из настроек сообщества или из метода groups.getCallbackConfirmationCode. Строка время от времени меняется, при смене сервера её надо взять заново. Отвечайте «ok» сразу, а долгую работу вроде запросов к нейросети делайте после ответа или в очереди.

  • На каждое уведомление сервер отвечает строкой ok и статусом HTTP 200.
  • Поле «Секретный ключ» приходит в каждом уведомлении как secret: проверяйте его и отбрасывайте запросы без него.
  • Повторные попытки помечены заголовком X-Retry-Counter, а ответом 410, 429 или 503 с Retry-After можно попросить повторить позже, но не дальше чем через 3 часа.
  • К одному сообществу можно подключить до 10 серверов со своим набором событий и версией API.

Вопросы и ответы

Почему бот ВКонтакте работает, только когда включён компьютер?

Потому что сам процесс бота запущен на компьютере: выключили его, и события сообщества некому забирать. Перенесите бота на VPS и запустите службой с автоперезапуском.

Что делать, если Callback API ВКонтакте перестал присылать события?

Проверьте, что адрес отвечает строкой ok со статусом 200: после нескольких ошибок подряд ВКонтакте временно прекращает отправку. Затем убедитесь, что строка подтверждения не сменилась.

Можно ли разместить бота ВКонтакте на обычном хостинге сайтов?

Да, если бот работает через Callback API: каждое событие приходит отдельным HTTP-запросом, и PHP-скрипт успевает ответить ok. Боту на Long Poll нужен постоянный процесс, то есть VPS.
