Свой сервер для Enshrouded: коротко и с данными

Конспект страницы: 6 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Свой сервер для Enshrouded.

Коротко

Сервер для Enshrouded Keen Games выпускает только под Windows: SteamCMD скачивает enshrouded_server.exe под app 2278520 без входа в Steam. На Linux-VPS его запускают через слой совместимости Proton в Docker-образе сообщества, и сервер держит до 16 игроков. Для компании до четырёх человек начните с 2 ядер и 4-6 ГБ на Linux с Docker-образом.

Конспект по разделам

Есть ли сервер Enshrouded под Linux

Родной Linux-сборки нет: в SteamCMD лежит только Windows-программа enshrouded_server.exe. Отсюда два пути. Windows доступен среди готовых образов при создании VPS у Таймвеб Клауд наряду с Ubuntu и Debian, так что выбор не ограничен провайдером.

Сколько ресурсов нужно серверу Enshrouded

Нагрузку определяют компания и мир: каждый игрок, ушедший в свой биом, заставляет сервер держать в работе отдельную область карты, а большие базы со множеством построек добавляют памяти. Слой Proton или сама Windows забирают свою долю сверху. Система, компания и мир: калькулятор подберёт конфигурацию

Установка сервера Enshrouded в Docker на Ubuntu

Образ sknnr/enshrouded-dedicated-server при старте скачивает сервер через SteamCMD с анонимным входом и запускает его в GE-Proton. Сохранения хранятся в отдельном томе и переживают пересоздание контейнера. Обновление игры сводится к перезапуску контейнера: образ проверяет версию при каждом старте.

Пароли, группы и слоты в enshrouded_server.json

Сервер настраивается файлом enshrouded_server.json. Главные поля: Docker-образ подставляет пароль из SERVER_PASSWORD во все группы сразу. Если нужны разные права, включите EXTERNAL_CONFIG=1 и подключите свой файл enshrouded_server.json: тогда образ берёт настройки из него.

  • name: имя сервера в списке;
  • slotCount: число мест, не больше 16;
  • userGroups: группы игроков, у каждой свой пароль и свой набор прав.

Как друзья заходят на сервер Enshrouded и где лежит мир

Друзья находят сервер по имени в списке серверов игры и вводят пароль своей группы. Мир хранится в папке savegame рядом с сервером, в Docker это том enshrouded-data. Архивируйте его перед каждым обновлением игры и уносите копии с VPS, например на сервер для бэкапов.

Вопросы и ответы

Сколько стоит сервер Enshrouded в месяц?

На 14 октября 2026 конфигурация с 2 ядрами и 4 ГБ стоит 5 480 ₽ в месяц, с 4 ядрами и 8 ГБ для полной компании или Windows стоит 10 120 ₽. Оплата почасовая.

Можно ли поставить сервер Enshrouded на Windows VPS?

Да, это родная платформа сервера. Создайте VPS из образа Windows, поставьте SteamCMD, скачайте app 2278520 и запускайте enshrouded_server.exe, настройки в том же enshrouded_server.json.

Сколько игроков вмещает сервер Enshrouded?

До 16: это предел параметра slotCount. Для компании из четырёх-пяти человек ставьте меньше, чтобы на сервер не зашли лишние.

Почему сервер Enshrouded открыт для всех?

Не задан пароль. Docker-образ прямо предупреждает в журнале, что без SERVER_PASSWORD сервер будет публичным. Задайте пароль и перезапустите контейнер.
