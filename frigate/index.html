Установка Frigate на свой сервер: коротко и с данными

Конспект страницы: 7 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Установка Frigate на свой сервер.

Коротко

Главная / Self-hosted / Frigate Установка Frigate делается одним контейнером Docker: образ ghcr.io/blakeblackshear/frigate:stable принимает видео камер по RTSP, ищет в кадре людей и машины нейросетью и записывает нужные фрагменты. На VPS без видеокарты и без встроенной графики Intel он будет работать на процессоре, а документация проекта такой режим не рекомендует, поэтому серьёзную установку делают на домашнем мини-ПК. Frigate нужен детектор: Intel с графикой, видеокарта Nvidia или ускоритель.

Конспект по разделам

Что такое Frigate и подойдёт ли для него VPS

Frigate это видеорегистратор (NVR) с открытым кодом и распознаванием объектов. Вместо записи всего подряд он ищет в кадре человека, машину или животное и сохраняет события: клип, снимок и уведомление. Он умеет передавать события в Home Assistant и по MQTT.

Какое железо нужно Frigate: процессор, детектор и память

Документация рекомендует сервер на процессоре Intel с инструкциями AVX и AVX2, способном работать с Debian. Среди готовых мини-ПК она сейчас выделяет Beelink EQ13 на процессоре N100. Расчёт числа камер на разных процессорах приведён в таблице самой документации.

Установка Frigate в Docker Compose по шагам

Параметр shm_size важен: Docker по умолчанию даёт общей памяти всего 64 МБ, а Frigate для двух камер с детекцией 720p по документации нужно около 210 МБ. Формулу для своих разрешений ищите в разделе установки документации. Для Proxmox действует правило: у виртуальной машины отключите ballooning, особенно при передаче видеокарты.

  • Подготовьте Debian или Ubuntu с Docker и Compose, создайте каталоги config и storage.
  • Положите compose.yaml из примера, поправив пути и устройства под ваше железо.
  • Создайте минимальный config.yml из следующего раздела и запустите docker compose up -d.
  • Откройте интерфейс на порту 8971 и найдите данные для первого входа в журнале контейнера: docker logs frigate.

Первая настройка Frigate: config.yml с камерой и двумя потоками

Камера отдаёт два потока. Лёгкий дополнительный поток (в примере 102) нужен детектору, он смотрит кадры и не нагружает процессор. Основной поток высокого качества (101) идёт на запись.

Порт 8971, пароль и безопасный доступ к Frigate

Основной интерфейс Frigate открыт на порту 8971 и требует вход. Порт 5000 в документации назван внутренним и без авторизации, поэтому в compose-файле его не публикуют, а если он нужен соседнему контейнеру, оставляют только внутри сети Docker.

  • Не выставляйте камеры в интернет.
  • Поставьте перед 8971 прокси вроде Caddy и закройте порт файрволом.
  • Смените пароли камер с заводских: пароль от камеры записан в конфиге открытым текстом, храните файл с правами только для владельца.

Где хранить записи Frigate и как считать диск

Записи Frigate лежат в каталоге, примонтированном как /media/frigate. Объём определяется битрейтом основного потока и сроком хранения, а режим записи только по событиям уменьшает его в зависимости от сцены. Формула и калькулятор: расчёт места на странице про сервер для видеонаблюдения.

Вопросы и ответы

Какой образ Docker использовать для установки Frigate?

Образ ghcr.io/blakeblackshear/frigate с тегом stable: так написано в примере установки в документации. Для своей версии подставьте номер вместо stable.

Можно ли запустить Frigate на VPS без видеокарты?

Запустить можно, но документация не рекомендует детекцию только на процессоре. Для нескольких камер лучше мини-ПК с графикой Intel или видеокартой, а VPS оставить для доступа и копий.

Нужен ли Coral для Frigate в 2026 году?

Документация пишет, что Coral больше не рекомендован для новых установок, кроме случаев с низким энергопотреблением. Для новых систем смотрят на OpenVINO, Hailo или видеокарту Nvidia.

На каком порту открывается интерфейс Frigate?

На 8971 с запросом пароля. Порт 5000 работает без авторизации, поэтому наружу его не публикуют.
