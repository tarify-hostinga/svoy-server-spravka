Установка ComfyUI на сервер с видеокартой: коротко и с данными

Конспект страницы: 6 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Установка ComfyUI на сервер с видеокартой.

Коротко

Установка ComfyUI на сервер занимает несколько команд: клонировать репозиторий, поставить PyTorch под свою видеокарту, зависимости и запустить main.py. Интерфейс откроется на порту 8188, но только для самого сервера: чтобы зайти из браузера, нужен флаг --listen и обязательно пароль, своего входа у ComfyUI нет. ComfyUI ставится в виртуальное окружение Python одной последовательностью команд.

Конспект по разделам

Что такое ComfyUI и кому он нужен

ComfyUI это интерфейс для генеративных моделей, где процесс собирается из узлов: загрузка модели, текст запроса, семплер, декодер, сохранение. Схему можно сохранить в JSON и повторить один в один, поэтому ComfyUI выбирают для повторяемой работы и пакетной генерации. Новые открытые модели появляются в ComfyUI раньше, чем в других интерфейсах.

Где запускать ComfyUI: свой ПК или GPU-сервер

Разработчики выпускают настольное приложение, переносную сборку для Windows и платное облако Comfy Cloud. На сервер ComfyUI ставится вручную или через comfy-cli. По README он запускает даже крупные модели на 4 ГБ видеопамяти и 8 ГБ оперативной, подгружая веса по частям, но скорость при этом падает.

ComfyUI-Manager: установка узлов и чем это опасно

ComfyUI-Manager ставит, обновляет и отключает сторонние узлы. В свежих версиях он включается флагом запуска: Каждый сторонний узел это код на Python, который выполняется с правами процесса ComfyUI. Ставьте узлы из реестра Comfy Registry и популярных репозиториев, запускайте ComfyUI от отдельного пользователя без sudo и делайте снимок сервера перед массовым обновлением узлов.

Как открыть ComfyUI из интернета с паролем

По умолчанию ComfyUI слушает только 127.0.0.1. Флаг --listen без адреса открывает его на всех интерфейсах сервера, флаги --tls-keyfile и --tls-certfile включают HTTPS, но README предлагает для них самоподписанный сертификат, который браузер встретит предупреждением. Логина и пароля в ComfyUI нет совсем.

Вопросы и ответы

Как установить ComfyUI-Manager в новой версии ComfyUI?

Поставить зависимости из manager_requirements.txt и запускать ComfyUI с флагом --enable-manager. Старый интерфейс менеджера включает флаг --enable-manager-legacy-ui.

Какая версия Python нужна для ComfyUI?

Разработчики рекомендуют Python 3.13. Версия 3.14 работает, но часть сторонних узлов на ней ломается, а при проблемах с зависимостями узлов советуют 3.12.

Можно ли запустить ComfyUI без видеокарты?

Да, с флагом --cpu, но README прямо называет этот режим медленным. Для картинок терпимо на пробу, для FLUX и видео нужен GPU.

Есть ли у ComfyUI официальный Docker-образ?

В README официальные способы такие: настольное приложение, переносная сборка, comfy-cli и ручная установка. Docker-образы делает сообщество, например профиль comfy в репозитории AbdBarho.
