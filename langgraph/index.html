Установка LangGraph на свой сервер: коротко и с данными

Конспект страницы: 6 разделов коротко, данные на 14 октября 2026 и ответы на 3 вопроса. Полный разбор с примерами: Установка LangGraph на свой сервер.

Коротко

Установка LangGraph на сервер бывает двух видов: библиотека внутри вашего Python-сервиса или Agent Server, который команда langgraph build упаковывает в Docker-образ. Agent Server нужны PostgreSQL и Redis, а в проде ещё ключ LangSmith и выход в интернет для проверки лицензии. Для своего продукта без лицензионных ключей встраивайте LangGraph в сервис на FastAPI.

Конспект по разделам

Два способа запустить LangGraph на VPS

LangGraph это фреймворк для агентов в виде графа: шаги, переходы, состояние и паузы для проверки человеком. На сервер его ставят одним из двух способов. Первый путь подходит, когда граф вызывается из одного приложения.

Команды langgraph dev, build и dockerfile

Утилита ставится командой pip install langgraph-cli и требует Python 3.11 или новее. Настройки проекта лежат в langgraph.json. Версию Python в образе задаёт поле python_version: допустимы 3.11, 3.12 и 3.13, по умолчанию 3.11.

  • langgraph dev: лёгкий сервер для разработки без Docker, по умолчанию на порту 2024, состояние хранится в локальной папке.
  • langgraph build -t my-image: собирает Docker-образ API-сервера на базе langchain/langgraph-api.
  • langgraph dockerfile: выводит Dockerfile по вашему конфигу, если сборку нужно настроить вручную.
  • langgraph up: запускает сервер локально в Docker вместе с базой.

Docker Compose для LangGraph Agent Server

PostgreSQL хранит ассистентов, потоки, запуски, состояние графа и очередь фоновых задач. Redis работает брокером, через который сервер стримит ответы фоновых запусков. Чекпойнты можно вынести в MongoDB, но PostgreSQL всё равно остаётся обязательным.

  • Соберите образ: langgraph build -t my-agent.
  • Создайте.env с LANGSMITH_API_KEY и ключами моделей.

Вопросы и ответы

Нужен ли LangGraph ключ LangSmith на своём сервере?

Для Agent Server да: он стартует с LANGSMITH_API_KEY или лицензионным ключом. Если LangGraph работает как библиотека внутри вашего сервиса, ключ платформы не нужен.

Чем langgraph dev отличается от langgraph up?

langgraph dev запускает лёгкий сервер без Docker с перезагрузкой кода и состоянием в локальной папке. langgraph up поднимает API-сервер в Docker вместе с базой, ближе к тому, что будет на сервере.

Можно ли хранить состояние LangGraph в MongoDB?

Чекпойнты можно: в langgraph.json задаётся бэкенд mongo. Остальные данные Agent Server всё равно держит в PostgreSQL.
