Установка Redmine на свой сервер: коротко и с данными

Конспект страницы: 6 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Установка Redmine на свой сервер.

Коротко

Установка Redmine на свой сервер проще всего через официальный образ Docker: приложение слушает порт 3000, база PostgreSQL работает рядом. Redmine это классический трекер задач на Ruby on Rails с лицензией GPL-2.0, ролями, учётом времени и сотнями плагинов. Для команды до 20 человек хватит 1 ядра и 2 ГБ памяти (оценка редакции).

Конспект по разделам

Что умеет Redmine и когда он подходит вместо Jira

Redmine ведёт проекты, задачи, трекеры (ошибка, функция, поддержка), версии и сроки, умеет учёт времени, вики и файлы проекта. Права выдаются ролями на уровне каждого проекта, а статусы задач и переходы между ними настраиваются для каждой роли отдельно. Он старше и проще современных трекеров, зато у него огромный набор плагинов.

Какие требования у Redmine к Ruby и базе данных

Из баз данных страница установки называет PostgreSQL 14, MySQL 8.0 (для него нужна настройка transaction_isolation в значение READ COMMITTED), SQL Server 2012 и SQLite 3, но SQLite не годится для многопользовательской работы. В Docker Ruby уже внутри образа. На Ubuntu 24.04 системный Ruby 3.2 подходит под обе ветки.

Установка Redmine в Docker с PostgreSQL по шагам

Каталог files хранит вложения задач, каталог plugins нужен для плагинов, а pgdata для базы. Тег 6 следует за веткой 6.x и не перескочит на 7 сам.

  • Docker и плагин Compose v2 обязательны: проще всего поставить их через curl -fsSL https://get.docker.com | sh.
  • Создайте compose-файл ниже, поменяв пароли и секрет сессий.
  • Запустите docker compose up -d: образ сам создаст таблицы и применит миграции при старте.
  • Откройте http://IP-сервера:8080 и войдите под admin с паролем admin.

HTTPS, почта и плагины Redmine на своём сервере

Порт 8080 наружу не оставляйте: привяжите его к 127.0.0.1 и поставьте перед контейнером Caddy или Nginx с сертификатом. Затем в разделе Администрирование, Настройки, Общие укажите имя хоста и протокол https, иначе письма придут со ссылками на IP. Плагин ставится так: распакуйте его в каталог plugins, выполните внутри контейнера bundle exec rake redmine:plugins:migrate RAILS_ENV=production и перезапустите Redmine.

Копии и обновление Redmine без потери задач

В копию входят дамп PostgreSQL, каталог files с вложениями и каталог plugins. Базу выгружает docker compose exec db pg_dump -U redmine redmine > redmine.sql. Как выносить копии за пределы сервера, описано в разборе сервер для бэкапов.

Вопросы и ответы

Как развернуть Redmine на сервере с Docker?

Взять образ redmine и контейнер PostgreSQL, задать переменные REDMINE_DB_POSTGRES, REDMINE_DB_USERNAME и пароль, смонтировать каталоги files и plugins и выполнить docker compose up -d. Приложение отвечает на порту 3000 внутри контейнера.

Какой логин и пароль у Redmine после установки?

Логин admin и пароль admin. При первом входе Redmine требует заменить пароль.

Какая версия Ruby нужна, чтобы установить Redmine на Ubuntu 24.04?

Для Redmine 6.0 подходит Ruby 3.1-3.3, для 6.1 Ruby 3.2-3.4. Системный Ruby 3.2 из Ubuntu 24.04 попадает в оба диапазона.

Как поставить плагин в Redmine, запущенный в Docker?

Положить плагин в смонтированный каталог plugins, выполнить внутри контейнера rake redmine:plugins:migrate в режиме production и перезапустить контейнер.
