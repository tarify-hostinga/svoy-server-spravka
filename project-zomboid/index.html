Свой сервер для Project Zomboid: коротко и с данными

Конспект страницы: 6 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Свой сервер для Project Zomboid.

Коротко

Главная / Игры / Project Zomboid Сервер для Project Zomboid скачивается через SteamCMD под app 380870 без входа в Steam и работает на Linux. Он слушает UDP-порты 16261 и 16262, настраивается одним ini-файлом и сам скачивает моды из Workshop по списку. Для компании до восьми человек хватит 2 ядер и 4-6 ГБ, сотня модов и разбредшиеся по карте игроки просят 8 ГБ.

Конспект по разделам

Сколько памяти нужно серверу Project Zomboid

The Indie Stone не даёт формулы на число игроков, поэтому ориентируются на настройки по умолчанию популярных сборок. Docker-образ сообщества renegademaster/zomboid-dedicated-server по умолчанию выделяет Java 4096 МБ и рассчитан на 16 слотов. Память съедают не столько игроки, сколько загруженные ими части карты: компания, которая держится вместе, обходится серверу дешевле, чем та же компания в четырёх городах.

Как развернуть сервер Project Zomboid на Ubuntu

Имя из -servername становится именем файлов настроек и папки с миром. Лимит памяти Java задают параметром -Xmx в файле ProjectZomboid64.json рядом со скриптом запуска. Как оформить запуск службой, описано в разделе об игровых серверах.

  • LinuxGSM: скрипт pzserver ставит зависимости, сервер и обновления.
  • Docker: образ сообщества с переменными для имени, пароля, слотов, модов и лимита памяти.
  • Вручную: SteamCMD и скрипт запуска из комплекта сервера, как ниже.

Имя, пароль и слоты в ini-файле сервера Project Zomboid

Настройки лежат в ~/Zomboid/Server/<имя>.ini; без параметра -servername файл называется servertest.ini.

Установка модов на сервер Project Zomboid: WorkshopItems и Mods

Моды подключаются двумя списками через точку с запятой. В WorkshopItems пишут номера предметов Steam Workshop, их сервер скачает сам. В Mods пишут идентификаторы модов (Mod ID), они указаны на странице мода в Workshop и не совпадают с номером.

Как друзья заходят на сервер Project Zomboid и где сохранения

В игре друзья выбирают подключение к серверу, вводят IP, порт 16261 и пароль. При первом входе каждый задаёт себе логин и пароль для этого сервера. Мир лежит в ~/Zomboid/Saves/Multiplayer/<имя>, рядом в ~/Zomboid/Server настройки.

Вопросы и ответы

Сколько стоит сервер Project Zomboid в месяц?

На 14 октября 2026 конфигурация с 2 ядрами и 4 ГБ стоит 5 480 ₽ в месяц, с 4 ядрами и 8 ГБ для модов и большой компании стоит 10 120 ₽. Оплата почасовая.

Как запустить моды на сервере Project Zomboid, если они не загружаются?

Проверьте, что мод есть в обоих списках: номер в WorkshopItems и Mod ID в Mods. Частая ошибка: указан только номер из адреса Workshop, тогда сервер мод скачает, но не включит.

Почему подключение к серверу Project Zomboid прерывается на загрузке?

Обычно не совпадают версии игры у сервера и игрока или у игрока не скачался мод. Третья причина: в фаерволе открыт только 16261, а второй порт 16262 тоже обязателен.

Как стать администратором на своём сервере Project Zomboid?

Пароль администратора передают при первом запуске параметром -adminpassword, так делает и LinuxGSM. Потом входите под учётной записью admin с этим паролем и получаете права в игре.
