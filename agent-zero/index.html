Agent Zero в Docker на своём сервере: коротко и с данными

Конспект страницы: 6 разделов коротко, данные на 14 октября 2026 и ответы на 3 вопроса. Полный разбор с примерами: Agent Zero в Docker на своём сервере.

Коротко

Agent Zero в Docker работает как отдельный Linux-компьютер для ИИ-агента: образ agent0ai/agent-zero отдаёт веб-интерфейс на порту 80 внутри контейнера и хранит настройки, память и проекты в /a0/usr. На сервере к этому добавляются пароль на интерфейс и порт, закрытый снаружи. Для одного агента возьмите 2 ядра и 4 ГБ памяти: внутри контейнера работают браузер и модель эмбеддингов.

Конспект по разделам

Что делает Agent Zero и почему он живёт в контейнере

Agent Zero это открытый фреймворк ИИ-агента под лицензией MIT. В отличие от чат-бота, он сам выполняет команды в терминале, ставит программы, пишет и запускает код, открывает сайты в браузере и ведёт проекты с файлами. Новые умения добавляются навыками и плагинами.

Какой сервер нужен Agent Zero

Разработчики пишут, что Agent Zero запускается везде, где есть Docker: от маленького VPS и Raspberry Pi до рабочей станции с видеокартой. Минимальной конфигурации в документации нет, поэтому калькулятор ниже даёт редакционную оценку. Из чего складывается нагрузка: Python-приложение агента, браузер внутри контейнера, модель эмбеддингов для памяти и базы знаний, которая по умолчанию считает на процессоре, и всё, что агент установит в процессе работы.

Запуск Agent Zero на VPS через Docker Compose

Документация отдельно предупреждает: не монтируйте весь каталог /a0. В нём код приложения, и такой том ломает обновления.

  • Поставьте Docker на чистую Ubuntu или Debian.
  • Создайте compose-файл как ниже: порт 50080 открыт только на локальном адресе, данные в именованном томе.
  • Запустите docker compose up -d и подождите несколько секунд, пока фреймворк стартует.
  • Откройте интерфейс через туннель ssh -N -L 50080:127.0.0.1:50080 root@IP-сервера и адрес http://localhost:50080.

Какие модели подключить к Agent Zero

В настройках Agent Zero три роли: основная модель для чата, вспомогательная для служебных задач и модель эмбеддингов для памяти. Основной нужна сильная модель с длинным контекстом, вспомогательной хватит дешёвой и быстрой. Начальные значения можно передать переменными окружения с префиксом A0_SET_, например A0_SET_chat_model_provider.

Как обновлять Agent Zero и открывать его снаружи

Обновление по документации выглядит так: скачать agent0ai/agent-zero:latest, запустить новый контейнер на другом порту и перенести данные через резервную копию /a0/usr (кнопки Backup и Restore в интерфейсе). Если новая версия не читает старые настройки, удалите /a0/usr/settings.json, и он создастся заново. Для доступа с телефона в интерфейсе есть функция туннеля: она выдаёт HTTPS-адрес без настройки домена.

Вопросы и ответы

Где Agent Zero хранит настройки, память и проекты?

В каталоге /a0/usr внутри контейнера: settings.json, память, проекты и пользовательские плагины. Этот каталог и нужно монтировать в том и копировать.

Что делать, если порт 80 занят при запуске Agent Zero?

Опубликовать другой внешний порт, например -p 5080:80, и открыть http://localhost:5080. Внутри контейнера интерфейс всегда слушает 80.

Можно ли поставить Agent Zero без Docker?

Основной путь в документации это Docker, вариант без него упоминается для старых установок. В Docker агент работает в изолированном Linux, а без контейнера получает доступ ко всей вашей машине.
