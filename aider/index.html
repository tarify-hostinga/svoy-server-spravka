Aider: установка и работа на своём сервере, коротко и с данными

Конспект страницы: 5 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Aider: установка и работа на своём сервере.

Коротко

Aider установка на сервер сводится к двум командам pip, а нужную версию Python установщик подтянет сам. Aider работает в терминале как напарник по коду: вы называете файлы и задачу, он вносит правки и сразу коммитит их в git, поэтому любую правку можно откатить. Aider почти не нагружает сервер: хватит 1 ядра и 2 ГБ памяти, если проект не компилируется.

Конспект по разделам

Чем Aider отличается от других агентов для кода

Aider: открытый помощник для программирования в терминале. Его особенность в тесной связке с git. Каждую правку файла Aider коммитит с понятным описанием, а незакоммиченные изменения, которые были до него, сначала сохраняет отдельным коммитом.

Установка Aider на Ubuntu через aider-install

Документация предлагает несколько путей. Для сервера удобнее всего aider-install: он ставит Aider в отдельное окружение и при необходимости скачивает собственный Python 3.12, не трогая системный. Ещё два пути из документации: uv tool install и pipx install aider-chat, второй работает с Python 3.9-3.12.

  • Проверьте Python: для aider-install подходит 3.8-3.13.
  • Задайте имя и почту в git ( git config --global user.name и user.email ), иначе коммиты Aider будут без автора.
  • Запустите Aider из корня репозитория с моделью и ключом.

Как подключить Aider к OpenAI-совместимому API

Aider умеет работать с моделями OpenAI, Anthropic, Gemini, DeepSeek, Ollama и другими, а любой сервис с OpenAI-совместимым API подключается тремя строками: Префикс openai/ говорит Aider, что модель надо искать по указанному адресу. Если модель Aider не знает, он покажет предупреждение о неизвестных параметрах, но работать будет. Так подключается AI Gateway Таймвеб Клауд: OpenAI-совместимый API к современным моделям, оплата рублями за токены (на 14 октября 2026).

Aider в Docker и в долгой сессии на VPS

Официальные образы: paulgauthier/aider (ядро) и paulgauthier/aider-full (с дополнительными пакетами). Запускать их нужно из корня репозитория, потому что текущий каталог подключается в контейнер как /app: В контейнере нет вашего глобального конфига git, поэтому имя и почту задайте в самом репозитории командой git config user.email, иначе коммиты Aider получат чужого автора. Для долгих задач откройте окно tmux ( tmux new -s aider ): обрыв SSH не остановит работу, а вернуться можно командой tmux attach -t aider.

Вопросы и ответы

Какой Python нужен для Aider?

Для aider-install подходит Python 3.8-3.13, а сам Aider установщик запустит на отдельном Python 3.12, скачав его при необходимости.

Как отменить правку Aider?

Командой /undo в чате: Aider откатит свой последний коммит. Посмотреть изменения до отмены можно через /diff.

Работает ли Aider с локальной моделью?

Да, если модель отдаёт OpenAI-совместимый API, например через Ollama: укажите адрес в OPENAI_API_BASE и модель с префиксом openai/.

Почему Aider в Docker делает коммиты без автора?

В контейнере нет глобального конфига git. Задайте user.name и user.email в самом репозитории до запуска.
