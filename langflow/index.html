Langflow в Docker на своём сервере: коротко и с данными

Конспект страницы: 6 разделов коротко, данные на 14 октября 2026 и ответы на 3 вопроса. Полный разбор с примерами: Langflow в Docker на своём сервере.

Коротко

Langflow в Docker запускается одной командой с образом langflowai/langflow: визуальный редактор открывается на порту 7860, а вход защищён паролем суперпользователя. Для постоянной работы берут compose-файл из репозитория, в нём уже есть PostgreSQL и том для настроек. Берите сервер от 2 ядер и 4 ГБ памяти: минимум из документации 2 ГБ, но разбор документов съедает запас.

Конспект по разделам

Что делает Langflow и чем он отличается от Flowise

Langflow это визуальный редактор ИИ-потоков на Python: агенты, чат-боты, поиск по документам собираются из компонентов на холсте. Любой компонент можно открыть и поправить кодом на Python, а готовый поток вызвать по API или подключить к ИИ-клиенту как MCP-сервер. Лицензия MIT.

Сколько памяти нужно Langflow

Для пакета без Docker нужен Python от 3.10 до 3.14. В Docker версия Python уже внутри образа, на сервер ставится только Docker. Тяжёлую работу Langflow делает при загрузке файлов: разбивает их на куски и считает векторы, поэтому память добавляют под документы, а не под число пользователей.

Запуск Langflow в Docker и Docker Compose

Быстрая проверка без базы данных: одна команда, вход по логину langflow и паролю, который вы передали в переменной. Для постоянной работы используйте пример из репозитория, папка docker_example: Compose-файл держит два тома: langflow-postgres с базой и langflow-data с журналами, файлами и секретным ключом (переменная LANGFLOW_CONFIG_DIR=/app/langflow ).

  • Скачайте репозиторий langflow-ai/langflow и перейдите в docker_example.
  • Создайте.env со строкой LANGFLOW_SUPERUSER_PASSWORD: без неё compose-файл откажется стартовать.
  • Поменяйте пароль PostgreSQL в обоих местах, в сервисе базы и в LANGFLOW_DATABASE_URL: в примере стоит langflow.
  • Удалите блок ports у сервиса postgres.

Вход, ключи API и HTTPS в Langflow

Официальные образы стартуют с LANGFLOW_AUTO_LOGIN=false, то есть без пароля в редактор не попасть. Документация добавляет ещё два правила для сервера: задать свой LANGFLOW_SECRET_KEY вместо значения по умолчанию и поставить Langflow за обратный прокси с HTTPS. Ключи моделей (OpenAI, AI Gateway, Anthropic) хранятся в компонентах как переменные.

  • Прокси: Nginx с сертификатом Certbot или Caddy, порт 7860 при этом публикуют только на 127.0.0.1.
  • Запуск потоков через /api/v1/run/ по умолчанию требует ключ API Langflow.
  • Вебхуки тоже проверяют ключ.

Как обновить образ Langflow и сохранить потоки

Потоки, пользователи и ключи лежат в PostgreSQL, файлы и секретный ключ в томе langflow-data. Оба тома переживают пересоздание контейнера, поэтому обновление это docker compose pull и docker compose up -d. В примере стоит тег latest с pull_policy: always: каждый перезапуск может принести новую версию.

Вопросы и ответы

Какой логин у Langflow после запуска в Docker?

Логин langflow, пароль тот, что передан в LANGFLOW_SUPERUSER_PASSWORD. Без этой переменной compose-файл из репозитория не запустится.

Можно ли оставить Langflow на SQLite?

Для одного человека и тестов можно. Для продакшена документация Langflow рекомендует внешний PostgreSQL: он рассчитан на параллельную работу и копируется штатными дампами.

Как вызвать поток Langflow из своего приложения?

Отправить запрос на /api/v1/run/ с идентификатором потока и ключом API Langflow. Тот же поток можно отдать ИИ-клиенту как MCP-сервер.
