Установка GitLab на свой сервер: коротко и с данными

Конспект страницы: 6 разделов коротко, данные на 14 октября 2026 и ответы на 5 вопросов. Полный разбор с примерами: Установка GitLab на свой сервер.

Коротко

Установка GitLab на свой сервер занимает один compose-файл, но сам GitLab тяжёлый: документация называет минимумом для одного сервера 8 vCPU и 16 ГБ памяти. Зато вы получаете Git, задачи, ревью кода, CI/CD и реестр образов в одной программе на собственном железе. GitLab на одном сервере просит 8 vCPU и 16 ГБ памяти, в режиме экономии памяти хватает 8 ГБ.

Конспект по разделам

Что входит в GitLab и когда он нужен вместо Gitea

GitLab это единая платформа разработки: репозитории Git, запросы на слияние, задачи, CI/CD-пайплайны, реестр контейнеров и пакетов, окружения, сканирование кода. Бесплатная редакция называется Community Edition (образ gitlab-ce), платная Enterprise (gitlab-ee) добавляет функции для больших компаний. Платформа оправдана, когда вся цепочка от задачи до выкладки должна жить в одном месте.

Сколько ресурсов нужно, чтобы установить GitLab на VPS

Домен, HTTPS и SSH для GitLab на своём сервере

Направьте A-запись, например gitlab.example.com, на IP сервера до первого запуска: иначе Let's Encrypt откажет в сертификате, а GitLab будет пытаться выпустить его снова. Если на сервере уже стоит обратный прокси, то есть программа, принимающая HTTPS и передающая запросы приложениям, отдайте ему сертификаты. Тогда в настройках GitLab отключают встроенный HTTPS и слушают порт 80 внутри сети, а снаружи работают Caddy, Traefik или Nginx.

Резервные копии и обновление GitLab в Docker

Архив данных делает команда docker exec -t gitlab gitlab-backup create, файл попадает в data/backups. В архив не входят настройки, поэтому каталог config с файлами gitlab.rb и gitlab-secrets.json копируйте отдельно: в secrets лежит ключ шифрования, без него переменные CI и данные двухфакторной защиты не восстановить. Ночной запуск ставят в cron с параметром CRON=1, а копии выносят с сервера: схема в разборе сервер для бэкапов.

Вопросы и ответы

Сколько оперативной памяти нужно, чтобы установить GitLab?

Документация GitLab называет минимумом 16 ГБ для одного сервера, а для режима с экономией памяти 8 ГБ. Подкачку советуют отключить или дать столько памяти, чтобы до неё не доходило.

Как развернуть GitLab на сервере в Docker?

Поставить Docker, описать образ gitlab/gitlab-ce в compose-файле с тремя томами (config, logs, data), открыть порты 80, 443 и вынести SSH на 2424, затем выполнить docker compose up -d и дождаться конца первого старта.

Где взять пароль root после установки GitLab?

В файле /etc/gitlab/initial_root_password внутри контейнера. Он удаляется автоматически через сутки после первой настройки, поэтому смените пароль сразу.

Можно ли установить GitLab на Windows?

Сервер GitLab ставится на Linux. На Windows его запускают в WSL2 или Docker Desktop только для проб; боевой сервер лучше держать на Linux VPS. Раннер GitLab при этом под Windows работает.

Как обновить GitLab в Docker и не потерять данные?

Сделать архив gitlab-backup и копию каталога config, сменить тег образа по пути обновления из документации и выполнить docker compose up -d. Данные остаются в томах.
