Установка Ollama на Linux, Windows и в Docker: коротко и с данными

Конспект страницы: 6 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Установка Ollama на Linux, Windows и в Docker.

Коротко

Установка Ollama на Linux занимает одну команду, на Windows и macOS это обычный установщик, а в Docker хватает образа ollama/ollama. После запуска Ollama держит API на порту 11434, скачивает модели командой ollama pull и отдаёт ответы любой программе, которая умеет говорить с OpenAI API. Для пробы хватит VPS с 8 ГБ памяти и модели на 3-9 млрд параметров.

Конспект по разделам

Сколько памяти и диска нужно Ollama

Ollama сама почти ничего не весит: память съедает модель, которую вы запускаете. Официальная страница для Windows просит 4 ГБ свободного места под программу и предупреждает, что модели займут от десятков до сотен гигабайт. Расчёт ниже покажет, хватит ли памяти обычного сервера или пора смотреть на карту.

Установка Ollama на Ubuntu и Debian одним скриптом

На Linux модели лежат в /usr/share/ollama/.ollama/models. Если системный диск маленький, задайте другую папку переменной OLLAMA_MODELS и выдайте на неё права пользователю ollama: sudo chown -R ollama:ollama /data/models. Обновление на Linux делается тем же скриптом установки.

  • Запустите скрипт из документации: curl -fsSL https://ollama.com/install.sh | sh.
  • Проверьте версию командой ollama -v.
  • Скачайте и запустите модель: ollama run qwen3.5:9b.
  • Посмотрите, что уже скачано: ollama list.

Ollama в Docker: образ ollama/ollama, том и GPU

Docker удобен, когда на сервере уже живут другие контейнеры, например Open WebUI. Модели хранятся в томе ollama, поэтому пересоздание контейнера их не стирает. В docker compose те же параметры переносятся в сервис с образом ollama/ollama, томом ollama:/root/.ollama и блоком deploy.resources.reservations.devices для карты.

Как открыть API Ollama для других программ

Из коробки Ollama слушает только 127.0.0.1:11434, и это правильно: локальные запросы к ней не требуют ключа. Чтобы к модели обращались другие контейнеры или соседний сервер, адрес меняют переменной OLLAMA_HOST через systemctl edit ollama.service: После этого выполните systemctl daemon-reload и systemctl restart ollama. Наружу такой порт открывать нельзя: любой, кто узнает IP, будет крутить модели на вашем железе.

Установка Ollama на Windows и macOS

На Windows Ollama ставится обычным установщиком без прав администратора, в домашнюю папку пользователя. Поставить программу на другой диск можно флагом OllamaSetup.exe /DIR="D:\Ollama", а модели перенести переменной окружения OLLAMA_MODELS в настройках учётной записи. После смены переменной приложение в трее нужно закрыть и открыть заново.

Вопросы и ответы

Можно ли поставить Ollama на VPS без видеокарты?

Да. На процессоре Ollama работает с моделями на 3-9 млрд параметров в сжатии Q4, ответ появляется медленнее, чем на GPU. Для пробы хватит 8 ГБ памяти, для моделей крупнее берут сервер с картой.

Как установить Ollama на другой диск?

На Windows запустите установщик с флагом /DIR и задайте переменную OLLAMA_MODELS для папки моделей. На Linux достаточно OLLAMA_MODELS в настройках службы и прав пользователя ollama на эту папку.

Как обновить Ollama в Docker и не потерять модели?

Скачайте новый образ ollama/ollama, удалите старый контейнер и запустите его той же командой с тем же томом ollama. Модели лежат в томе и остаются на месте.

Почему Open WebUI в Docker не видит Ollama?

Внутри контейнера localhost указывает на сам контейнер. Укажите адрес http://host.docker.internal:11434 и добавьте флаг --add-host=host.docker.internal:host-gateway, а Ollama на хосте переведите на OLLAMA_HOST=0.0.0.0.
