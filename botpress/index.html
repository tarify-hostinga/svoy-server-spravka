Коротко

Botpress в Docker сегодня это версия v12: официальный образ botpress/server запускает студию и бота на порту 3000. После запуска Botpress Cloud основной продукт компании облачный, а v12 живёт в отдельном репозитории со своей документацией, поэтому сначала решите, нужна ли вам именно своя копия. Своя установка Botpress это версия v12 в Docker, а не облачная платформа.

Конспект по разделам

Что такое Botpress и какая версия ставится на сервер

Botpress это платформа для чат-ботов с визуальным редактором диалогов. Сейчас у компании два продукта. Botpress Cloud работает только у разработчиков, и README прямо называет его самым быстрым способом начать.

Лицензия Botpress v12: AGPLv3 или проприетарная

Botpress v12 распространяется по двойной лицензии: AGPLv3 и Botpress Proprietary License. Любой бот, созданный в Botpress, по умолчанию идёт под AGPLv3, переключить его на лицензию Botpress можно в веб-интерфейсе бота. Что это значит на практике: AGPLv3 требует открыть исходный код изменённой программы тем, кто пользуется ей по сети.

Запуск Botpress v12 в Docker Compose

Без Docker v12 ставится готовой сборкой под вашу систему с сайта документации. Docker удобнее на сервере: обновление сводится к новому образу, а откат к старому тегу.

  • Поставьте Docker и Compose на чистую Ubuntu или Debian.
  • Возьмите пример из репозитория examples/docker-compose: образ botpress/server и порт 3000.
  • Добавьте перезапуск и локальную публикацию порта, как в файле ниже, и закрепите конкретную версию образа из Docker Hub вместо тега по умолчанию.
  • Подключите том для данных.

Домен и HTTPS для Botpress на своём сервере

Мессенджеры отправляют сообщения боту вебхуками и почти всегда требуют HTTPS. Поэтому перед Botpress ставят обратный прокси: Nginx с сертификатом Certbot или Caddy, который получает сертификат сам. После этого пропишите внешний адрес в настройках сервера Botpress, чтобы ссылки на студию и адреса вебхуков строились на домен, а не на localhost.

Когда вместо Botpress выбрать другой путь

Для самого Botpress v12 нагрузку дают число ботов и диалогов. Калькулятор ниже даёт стартовую конфигурацию. Оценка редакции: требований к железу в README нет

  • Свой сервер не обязателен: тогда проще Botpress Cloud, там не нужно следить за обновлениями и сертификатами.
  • Нужен бот на языковой модели с поиском по документам: Flowise, Dify или Langflow, у них есть compose-файлы и свежие релизы.
  • Нужен простой бот для Telegram на Python или Node.js: обычный VPS и свой код, см. хостинг для Telegram-бота.

Вопросы и ответы

Есть ли у Botpress официальный Docker-образ?

Да, botpress/server на Docker Hub. Он относится к версии v12; облачная Botpress Cloud на свой сервер не ставится.

Чем Botpress v12 отличается от Botpress Cloud?

v12 вы ставите и обслуживаете сами: сборка, Docker или исходники, лицензия AGPLv3 по умолчанию. Botpress Cloud работает у разработчиков, и её README рекомендует как самый быстрый старт.

Можно ли запустить Botpress v12 без Docker?

Да, готовой сборкой для Windows, macOS или Linux с сайта документации v12 либо из исходников. На сервере Docker удобнее для обновлений и отката.
