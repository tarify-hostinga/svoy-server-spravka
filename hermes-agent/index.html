Коротко

Главная / ИИ-агенты / Hermes Agent AI-агент Hermes (Hermes Agent) это открытый ИИ-агент от Nous Research под лицензией MIT: он живёт на вашем компьютере или сервере, помнит прошлые разговоры и сам записывает навыки после сложных задач. Ставится одной командой, общается через терминал или мессенджеры, а модель подключается по API, в том числе через любой OpenAI-совместимый адрес. Hermes Agent ставится одной командой и работает с любой моделью по API.

Конспект по разделам

Что умеет Hermes Agent от Nous Research

Hermes построен вокруг цикла обучения. После сложной задачи агент сам пишет навык (skill), то есть инструкцию, как он её решил, и дорабатывает её при следующих запусках. Рядом лежат память о пользователе и полнотекстовый поиск по прошлым сессиям.

Что нужно Hermes Agent: система и модель

Установщик работает в Linux, macOS, WSL2 и в обычном Windows через PowerShell, для Android есть пакет в Termux. Скрипту для Linux нужны Git, curl и tar, а Python 3.14 и зависимости он подтягивает сам через менеджер пакетов uv. Главное требование касается модели: окно контекста от 64 тысяч токенов.

Установка Hermes Agent на VPS по шагам

Если что-то не заработало, команда hermes doctor покажет причину. Обновление делается командой hermes update.

  • Создайте сервер на Ubuntu или возьмите позицию Hermes в маркетплейсе Таймвеб Клауд: на 14 октября 2026 её установили 319 раз.
  • Поставьте агента командой из блока ниже и перечитайте настройки оболочки.
  • Запустите мастер hermes setup: он за один проход настроит модель, инструменты и мессенджеры.
  • Проверьте модель командой hermes model: для своего адреса выберите пункт Custom endpoint и введите URL API, ключ и имя модели.

Какую модель подключить к Hermes Agent

Hermes не привязан к одному провайдеру: в документации описаны Nous Portal, OpenRouter, OpenAI, Anthropic, локальные Ollama и vLLM и любой свой адрес. Если нужна оплата в рублях без зарубежной карты, подойдёт AI Gateway Таймвеб Клауд: OpenAI-совместимый API, где модели разных семейств доступны по одному ключу. Ключ можно не хранить в файле, а передать через переменную окружения параметром key_env.

Кто может писать агенту Hermes в Telegram

Шлюз Hermes по умолчанию закрыт: если не задан ни один список разрешённых пользователей, агент отказывает всем. Свой числовой ID в Telegram пропишите в файле ~/.hermes/.env: Переменная GATEWAY_ALLOW_ALL_USERS=true открывает агента всем подряд. Для бота с доступом к терминалу это опасно: любой собеседник сможет просить его выполнять команды на сервере.

Вопросы и ответы

Hermes Agent бесплатный или платный?

Сам агент распространяется под лицензией MIT и ничего не стоит. Платить придётся за модель (токены у провайдера API или подписка Nous Portal, где модели, веб-поиск и генерация картинок идут одним счётом) и за сервер, если агент нужен круглосуточно.

Можно ли поставить Hermes Agent на Windows без WSL?

Да, есть установщик для PowerShell, он кладёт агента в каталог %LOCALAPPDATA%\hermes. Антивирус иногда помечает входящий в комплект uv.exe; разработчики называют это ложным срабатыванием и описывают в README, как сверить файл с официальным релизом.

Чем Hermes Agent отличается от OpenClaw?

Оба агента работают на вашем железе и отвечают в мессенджерах. Hermes делает упор на самообучение: сам пишет и улучшает навыки после задач. Переход с OpenClaw проходит без потери истории: Hermes импортирует SOUL.md, MEMORY.md, USER.md, навыки и список разрешённых команд.
