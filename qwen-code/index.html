Установка Qwen Code на сервер: коротко и с данными

Конспект страницы: 5 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Установка Qwen Code на сервер.

Коротко

Установка Qwen Code на сервер делается скриптом или через npm при Node.js 22 и новее. Главное изменение 2026 года: бесплатный вход Qwen OAuth закрыт 15 апреля, и теперь агенту нужен провайдер модели с ключом API, например любой OpenAI-совместимый. Qwen Code сам по себе лёгкий: хватит 1 ядра и 2 ГБ памяти, если модель работает у провайдера.

Конспект по разделам

Qwen Code: агент для терминала с выбором модели

Qwen Code: открытый агент для программирования от команды Qwen. Он работает в терминале, читает репозиторий, правит файлы и запускает команды. В отличие от агентов, привязанных к одному разработчику моделей, Qwen Code подключается к разным провайдерам.

Установка Qwen Code на Ubuntu

Если сервер новый, сначала обновите систему и создайте пользователя для работы. Подробнее о версиях Node.js на сервере: Node.js на VPS. Модель работает у провайдера, поэтому считаем память под проект и сам агент

  • Выберите способ.
  • Поставьте агента одной из команд ниже и перезапустите терминал, чтобы подхватились переменные.
  • Перейдите в каталог проекта и запустите qwen.
  • Настройте провайдера через /auth или сразу файлом настроек (следующий раздел).

Как подключить Qwen Code к OpenAI-совместимому API

Без браузера на сервере проще всего настроить провайдера файлом ~/.qwen/settings.json. Ключ openai в разделе modelProviders означает протокол, а не компанию: туда подходит любой OpenAI-совместимый адрес. Сам ключ задайте в окружении: export GATEWAY_API_KEY=... в ~/.bashrc пользователя.

Qwen Code со своей моделью Qwen Coder на GPU

Связка «агент плюс своя модель» работает так: на сервере с видеокартой модель поднимают в vLLM или Ollama, оба отдают OpenAI-совместимый API, а Qwen Code получает его адрес в baseUrl. Код и запросы тогда не уходят к внешнему провайдеру. Платить придётся видеопамятью: модели для программирования, которые уверенно вызывают инструменты, крупные.

Как не потерять работу Qwen Code при обрыве SSH

Запускайте qwen в окне tmux: tmux new -s qwen. После отключения сочетанием Ctrl+B, D агент продолжит задачу, а вернуться можно командой tmux attach -t qwen. Документация отдельно предупреждает: в SSH, CI и контейнерах браузерный вход обычно не проходит, поэтому на сервере используют ключ API.

Вопросы и ответы

Qwen Code ещё бесплатный?

Бесплатный уровень входа Qwen OAuth закрыт 15 апреля 2026. Сам агент открытый и бесплатный, а за модель платите выбранному провайдеру или запускаете её на своём GPU.

Какой Node.js нужен для Qwen Code?

Для установки через npm нужен Node.js 22 или новее. Отдельный установщик Qwen Code ставится без Node.js.

Можно ли подключить Qwen Code к своему серверу с моделью?

Да: поднимите модель в vLLM или Ollama и укажите их OpenAI-совместимый адрес в baseUrl провайдера openai в ~/.qwen/settings.json.

Где Qwen Code хранит настройки провайдеров?

В файле ~/.qwen/settings.json в разделе modelProviders. Документация советует держать его на уровне пользователя, а не проекта.
