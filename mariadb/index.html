Установка MariaDB на свой сервер: коротко и с данными

Конспект страницы: 7 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Установка MariaDB на свой сервер.

Коротко

Установка MariaDB на сервер проще всего в Debian и Ubuntu: пакет mariadb-server ставится одной командой, а в Docker есть официальный образ с долгосрочными тегами 12.3 и 11.8. База говорит на языке MySQL, так что большинство PHP-проектов подключается к ней без правок. Различия начинаются в функциях и в именах утилит.

Конспект по разделам

Чем MariaDB отличается от MySQL и когда её брать

MariaDB это ответвление MySQL с открытым кодом GPL. Оно появилось после покупки MySQL компанией Oracle и сохранило протокол, клиентские библиотеки и привычные SQL-команды. В Debian MariaDB стоит вместо MySQL по умолчанию, поэтому на Debian её и ставят.

Установка MariaDB на Debian и Ubuntu

Клиент и утилиты в новых версиях называются mariadb и mariadb-dump, старые имена mysql и mysqldump остались как ссылки для совместимости. Пользователь root при локальном входе проверяется по сокету, а не по паролю: sudo mariadb пускает без пароля, обычный пользователь системы нет. В Debian настройки лежат в /etc/mysql/mariadb.conf.d/50-server.cnf, там же параметр bind-address, по умолчанию локальный.

  • Поставьте сервер пакетом mariadb-server, он запускается как служба сразу после установки.
  • Запустите мастер защиты mariadb-secure-installation: удалит тестовую базу и анонимных пользователей.
  • Создайте базу и пользователя приложения, не работайте от root.

MariaDB в Docker: compose-файл с healthcheck

Официальный образ mariadb требует один из вариантов пароля root, например MARIADB_ROOT_PASSWORD. Тег lts ведёт на ветку 12.3, а latest на 13.0 с коротким сроком поддержки; для рабочей базы фиксируйте 11.8 или 12.3. В.env задайте MARIADB_ROOT_PASSWORD и MARIADB_PASSWORD.

Сколько памяти нужно MariaDB и как настроить InnoDB

Основной расход памяти идёт на innodb_buffer_pool_size, кэш данных и индексов. Значение по умолчанию 128 МБ мало для базы в несколько гигабайт, но для сайта-визитки хватает. Если на сервере живут PHP и веб-сервер, отдайте пулу около половины памяти, на отдельном сервере базы можно больше.

Кластер Galera для MariaDB: когда он нужен и сколько серверов

Galera связывает несколько узлов MariaDB в один кластер, где запись идёт на любой из них, а данные синхронно копируются на остальные. Для кворума нужны не меньше трёх узлов, иначе при падении одного оставшийся не поймёт, кто из них главный. Для сайта на CMS такая схема избыточна: три сервера стоят втрое дороже, а нагрузка редко её оправдывает.

Резервные копии MariaDB: mariadb-dump и mariadb-backup

Логический дамп делается командой mariadb-dump --single-transaction appdb | gzip > appdb.sql.gz. Для баз в десятки гигабайт дамп и восстановление идут долго, тогда берут физическую копию утилитой mariadb-backup: она копирует файлы данных без остановки сервера. Управляемой MariaDB в Таймвеб Клауд нет, а у управляемого MySQL автокопии стоят 6 ₽ в месяц за ГБ (цена на 14 октября 2026).

Отдайте базу данных провайдеру

Обновления, мониторинг и резервные копии делает провайдер, вы работаете с подключением.

Вопросы и ответы

Какую версию MariaDB ставить в новый проект?

Берите долгосрочную ветку: 12.3 поддерживается до июня 2029 года, 11.8 до июня 2028 года. Ветки с короткой поддержкой вроде 13.0 годятся для проверки новых функций, а не для рабочей базы.

Можно ли заменить MySQL на MariaDB без переделки сайта?

Для большинства CMS да: протокол и SQL совместимы. Проверьте на тестовой копии, потому что расширения под конкретную версию MySQL иногда используют функции, которых в MariaDB нет.

Как установить MariaDB в Docker с проверкой готовности?

Используйте образ mariadb с тегом lts и добавьте в compose-файл healthcheck через скрипт healthcheck.sh с флагами --connect и --innodb_initialized. Приложение тогда стартует после готовности базы.

Как установить MariaDB на Windows 10 для разработки?

Скачайте установщик MSI с сайта проекта и оставьте порт 3306. Для рабочего сервера берите Linux: на нём проще копии и обновления.
