Установка Dify на свой сервер: коротко и с данными

Конспект страницы: 6 разделов коротко, данные на 14 октября 2026 и ответы на 3 вопроса. Полный разбор с примерами: Установка Dify на свой сервер.

Коротко

Установка Dify на сервер идёт через Docker Compose из официального репозитория: одна команда поднимает 15 контейнеров, от API и воркеров до PostgreSQL, Redis и векторной базы Weaviate. Поэтому Dify требует больше соседей по классу: от 2 ядер и 4 ГБ памяти. Под Dify берите 2 ядра и 4 ГБ памяти как нижнюю границу, с большой базой знаний сразу 8 ГБ.

Конспект по разделам

Что внутри Dify и почему он тяжелее Flowise

Dify это платформа для ИИ-приложений: чат-боты, рабочие процессы, агенты с инструментами и база знаний с поиском по документам. Модели и инструменты подключаются плагинами из маркетплейса Dify. Лицензия основана на Apache 2.0, но с дополнительными условиями: прочитайте их до того, как продавать доступ к своей установке нескольким клиентам.

Сколько ресурсов нужно Dify на VPS

README Dify называет минимум: 2 ядра и 4 ГиБ памяти. Для Docker Desktop на Mac документация просит выделить виртуальной машине 2 vCPU и 8 ГиБ, это хороший ориентир и для сервера, где база знаний большая. Docker Compose нужен версии 2.24.0 или новее.

Установка Dify через Docker Compose на Ubuntu

  • Поставьте Docker с Compose 2.24.0+ и проверьте версию командой docker compose version.
  • Склонируйте последний релиз.
  • Создайте.env из примера и поправьте переменные из следующего раздела.
  • Запустите docker compose up -d и проверьте docker compose ps: контейнеры должны быть Up или healthy, init_permissions в статусе Exited это норма.

Какие переменные Dify поменять до первого запуска

Модели Dify берёт у провайдеров через плагины: OpenAI, Anthropic, OpenAI-совместимые API вроде AI Gateway с оплатой в рублях, локальная Ollama. Внутри контейнера localhost указывает на сам контейнер, поэтому Ollama на хосте задают через адрес хоста в сети Docker, например host.docker.internal, если он настроен.

  • INIT_PASSWORD: пароль на страницу /install.
  • DIFY_AGENT_SERVER_SECRET_KEY: в примере значение для разработки, комментарий в файле прямо просит заменить его в продакшене.
  • SECRET_KEY: если оставить пустым, Dify сгенерирует постоянный ключ в каталоге хранилища.
  • CONSOLE_API_URL, APP_WEB_URL и соседние адреса: пропишите домен, когда он появится.

HTTPS и обновление Dify без потери данных

Снаружи Dify слушает порт 80 через свой Nginx. HTTPS включается в нём же: NGINX_HTTPS_ENABLED=true, сертификат в файлах dify.crt и dify.key, а для Let's Encrypt в compose есть сервис certbot и переменная NGINX_ENABLE_CERTBOT_CHALLENGE. Если на сервере уже стоит Caddy или Traefik, смените EXPOSE_NGINX_PORT на внутренний порт и проксируйте на него.

Вопросы и ответы

Почему Dify не открывается после docker compose up?

Проверьте docker compose ps: часть сервисов стартует дольше минуты, а при нехватке памяти контейнеры перезапускаются по кругу. Если на сервере меньше 4 ГБ, начните поиск причины с памяти.

Как перезапустить Dify в Docker?

Из каталога dify/docker: docker compose restart для мягкого перезапуска или docker compose down и docker compose up -d, если меняли.env. Данные в docker/volumes при этом сохраняются.

Можно ли поставить Dify без Docker?

Можно собрать из исходников, но это путь для разработчиков самого Dify: вручную придётся поднять PostgreSQL, Redis, векторную базу и песочницу. Для сервера документация предлагает Docker Compose.
