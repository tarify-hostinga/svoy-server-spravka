Установка PyTorch и TensorFlow на сервер с видеокартой: коротко и с данными

Конспект страницы: 6 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Установка PyTorch и TensorFlow на сервер с видеокартой.

Коротко

Установка PyTorch на сервер с видеокартой делается одной командой pip с адресом сборки под нужную CUDA, отдельный CUDA Toolkit для этого не нужен. На 14 октября 2026 стабильная версия 2.14.1 и она требует Python 3.10 или новее, а TensorFlow ставится пакетом с суффиксом and-cuda. На сервер с GPU ставьте драйвер NVIDIA и PyTorch из pip со сборкой cu132 (драйвер 580+) или cu126 для старых драйверов.

Конспект по разделам

Что нужно серверу перед установкой PyTorch

PyTorch и TensorFlow: две основные библиотеки для обучения и запуска нейросетей на Python. Обеим для работы на видеокарте нужен только драйвер NVIDIA на хосте: библиотеки CUDA приезжают вместе с пакетами pip. Опишите задачу, и калькулятор подскажет: обычный сервер или GPU

  • Проверьте драйвер командой nvidia-smi.
  • Создайте виртуальное окружение: python3 -m venv ~/venv-torch и source ~/venv-torch/bin/activate.
  • Проверьте версию Python: PyTorch просит 3.10 или новее.

Установка PyTorch с CUDA через pip

Сборки PyTorch различаются адресом индекса пакетов. Для Linux конфигуратор на pytorch.org предлагает варианты под CUDA 12.6 и 13.2, а также сборку только для процессора. Установка TensorFlow с GPU на Ubuntu

TensorFlow поддерживает Python 3.9-3.12, поэтому ему часто нужно своё окружение с другой версией Python, чем у PyTorch. Видеокарту на Linux он получает через пакет с библиотеками CUDA: Пустой список в ответе означает, что TensorFlow карту не нашёл. Для серверов без GPU есть пакет tensorflow-cpu.

Какой сервер нужен для обучения на PyTorch

Для учебных примеров и небольших моделей на табличных данных хватает обычного VPS: процессор справится, только медленнее. Вопросы и ответы

Нужно ли ставить CUDA Toolkit для PyTorch?

Нет. Пакеты PyTorch из pip приносят библиотеки CUDA с собой, на сервере нужен только драйвер NVIDIA подходящей версии.

Какой Python нужен для PyTorch и для TensorFlow?

Стабильный PyTorch требует Python 3.10 или новее, TensorFlow поддерживает 3.9-3.12. Удобно держать их в разных виртуальных окружениях.

Почему torch.cuda.is_available() возвращает False?

Две типичные причины: установлена сборка для процессора или драйвер старее, чем требует сборка. Для cu132 нужен драйвер ветки 580 и новее.

Как установить TensorFlow с поддержкой GPU?

На Linux командой pip install с пакетом tensorflow[and-cuda] внутри виртуального окружения, затем проверить список устройств GPU в Python.
