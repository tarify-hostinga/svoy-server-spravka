Self hosted мессенджеры: сравнение пяти систем

Все пять систем открыты и бесплатны в базовой редакции, у Mattermost и Rocket.Chat есть платные тарифы с функциями для крупных компаний. Если в компании уже стоит Nextcloud, начните с Talk: он включается в той же панели и не требует отдельного сервера.

Какой self hosted мессенджер выбрать для команды

Два ответа, и подборка сузится до одного-двух вариантов Попробуйте выбранный вариант на одном отделе две недели, прежде чем переводить всю компанию. Перенос истории между мессенджерами почти всегда неполный, поэтому смена системы через год обойдётся дороже, чем лишняя неделя теста.

Self hosted мессенджер со звонками: что нужно серверу

Текстовый чат нагружает сервер слабо, звонки устроены иначе. Видео и звук идут через сервер-ретранслятор, если участники за разными NAT: так работают TURN в Nextcloud Talk (порт 3478 по TCP и UDP) и видеомост Jitsi. Без открытых UDP-портов звонки соединяются только внутри одной сети.

Вопросы и ответы

Какой self hosted мессенджер поддерживает звонки?

Звонки есть в Mattermost, Rocket.Chat, Element на Matrix и Nextcloud Talk. Для частых встреч с большим числом участников удобнее отдельный Jitsi Meet.

Есть ли у self hosted мессенджеров приложения для телефонов?

Да, у всех пяти систем из сравнения есть клиенты для Android и iOS, а также для Windows, macOS и Linux.

Можно ли переписываться с другой компанией через свой мессенджер?

Да, если обе стороны на Matrix: серверы обмениваются сообщениями через федерацию. Mattermost и Rocket.Chat рассчитаны на работу внутри одной организации.
