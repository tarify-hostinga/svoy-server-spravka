Установка Immich на свой сервер: коротко и с данными

Конспект страницы: 7 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Установка Immich на свой сервер.

Коротко

Установка Immich на свой сервер делается через Docker Compose: два файла из последнего выпуска, правка пути к архиву и пароля базы, затем одна команда запуска. Immich заменяет облако для фото с телефона, но просит больше памяти, чем остальные self-hosted приложения: минимум 6 ГБ. Под Immich берите сервер с 4 ядрами и 8 ГБ памяти, базу держите на локальном SSD.

Конспект по разделам

Что умеет Immich и чем он заменяет облако для фото

Immich это фотоархив с открытым кодом под лицензией AGPL-3.0. Приложения для Android и iOS загружают снимки и видео с телефона на ваш сервер, а веб-интерфейс показывает ленту по датам, карту, альбомы и общие ссылки. Отдельный контейнер машинного обучения распознаёт лица и строит поиск по описанию: можно найти «собака на пляже» без ручных тегов.

Сколько памяти нужно Immich и зачем ему контейнер ML

Требования из документации Immich: С третьей версии контейнер машинного обучения на amd64 требует процессор с набором инструкций x86-64-v2. Его поддерживают почти все процессоры примерно с 2012 года, но на виртуальной машине стоит проверить, какая модель CPU выставлена гостю. Ответьте про распознавание, объём архива и число людей

Установка Immich через Docker Compose

Нужна именно команда docker compose: старый docker-compose Immich больше не поддерживает.

  • Создайте каталог и скачайте compose-файл и пример настроек из последнего выпуска (команды ниже).
  • Откройте.env: в UPLOAD_LOCATION укажите каталог для оригиналов на большом диске, в DB_PASSWORD свой пароль из латинских букв и цифр.
  • Запустите docker compose up -d.
  • Откройте http://IP-сервера:2283 и создайте учётную запись администратора.

Immich на VPS: диск, HTTPS и видеокарта

На VPS главный вопрос это место под оригиналы. Архив за несколько лет съёмки на телефон легко переходит за сотню гигабайт, поэтому сначала посчитайте медиатеку, потом выбирайте диск. Тома для оригиналов и для базы лучше разнести: база любит быстрый NVMe, архиву важен объём.

Как обновить Immich в Docker и не сломать базу

Immich выходит часто, и некоторые выпуски ломают обратную совместимость. Порядок обновления из документации: прочитать заметки к выпуску, при закреплённой версии поменять IMMICH_VERSION в.env, затем выполнить docker compose pull && docker compose up -d. Старые образы удаляет docker image prune.

Immich или PhotoPrism для своего фотоархива

PhotoPrism удобен для готового архива на диске, который нужно проиндексировать и просматривать. Immich удобнее, когда фото каждый день приходят с телефонов всей семьи.

Вопросы и ответы

Как обновить Immich в Docker?

Прочитайте заметки к выпуску, затем в каталоге с compose-файлом выполните docker compose pull и docker compose up -d. Если в.env закреплена версия, сначала поменяйте IMMICH_VERSION.

Можно ли запустить Immich на 4 ГБ памяти?

Да, если выключить функции машинного обучения: так написано в требованиях Immich. Поиск по лицам и описанию фото в этом режиме работать не будет.

Нужна ли видеокарта для Immich?

Нет. Распознавание и перекодирование видео идут на процессоре, видеокарта только ускоряет их. Для начала хватит обычного сервера.

Можно ли поставить Immich на Windows?

Через Docker Desktop или WSL 2 можно, но разработчики не советуют. База Immich не работает на NTFS и на каталогах Windows, смонтированных в WSL.
