Коротко

Главная / Разработка / Terraform Установка Terraform нужна, чтобы описывать серверы текстом и создавать их одной командой: в Таймвеб Клауд серверами управляют через API, CLI и Terraform. Terraform работает на вашем компьютере, читает файлы.tf, сверяет их с облаком и создаёт недостающее, а провайдер twc подключает его к Таймвеб Клауд. Terraform окупается, когда серверы нужно создавать и удалять повторяемо: стенд под ветку, копия окружения, кластер для теста.

Конспект по разделам

Что делает Terraform и когда он нужен для VPS

Terraform это инструмент, в котором вы описываете желаемое состояние инфраструктуры в файлах формата HCL: какие серверы, диски, домены и сети должны существовать. Команда plan показывает разницу между описанием и облаком, команда apply её устраняет. Почасовая оплата делает Terraform удобным для временных стендов: сервер живёт пока идёт проверка, потом его удаляет destroy.

Установка Terraform на Ubuntu, Windows и macOS

Terraform ставится на ваш компьютер или на сервер CI, где запускаются сборки, а не на создаваемый VPS. Провайдер Таймвеб Клауд поддерживает Terraform версии 0.13 и выше, на более старых работа не заявлена. Проверка одинакова везде: terraform version.

  • Ubuntu и Debian: пакет из apt-репозитория HashiCorp либо архив с одним файлом terraform, который кладут в /usr/local/bin.
  • Windows: архив с файлом terraform.exe в каталоге из переменной PATH или менеджер пакетов.
  • macOS: пакет через Homebrew или тот же архив.

Провайдер Таймвеб Клауд для Terraform: токен и первый main.tf

Пример взят из README провайдера: сервер на 1 ядро, 1 ГБ памяти и NVMe-диск, по составу он соответствует тарифу MSK Ultra 15 (цена тарифа 1 920 ₽ в месяц на 14 октября 2026, итог для конфигуратора смотрите в панели). Значения памяти и диска задаются числами в стиле 1024 * 15. Пароль к серверу приходит на почту, а для входа по ключу используют ресурс twc_server вместе с источником данных twc_ssh_keys.

  • Создайте каталог и файл main.tf с блоком провайдера из примера.
  • Получите токен API в разделе ключей панели управления и отключите у него подтверждение удаления серверов через Telegram: документация провайдера требует этого для корректной работы.
  • Передайте токен в переменной окружения: export TWC_TOKEN=значение_токена.
  • Скачайте провайдер: terraform init.

Рабочий цикл Terraform: init, plan, apply и destroy

Провайдер умеет управлять не только серверами. В его документации перечислены ресурсы для проектов, DNS-записей ( twc_dns_rr ), S3-хранилищ, управляемых баз данных, файрвола, VPC, плавающих IP и кластеров Kubernetes ( twc_k8s_cluster ). Так что рядом с сервером можно описать и базу, и домен.

Файл состояния Terraform: где хранить и как не потерять

После первого apply рядом появляется terraform.tfstate. Это таблица соответствия между вашим описанием и реальными серверами. Потеряете её, и Terraform решит, что серверов нет, а попытка создать их заново даст дубликаты.

  • Добавьте в.gitignore строки *.tfstate и.terraform/: в состоянии бывают пароли и токены.
  • Для работы вдвоём и больше храните состояние в удалённом бэкенде, например в S3-совместимом хранилище.
  • Ценному серверу добавьте блок lifecycle { prevent_destroy = true }: тогда destroy откажется его удалять.

Вопросы и ответы

Как установить Terraform на Ubuntu для работы с Таймвеб Клауд?

Поставьте пакет из репозитория HashiCorp или распакуйте архив в /usr/local/bin, проверьте terraform version и добавьте в main.tf блок провайдера twc. После terraform init провайдер скачается.

Как установить Terraform на Windows?

Скачайте архив для Windows, положите terraform.exe в каталог из PATH и проверьте terraform version в новом окне PowerShell. Токен задавайте переменной TWC_TOKEN.

Нужен ли отдельный сервер, чтобы запускать Terraform?

Нет. Terraform работает на любом компьютере с доступом в интернет. Сервер под него нужен, только если вы запускаете его из CI или хотите хранить состояние на общей машине.

Какой токен нужен провайдеру Terraform для Таймвеб Клауд?

Токен API из панели управления. Его передают переменной TWC_TOKEN или параметром token в блоке provider. У токена должно быть отключено подтверждение удаления серверов через Telegram.
