Установка Chatwoot на свой сервер: коротко и с данными

Конспект страницы: 7 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Установка Chatwoot на свой сервер.

Коротко

Установка Chatwoot на свой сервер сводится к Docker Compose с четырьмя сервисами: rails, sidekiq, PostgreSQL и Redis. Chatwoot собирает обращения из чата на сайте, Telegram и почты в одну общую очередь, а операторы отвечают из одного окна без оплаты за каждого сотрудника. Команде до 5 операторов для старта хватит 2 ядер и 4 ГБ памяти.

Конспект по разделам

Что умеет Chatwoot и когда он нужен вместо общего почтового ящика

Chatwoot это общий ящик для поддержки: сообщения клиентов из разных мест приходят в одну ленту диалогов, их можно назначать на операторов, помечать ярлыками и отвечать готовыми шаблонами. Код открытый, поэтому программу ставят на свой сервер, а история переписки остаётся у вас. Chatwoot ближе к мессенджеру, чем к трекеру задач: диалог живёт, пока клиент отвечает.

Сколько памяти и ядер нужно Chatwoot на сервере

На странице установки в Docker минимальные ресурсы не названы, поэтому цифры ниже редакционные ориентиры, а не данные документации. Приложение состоит из четырёх частей, и все они по умолчанию работают на одном сервере. Для команды до пяти операторов начинайте с 2 ядер и 4 ГБ: в Таймвеб Клауд это MSK Ultra 50 за 5 480 ₽ в месяц на 14 октября 2026.

Установка Chatwoot через Docker Compose по шагам

Параметр ENABLE_ACCOUNT_SIGNUP=false закрывает самостоятельную регистрацию новых аккаунтов: иначе любой посетитель страницы входа сможет завести своё рабочее пространство. По умолчанию образ называется chatwoot/chatwoot:latest; для рабочего сервера на Docker Hub выберите тег вида v*-ce, это сборка Community Edition с закреплённой версией.

  • Поставьте Docker и плагин Compose по инструкции для вашей версии Ubuntu на docs.docker.com.
  • Возьмите официальные файлы из репозитория chatwoot/chatwoot: docker-compose.production.yaml (переименуйте в docker-compose.yaml ) и.env.example (сохраните как.env ).
  • Заполните.env.
  • Подготовьте базу: эта команда создаёт таблицы и первичные данные.

Домен и HTTPS для Chatwoot: без них не заработают Telegram и виджет

Telegram отправляет сообщения на вебхук Chatwoot только по HTTPS, а виджет на сайте с HTTPS откажется загружаться с адреса без шифрования. Поэтому домен нужен до подключения каналов, а не после.

  • Направьте A-запись, например chat.example.com, на IP сервера.
  • В compose-файле проверьте, что порт 3000 слушает только 127.0.0.1: наружу его выпускает прокси.
  • Поставьте перед Chatwoot Caddy: достаточно записи chat.example.com { reverse_proxy 127.0.0.1:3000 }, сертификат он получит и продлит сам.
  • Адрес из FRONTEND_URL должен совпадать с доменом буква в букву, иначе ссылки в письмах операторам поведут на localhost.

Как подключить к Chatwoot виджет, Telegram и ИИ-бота

Каналы добавляют в настройках через пункт Inboxes. Для виджета выберите Website, укажите домен сайта и скопируйте готовый скрипт на страницы. Для Telegram создайте бота у @BotFather, вставьте токен, и входящие потекут в очередь.

Резервные копии и обновление Chatwoot без потери диалогов

Состояние Chatwoot лежит в двух местах: база PostgreSQL и каталог с вложениями клиентов. Дамп базы снимайте командой pg_dump внутри контейнера postgres, вложения копируйте отдельно, а оба файла отправляйте на другой сервер: порядок описан в разборе сервер для бэкапов. Обновление выглядит так: смените тег образа, выполните docker compose pull, затем снова запустите db:chatwoot_prepare, чтобы применились миграции базы, и поднимите сервисы.

Вопросы и ответы

Какой сервер нужен для Chatwoot на 5 операторов?

Для старта 2 ядра и 4 ГБ памяти, 40 ГБ диска. Документация Chatwoot минимальных цифр не называет, поэтому наблюдайте за памятью первые недели и добавляйте её, если растёт история и вложения.

Как подключить Telegram-бота к Chatwoot?

Создать бота у @BotFather, в Chatwoot открыть Settings, Inboxes, добавить канал Telegram и вставить токен. Нужен домен с HTTPS: на него Telegram присылает сообщения.

Как обновить Chatwoot в Docker и не потерять данные?

Сделать дамп PostgreSQL, сменить тег образа, выполнить docker compose pull и db:chatwoot_prepare, затем docker compose up -d. База и вложения остаются в томах.

Можно ли подключить ИИ-ответы к Chatwoot на своём сервере?

Да, через агент-бота: Chatwoot отправляет новые сообщения на вебхук, а бот на n8n или другой платформе возвращает ответ. Спорные диалоги бот передаёт оператору.
