Конспект по разделам

Модели DeepSeek для агента: Flash и Pro

В API DeepSeek сейчас два имени моделей. Обе держат окно в 1 млн токенов, отвечают до 384 тысяч токенов, умеют JSON-ответы и вызов инструментов и работают как в режиме рассуждений (он включён по умолчанию), так и без него. API DeepSeek отвечает и в формате OpenAI, и в формате Anthropic, поэтому модели подключаются к n8n, Hermes Agent, Aider и другим инструментам без переделки.

Как агент на DeepSeek вызывает инструменты

Вызов инструментов у DeepSeek идёт в формате OpenAI: агент передаёт список функций с описаниями, модель возвращает имя функции и аргументы, ваш код выполняет действие. Поэтому DeepSeek подключается в n8n через узел OpenAI Chat Model со своим Base URL (пошагово: ИИ-агент в n8n ), а в Hermes Agent и OpenClaw как OpenAI-совместимый провайдер. Режим рассуждений полезен в многошаговых задачах: модель сначала планирует, потом действует.

Как создать ИИ-агента на DeepSeek без своего сервера

Если агент уже собран в n8n или своём коде, хватит AI Gateway: один OpenAI-совместимый ключ и оплата рублями за фактический расход. Сравнить DeepSeek с моделями Anthropic по задачам можно на странице ИИ-агент на Claude.

  • Создайте агента на платформе ИИ-агентов Таймвеб Клауд и выберите модель DeepSeek из списка.
  • Добавьте базу знаний: файлы, по которым агент должен отвечать.
  • Напишите инструкцию: роль, тон, что делать, если ответа в базе нет.
  • Подключите канал: JS-виджет на сайт или OpenAI-совместимый API для своего бота.

DeepSeek на своём железе: что реально запустить

Веса DeepSeek V4 открыты под лицензией MIT, но это большие MoE-модели (mixture of experts: на каждый токен работает только часть параметров). У V4.1-Flash 552 млрд параметров основной сети, её запускают на сервере с несколькими видеокартами, а в библиотеке Ollama она доступна только как облачная модель. На ПК реально запустить дистиллированные DeepSeek-R1: это модели Qwen и Llama, дообученные на рассуждениях R1.

Вопросы и ответы

Чем DeepSeek V4 Flash отличается от V4 Pro для агента?

Flash это более новая версия V4.1, она принимает изображения, и на неё ведут старые имена deepseek-v4-flash. Pro крупнее и картинки не понимает. Окно в 1 млн токенов и вызов инструментов есть у обеих, так что начните с Flash и переходите на Pro, если не хватает качества.

Можно ли запустить DeepSeek для ИИ-агента на обычном компьютере?

Только дистиллированные версии DeepSeek-R1 через Ollama: для 7b и 8b на старте хватит видеокарты с 8 ГБ, 14b и 32b просят больше. Полная V4 на домашнем ПК не запустится.

Как подключить ИИ-агента на DeepSeek к Telegram?

Соберите сценарий в n8n: Telegram Trigger, узел AI Agent и модель DeepSeek через OpenAI-совместимый API. Другой путь: Hermes Agent или OpenClaw, у которых есть подключение к Telegram, а DeepSeek указывается как провайдер модели.
