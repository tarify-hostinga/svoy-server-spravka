Как создать свой сервер для игры с друзьями: пять шагов

Общие приёмы, одинаковые для всех игр (служба systemd, SteamCMD, обновления), собраны в разделе об игровых серверах.

  • Проверьте, есть ли у игры сервер под Linux.
  • Подберите конфигурацию калькулятором выше: для пробы лучше взять с запасом и уменьшить потом, чем мучиться с рывками.
  • Поставьте сервер.
  • Откройте порт игры в фаерволе VPS с правильным протоколом: Factorio и Valheim работают по UDP, Minecraft Java по TCP.

Как раздать друзьям адрес и не пустить на сервер чужих

Адрес сервера это IP и порт. Домен с A-записью запоминается проще, а Minecraft Java умеет ещё и SRV-записи, тогда порт писать не нужно. Bedrock SRV-записи не читает, там порт вводят всегда.

  • Minecraft Java с версии 26.3 включает белый список по умолчанию: друзей добавляют командой whitelist add.
  • Valheim не запустится с паролем короче пяти символов.
  • Terraria умеет только пароль, белый список даёт TShock.
  • Palworld и Enshrouded закрываются паролем в файле настроек; без него сервер открыт всем.

Вопросы и ответы

Как создать свой сервер для игры с друзьями бесплатно?

Запустить сервер игры на своём компьютере: это бесплатно, но мир доступен, только пока компьютер включён, и нужен внешний IP. VPS с почасовой оплатой позволяет проверить идею за вечер и заплатить за часы.

Можно ли держать несколько игр на одном сервере для игры с друзьями?

Да, у каждой игры свой порт. Память складывается: Terraria, Factorio и TeamSpeak уживаются на 2-4 ГБ, а Rust или Palworld лучше держать на отдельном сервере.

Сколько друзей потянет сервер для игры на 4 ГБ памяти?

Зависит от игры. По вики Minecraft сам сервер на 10 и больше игроков просит 4 ГБ, Valheim на 4 ГБ работает в минимальном варианте, а Palworld и Rust на таком объёме не запустятся нормально.

Почему друзья не видят мой сервер в списке игры?

Список серверов зависит от настроек публичности и отдельного порта запросов, а подключение по адресу работает и без этого. Скрытый сервер Factorio, например, в списке не появится вовсе: друзьям нужен IP.
