Установка AUTOMATIC1111 на сервер с GPU: коротко и с данными

Конспект страницы: 6 разделов коротко, данные на 14 октября 2026 и ответы на 3 вопроса. Полный разбор с примерами: Установка AUTOMATIC1111 на сервер с GPU.

Коротко

Установка AUTOMATIC1111 на сервер сводится к скрипту webui.sh: он сам создаёт виртуальное окружение, ставит PyTorch и открывает интерфейс на порту 7860. Заранее нужны Python 3.10 или 3.11, отдельный пользователь (от root скрипт не запускается) и пароль, без которого интерфейс в интернет не выпускают. AUTOMATIC1111 по-прежнему удобен для SD 1.5 и SDXL с расширениями.

Конспект по разделам

Что такое AUTOMATIC1111 и кому он подходит

AUTOMATIC1111 (stable-diffusion-webui) это веб-интерфейс для моделей Stable Diffusion на библиотеке Gradio: вкладки txt2img и img2img, inpaint, апскейл, расширения из каталога прямо в интерфейсе. Последний релиз v1.10.1, а для новых моделей вроде FLUX сами авторы Fooocus советуют форк Forge и ComfyUI. Какие модели запускать и сколько памяти им нужно, разобрано на странице установка Stable Diffusion.

Установка AUTOMATIC1111 на Ubuntu через webui.sh

  • Поставьте пакеты из официальной инструкции и драйвер NVIDIA.
  • Создайте пользователя. webui.sh от root завершается с ошибкой «must not be launched as root», обходить это флагом -f не нужно.
  • Поставьте Python 3.11 на Ubuntu 24.04.
  • Запустите скрипт.

Флаги AUTOMATIC1111 для работы на сервере

Флаги пишут в webui-user.sh строкой export COMMANDLINE_ARGS="...". Для сервера важны пять: Флаг --allow-code разрешает запуск произвольного Python из интерфейса, на сервере с открытым доступом его не включают. Пароль из --gradio-auth без HTTPS виден любому на пути трафика, поэтому снаружи ставят Caddy или Nginx с сертификатом, а AUTOMATIC1111 оставляют на 127.0.0.1.

AUTOMATIC1111 в Docker Compose: какие сборки есть

Официального образа нет. Вики проекта перечисляет сборки сообщества от neggles, emsi, AbdBarho и camenduru. У AbdBarho два шага: профиль download скачивает около 12 ГБ моделей, профиль auto запускает интерфейс на порту 7860.

Как держать AUTOMATIC1111 запущенным после перезагрузки

Запуск из консоли живёт до закрытия SSH-сессии. Служба systemd стартует интерфейс вместе с сервером и перезапускает после падения: Файл кладут в /etc/systemd/system/a1111.service и включают командой sudo systemctl enable --now a1111.

Вопросы и ответы

Почему webui.sh AUTOMATIC1111 не запускается от root?

Так задумано авторами: скрипт по умолчанию отказывается работать от root. Создайте обычного пользователя и ставьте интерфейс в его домашнюю папку.

Как поставить пароль на AUTOMATIC1111?

Флагом --gradio-auth логин:пароль или файлом через --gradio-auth-path, пар можно указать несколько через запятую. Без HTTPS пароль идёт открытым текстом, поэтому снаружи нужен прокси с сертификатом.

Чем Forge отличается от AUTOMATIC1111?

Forge это форк AUTOMATIC1111 от автора Fooocus: экономнее расходует видеопамять и умеет FLUX в форматах NF4 и GGUF. Ставится так же, через git clone и webui-user.
