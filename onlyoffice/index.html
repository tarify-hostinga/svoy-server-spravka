Установка ONLYOFFICE на свой сервер: коротко и с данными

Конспект страницы: 7 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Установка ONLYOFFICE на свой сервер.

Коротко

Главная / Для офиса / ONLYOFFICE Установка ONLYOFFICE Docs сводится к одному контейнеру onlyoffice/documentserver с ключом JWT_SECRET: сервер документов принимает файлы от Nextcloud или другого облака и открывает их в браузере. Документация просит минимум два ядра, 4 ГБ памяти и 40 ГБ диска. Для старта хватит 2 ядер и 4 ГБ памяти с подкачкой не меньше 4 ГБ.

Конспект по разделам

Что такое ONLYOFFICE Docs и чем он отличается от Collabora Online

ONLYOFFICE Docs это сервер документов: он умеет открывать и править тексты, таблицы и презентации прямо в браузере, а хранить файлы сам не умеет. Файлы лежат в облаке вроде Nextcloud или Seafile, редактор подключается к нему как приложение. Исходный код открыт, редакция Community бесплатна, у неё есть ограничение на число одновременных подключений: точную цифру для вашей версии смотрите на сайте ONLYOFFICE.

Сколько ресурсов нужно ONLYOFFICE Docs

Потому серверу нужна память под несколько служб сразу, а не только под редактор. Минимальная готовая конфигурация Таймвеб Клауд, закрывающая справку, это 2 vCPU и 4 ГБ памяти (MSK Ultra 50, 5 480 ₽ в месяц на 14 октября 2026). Если на этом же сервере будет и Nextcloud, берите больше.

Установка ONLYOFFICE Docs в Docker на Ubuntu

Порт привязан к 127.0.0.1, потому что наружу сервер документов выходит через прокси с HTTPS. Без параметра JWT_SECRET, по справке ONLYOFFICE, секрет создаётся заново при каждой перезагрузке и ломает связанные сервисы. Для Debian и систем на RPM есть пакеты без Docker, но контейнер проще обновлять; порядок для Astra Linux, ALT Linux и РЕД ОС смотрите в документации самого дистрибутива.

  • Поставьте Docker с плагином Compose: на чистой Ubuntu подойдёт официальный скрипт curl -fsSL https://get.docker.com | sh.
  • Придумайте длинный секрет для JWT, например командой openssl rand -hex 24, и запишите его: он понадобится при подключении к Nextcloud.
  • Создайте файл docker-compose.yml с содержимым ниже и запустите docker compose up -d.
  • Проверьте работу: адрес http://127.0.0.1:8081/healthcheck должен вернуть true, а страница /welcome/ показывает, что сервер документов запущен.

Поддомен и HTTPS для ONLYOFFICE Docs

Браузеру нужен HTTPS, иначе Nextcloud на защищённом адресе не станет грузить редактор с обычного http. Заведите поддомен, например office.example.com, направьте его на сервер и поставьте перед контейнером прокси, то есть программу, которая принимает HTTPS и передаёт запросы дальше. В Caddy хватает двух строк: имя поддомена и reverse_proxy 127.0.0.1:8081, сертификат он получит сам.

Как подключить ONLYOFFICE Docs к Nextcloud

Ловушка: если сервер документов имеет частный адрес, Nextcloud откажется к нему обращаться, пока в config.php не включён параметр allow_local_remote_servers. Для Collabora схема другая: приложение Nextcloud Office, а у контейнера переменная domain с адресом облака, где точки экранированы обратной косой чертой.

  • В Nextcloud откройте магазин приложений, раздел «Офис и текст», и установите приложение ONLYOFFICE.
  • В настройках администратора впишите адрес сервера документов, например https://office.example.com/, и тот же JWT-секрет.
  • Если оба сервера стоят в одной сети, заполните в дополнительных настройках внутренние адреса, чтобы запросы шли по локальной сети.
  • Откройте файл docx: он должен загрузиться в редакторе, а после закрытия сохраниться в Nextcloud.

Копии и обновление ONLYOFFICE Docs без потери правок

Документы остаются в Nextcloud, сервер ONLYOFFICE хранит только временные данные сессий, шрифты и настройки. Поэтому копировать нужно файл compose с секретом и каталоги томов, особенно если вы добавляли собственные шрифты. Полный порядок копий: сервер для бэкапов.

Вопросы и ответы

Какой сервер нужен для установки ONLYOFFICE Docs?

По справке ONLYOFFICE: два ядра от 2 ГГц, 4 ГБ памяти, подкачка не меньше 4 ГБ и 40 ГБ свободного диска. Если рядом работает Nextcloud, ресурсы суммируют.

Как установить ONLYOFFICE на Ubuntu через Docker?

Поставить Docker, запустить образ onlyoffice/documentserver с параметром JWT_SECRET и пробросом порта 80, проверить адрес /healthcheck и закрыть порт снаружи за прокси с HTTPS.

Зачем ONLYOFFICE нужен JWT_SECRET?

Это общий ключ между сервером документов и облаком: по нему они проверяют друг друга. Без заданного значения ключ создаётся заново при перезагрузке и подключение перестаёт работать.

Можно ли поставить ONLYOFFICE и Nextcloud на один сервер?

Да, но ресурсы складываются, а каждому нужен свой поддомен и HTTPS. Для командной работы разумнее разнести их на разные серверы или выделить ONLYOFFICE отдельный контейнер с запасом памяти.
