Сервер работает на Linux, по умолчанию держит 50 игроков на порту 7777, а свежая версия 1.6.7 вышла 14 октября 2026 года. Конспект по разделам

SA-MP или open.mp: на чём поднимать сервер сампа

open.mp появился как открытая замена серверу SA-MP и остаётся совместимым с ним: параметр network.allow_037_clients по умолчанию включён, и игроки заходят с привычного клиента 0.3.7. Проект живой: в списке релизов на GitHub есть версии с 1.1 по 1.6, последняя 1.6.7.3218 опубликована 14 октября 2026 года. Сервер по умолчанию анонсирует себя в списке серверов open.mp ( announce: true ).

Сколько ресурсов нужно серверу open.mp

Сервер open.mp на десятки игроков нетребователен, а вот ролевой мод с домами, бизнесами и базой MySQL уже просит память и быстрый диск. Если планируете тестовый сервер для разработки мода рядом с основным, закладывайте его в расчёт сразу. Режим, онлайн и база данных: калькулятор подберёт конфигурацию

Установка сервера open.mp на Ubuntu

Общая схема работы с игровыми серверами на Linux есть в разделе об играх.

  • Скачайте архив для Linux со страницы релизов openmultiplayer/open.mp на GitHub.
  • Создайте конфиг по умолчанию командой./omp-server --default-config, если в архиве его нет.
  • Положите свой мод (.amx) в gamemodes и пропишите его в pawn.main_scripts.
  • Откройте порт 7777 в фаерволе и запустите./omp-server службой systemd, чтобы сервер поднимался после перезагрузки.

Главные настройки config.json сервера open.mp

Значения можно подставлять из переменных окружения, например пароль из Environment= в службе systemd: так секреты не лежат в файле рядом с модом.

Как перенести мод SA-MP на open.mp и что сохранять

Игроки подключаются из клиента SA-MP по адресу IP-сервера:7777. В резервную копию идут папки gamemodes, scriptfiles с данными игроков и дамп базы, если мод работает с MySQL. Архивы храните вне VPS, порядок разобран на странице о бэкапах.

  • Мод: в исходнике замените #include <a_samp> на #include <open.mp> и перекомпилируйте в qawno.
  • Плагины: части понадобятся сборки под open.mp, а Pawn.CMD, Pawn.RakNet и похожие кладутся в components, не в plugins.
  • server.cfg переводят в config.json по отдельному руководству в документации open.mp.

Вопросы и ответы

Сколько стоит хостинг для сампа на своём VPS?

На 14 октября 2026 конфигурация с 1 ядром и 1 ГБ стоит 1 920 ₽ в месяц, с 2 ГБ памяти стоит 3 000 ₽. Второй вариант удобнее для ролевого мода с MySQL.

Можно ли зайти на сервер open.mp с клиента SA-MP 0.3.7?

Да. В config.json параметр network.allow_037_clients по умолчанию равен true, поэтому игрокам ничего переустанавливать не нужно.

Можно ли поднять сервер CR-MP на своём VPS?

Официального актуального серверного пакета CR-MP мы не нашли и инструкцию не публикуем. Для своего проекта на движке San Andreas надёжнее взять open.mp и написать или адаптировать мод на Pawn.

Нужна ли база MySQL для сервера сампа?

Самому open.mp она не нужна. MySQL используют ролевые моды для аккаунтов, домов и бизнесов через отдельный плагин, а простые режимы хранят данные в файлах scriptfiles.
