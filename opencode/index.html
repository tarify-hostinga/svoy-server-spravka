Установка OpenCode на свой сервер: коротко и с данными

Конспект страницы: 5 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Установка OpenCode на свой сервер.

Коротко

Установка OpenCode на сервер занимает одну команду, но сначала выберите ветку: вышел OpenCode 2, а документация OpenCode 1 ещё живёт рядом. Обе версии ставят команду opencode и не уживаются на одной машине под одним именем. OpenCode не держит модель у себя, поэтому для старта хватит 1 ядра и 2 ГБ памяти плюс запас под проект.

Конспект по разделам

OpenCode 1 или OpenCode 2: что ставить на сервер

OpenCode: открытый агент для программирования с интерфейсом в терминале, приложением для компьютера и веб-версией. Модель он не содержит: вы подключаете провайдера и платите ему за токены. Для нового сервера логичен OpenCode 2.

Установка OpenCode на Ubuntu и в Docker

В Docker образы второй версии помечены номером версии, поэтому закрепляйте тег, например 2.0.0, вместо плавающего. Каталог проекта подключайте томом, иначе правки агента пропадут вместе с контейнером. Интерфейс OpenCode рассчитан на современный эмулятор терминала: WezTerm, Alacritty, Ghostty или Kitty.

  • Поставьте OpenCode 2 скриптом или через npm (команды ниже).
  • Откройте каталог проекта и запустите opencode.
  • Подключите провайдера командой /connect и выберите модель через /models.

Какие модели подключаются к OpenCode

OpenCode берёт каталог моделей из Models.dev и через библиотеку AI SDK поддерживает больше 75 провайдеров, а также локальные модели. Подписки ChatGPT Plus, GitHub Copilot и GitLab Duo работают без дополнительной настройки. Подписки Claude Pro и Max подключать запрещает Anthropic, и с версии 1.3.0 плагинов для этого в поставке нет.

Как открыть веб-интерфейс OpenCode на сервере безопасно

В OpenCode 1 команда opencode serve по умолчанию слушает адрес 127.0.0.1 и порт 4096, а opencode web берёт случайный порт. Без переменной OPENCODE_SERVER_PASSWORD сервер открыт всем, кто до него дотянется, документация прямо пишет, что пароль нужен для доступа по сети. Имя пользователя по умолчанию: opencode.

Вопросы и ответы

Можно ли поставить OpenCode 1 и OpenCode 2 на один сервер?

Под стандартным именем нет: обе версии используют команду opencode. Держите их у разных пользователей или в разных контейнерах.

Как запустить OpenCode в Docker?

Образы лежат в ghcr.io/anomalyco/opencode, для второй версии с тегом версии, например 2.0.0. Запускайте контейнер интерактивно и подключайте каталог проекта томом.

Как установить OpenCode на Windows?

Документация советует WSL. В первой версии есть пакеты для Chocolatey и Scoop, во второй менеджеры пакетов Windows не поддерживаются, зато есть отдельные сборки.

Как подключить к OpenCode свой OpenAI-совместимый API?

Опишите провайдера в opencode.json: пакет openai-compatible, адрес в baseURL и список моделей, ключ передайте через переменную окружения.
