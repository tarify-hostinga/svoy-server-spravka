Хостинг для раст сервера на своём VPS: коротко и с данными

Конспект страницы: 6 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Хостинг для раст сервера на своём VPS.

Коротко

Хостинг для раст сервера требует много памяти: Facepunch просит 12 ГБ свободной оперативной памяти под карту стандартного размера и SSD-диск. Сам сервер бесплатно скачивается через SteamCMD под Linux и Windows, а плагины добавляет Oxide или Carbon. Rust из тяжёлых: даже для компании друзей смотрите на 16 ГБ памяти и NVMe.

Конспект по разделам

Сколько памяти нужно серверу Rust

На вики Facepunch требования к серверу короткие: 12 ГБ свободной оперативной памяти, 15 ГБ места на диске, желательно SSD или NVMe. Там же оговорка, что карта размером 6000 съест больше памяти. Главная ручка здесь размер карты server.worldsize: допустимы значения от 1000 до 6000, в примере вики стоит 4000.

Установка сервера Rust на Ubuntu через SteamCMD

Аккаунт Steam для загрузки сервера не нужен, он понадобится только игрокам. Общая подготовка Linux к игровым серверам описана в разделе об играх, ниже команды для Rust. Первый запуск идёт долго: сервер генерирует карту по сиду.

Параметры запуска сервера Rust: имя, слоты, карта и RCON

Постоянные настройки можно не писать в командную строку, а положить в server/<identity>/cfg/server.cfg: сервер читает его при старте.

Плагины для сервера Rust: Oxide (uMod) и Carbon

Официального API плагинов у Rust нет. Вики Facepunch отправляет за ним к Oxide: сборки для Windows и Linux лежат на сайте uMod, архив распаковывают поверх папки сервера. Вторая платформа, Carbon, упоминается на той же вики как фреймворк для модов.

Порты сервера Rust, подключение друзей и вайп

Мобильное приложение Rust+ работает по TCP на отдельном порту app.port. Друзья подключаются из консоли игры (F1): client.connect IP-сервера:28015. Всё состояние сервера лежит в папке server/<identity>: карта, сохранение мира, чертежи игроков, конфиги.

Вопросы и ответы

Сколько стоит держать сервер Раст в месяц?

Конфигурация с 8 ядрами, 16 ГБ памяти и 160 ГБ NVMe на 14 октября 2026 стоит 20 040 ₽ в месяц. Почасовая оплата позволяет держать сервер только в активные недели после вайпа.

Какой сервер нужен для Раста на компанию из пяти друзей?

Ориентир тот же: 12 ГБ свободной памяти по рекомендации Facepunch. Сэкономить помогает уменьшенная карта, например worldsize 2500-3000, и отказ от тяжёлых плагинов.

Нужно ли покупать Rust, чтобы запустить свой сервер Раст?

Для загрузки сервера нет: SteamCMD скачивает его с анонимным входом. Купленная игра нужна каждому, кто будет на сервере играть.

Как сделать вайп на своём сервере Раст?

Остановите сервер, сохраните архив папки server/identity, удалите из неё файлы карты и сохранения и запустите сервер с новым server.seed. Чертежи игроков лежат отдельно, их стирают только при полном вайпе.
