Коротко

Главная / Игры / Minecraft Bedrock Сервер майнкрафт бедрок Mojang выпускает сама: Bedrock Dedicated Server бесплатно скачивается для Windows и Ubuntu и принимает игроков с телефонов, планшетов и Windows-версии игры. На VPS он работает круглосуточно, а настройка сводится к трём файлам рядом с программой. Берите VPS на Ubuntu 22.04 или новее с 2 ядрами и 4 ГБ памяти: другие дистрибутивы Mojang не поддерживает.

Чем сервер Bedrock отличается от сервера Minecraft Java

Bedrock это версия игры для Android, iOS, Windows и консолей, и сервер для неё другой программой, чем Java-сервер. Игроки Java на него не попадут, и наоборот. Если в компании и Java-, и Bedrock-игроки, удобнее один Java-сервер на Paper с плагином Geyser: он принимает телефоны на UDP-порту 19132.

Установка Bedrock-сервера на Ubuntu

Готовый образ Minecraft BE есть в маркетплейсе Таймвеб Клауд: на 14 октября 2026 его поставили 812 раз. Ручная установка тоже короткая. Docker-вариант это образ itzg/minecraft-bedrock-server.

  • Скачайте архив для Ubuntu со страницы Bedrock Dedicated Server на minecraft.net: ссылка меняется с каждой версией, поэтому берите её оттуда.
  • Распакуйте его в отдельную папку, например /srv/bedrock, и запустите LD_LIBRARY_PATH=../bedrock_server.
  • Оформите запуск службой systemd или держите сервер в tmux, чтобы он пережил закрытие SSH.
  • Откройте порты из таблицы ниже и перезапустите сервер после правки настроек.

server.properties, allowlist.json и порты Bedrock-сервера

Главные строки server.properties и их значения в сборке 1.26.52.3: server-name=Dedicated Server, max-players=10, gamemode=survival, difficulty=easy, view-distance=32, level-name=Bedrock level. Параметр online-mode=true проверяет учётную запись Microsoft игрока, выключать его на открытом сервере не нужно. В свежих сборках включён allow-list=true: пустой список не пустит никого.

Как друзья заходят на Bedrock-сервер и как сохранить мир

На телефоне игрок открывает вкладку «Серверы», нажимает «Добавить сервер» и вводит IP и порт 19132. Домен можно направить A-записью на IP, но порт придётся вводить всё равно: SRV-записи Bedrock не читает. Миры лежат в папке worlds.

Вопросы и ответы

Можно ли сделать сервер Bedrock для майнкрафт ПЕ на телефоне друга?

Мир на телефоне живёт, пока открыта игра у хозяина. Выделенный сервер на VPS работает без него, и заходить можно в любое время.

Как установить аддон на сервер майнкрафт бедрок?

Распакуйте набор поведения в behavior_packs, ресурс-пак в resource_packs и подключите их к миру в файлах world_behavior_packs.json и world_resource_packs.json внутри папки мира. Затем перезапустите сервер: перезагрузки на лету у Bedrock нет.

Сколько игроков выдержит сервер майнкрафт бедрок?

По умолчанию max-players равен 10, значение можно поднять. Вики Minecraft предупреждает, что после 10 одновременных игроков может понадобиться больше 4 ГБ памяти.

Почему сервер Bedrock не виден с Xbox и PlayStation?

На консолях нет кнопки добавления своего сервера: по вики Minecraft подключение возможно только через сторонний DNS или локальную сеть. Для смешанной компании проверьте этот путь заранее.
