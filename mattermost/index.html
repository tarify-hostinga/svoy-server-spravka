Коротко

Главная / Для офиса / Mattermost Установка Mattermost через Docker Compose даёт два контейнера, PostgreSQL и приложение на порту 8065, а третий, Nginx, принимает HTTPS и передаёт запросы приложению. Конспект по разделам

Что такое Mattermost и чем он отличается от Slack

Mattermost это корпоративный чат с каналами, ветками обсуждений, файлами, ботами и вебхуками для интеграций. Он написан на Go, хранит данные в PostgreSQL и работает на вашем сервере, поэтому переписка не покидает компанию. Интерфейс знаком каждому, кто пользовался Slack, так что обучать команду почти не придётся.

Сколько людей выдержит один сервер с Mattermost

Чат нагружает сервер слабо, пока люди печатают, и сильнее, когда они присылают файлы и подключают много интеграций. Для старта хватит 2 ядер и 4 ГБ на команду до 50 человек, на 50-200 человек закладывайте 4 ядра и 8 ГБ, а за пределами этого сверяйтесь с руководством по масштабированию. Базу лучше вынести отдельно, если не хочется делить память между приложением и PostgreSQL.

Установка Mattermost через Docker Compose по шагам

Docker в документации Mattermost назван пробным вариантом Страница разработчиков предупреждает: развёртывание в контейнерах подходит для знакомства, тестов и разработки и не даёт отказоустойчивости. Для одной команды на одном сервере это не мешает работе, но обновления и копии лежат целиком на вас. Если нужна высокая доступность, документация советует Kubernetes.

  • Поставьте Docker Engine и плагин Compose на Linux-сервер, в документации требуется Compose версии 1.28 или новее.
  • Склонируйте репозиторий и создайте файл настроек из примера.
  • Откройте.env и впишите в DOMAIN адрес сервера.
  • Создайте каталоги для данных и отдайте их пользователю с номером 2000, от его имени работает приложение.

Домен и HTTPS для Mattermost: встроенный Nginx или Caddy

Набор из репозитория умеет поднять Nginx третьим контейнером: он слушает 443 и берёт сертификат из каталога, указанного в переменных CERT_PATH и KEY_PATH файла.env. Сертификат Let's Encrypt выпускает скрипт bash scripts/issue-certificate.sh -d chat.example.com -o $PWD/certs, подробнее про выпуск сертификатов: Certbot. Если на сервере уже работает свой прокси, запустите набор без Nginx командой с файлом docker-compose.without-nginx.yml, приложение откроется на порту 8065.

Мобильные приложения Mattermost и push-уведомления

Приложения для Android и iOS подключаются к вашему адресу сервера, отдельная настройка в магазинах не нужна. Если HTTPS настроен с настоящим сертификатом, вход работает так же, как в браузере. Сообщения на заблокированный экран приходят через сервис push-уведомлений, адрес которого задаётся в консоли системного администратора.

Резервные копии и обновление Mattermost

В Mattermost две части состояния: база PostgreSQL с сообщениями и каталог volumes/app/mattermost/data с загруженными файлами. Копируйте оба вместе по расписанию и проверяйте, что архив разворачивается: схемы хранения и проверки описаны в разделе сервер для бэкапов, а выгрузка базы командой pg_dump разобрана на странице установка PostgreSQL. Обновление идёт так: остановите контейнеры, выполните git pull в каталоге с набором и посмотрите, не изменился ли env.example, затем поменяйте MATTERMOST_IMAGE_TAG в.env и запустите заново.

Вопросы и ответы

Как развернуть Mattermost на своём сервере?

Поставьте Docker, склонируйте репозиторий mattermost/docker, впишите домен в.env, создайте каталоги данных и запустите docker compose. Первый зарегистрированный пользователь станет администратором.

Какой порт использует Mattermost?

Приложение слушает 8065. Если вы запускаете набор с Nginx, снаружи нужны 80 и 443, а сам порт 8065 закрывают файрволом. Для звонков плагина Calls отдельно открывают 8443.

Можно ли запускать Mattermost в Docker в рабочей среде?

Документация относит Docker к пробным установкам: в нём нет отказоустойчивости. Для одной команды на одном сервере это допустимо, если настроены копии базы и каталога data. Иначе ставьте из архива под systemd.

Сколько человек выдержит Mattermost на 4 ГБ памяти?

Для команды до 50 человек этого хватит на старте. Если вложений много и подключены интеграции, смотрите на расход памяти в мониторинге и добавляйте ядра и гигабайты по калькулятору выше.
