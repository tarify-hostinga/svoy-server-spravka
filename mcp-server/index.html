Установка MCP-сервера на свой VPS: коротко и с данными

Конспект страницы: 6 разделов коротко, данные на 14 октября 2026 и ответы на 3 вопроса. Полный разбор с примерами: Установка MCP-сервера на свой VPS.

Коротко

Установка MCP-сервера на VPS нужна, когда инструментами для ИИ пользуются с разных компьютеров или из облачных агентов: локальный сервер через stdio доступен только своей машине. Удалённый сервер работает по транспорту Streamable HTTP на одном адресе вроде /mcp, и без авторизации он становится открытым пультом к вашим данным. Для своих инструментов хватит 1 ядра и 1-2 ГБ памяти.

Конспект по разделам

Что такое MCP-сервер и чем он отличается от ИИ-агента

MCP (Model Context Protocol) это открытый протокол, по которому ИИ-клиент подключается к внешним инструментам и данным. MCP-сервер публикует инструменты (функции, которые модель может вызвать), ресурсы (данные для чтения) и шаблоны запросов. Клиентом выступает Claude Desktop, Cursor, IDE или ваш собственный агент.

stdio или HTTP: какой транспорт MCP выбрать для сервера

Streamable HTTP заменил прежний транспорт HTTP+SSE из ранней версии протокола. Спецификация требует от такого сервера проверять заголовок Origin у каждого подключения (защита от DNS rebinding). Ещё два правила она рекомендует: при локальном запуске слушать только 127.0.0.1, а не 0.0.0.0, и проверять подлинность всех подключений.

Как развернуть MCP-сервер на Python в Docker

В compose-файле для этого сервиса укажите network_mode: host и restart: unless-stopped. Минимальная защита на Caddy: запросы без нужного токена получают 401 ещё до сервера.

  • Напишите сервер на официальном Python SDK (нужен Python 3.11+, пакет mcp[cli] ): инструмент это функция с аннотациями типов и описанием.
  • Запустите его на HTTP командой mcp run server.py --transport streamable-http: клиент найдёт его по адресу http://localhost:8000/mcp.
  • Упакуйте в контейнер с сетью хоста, чтобы порт 8000 остался на loopback сервера.
  • Поставьте HTTPS-прокси с проверкой токена и выдайте клиентам адрес https://mcp.example.com/mcp.

Как защитить MCP-сервер, открытый в интернет

Инструмент MCP выполняет действие от имени владельца ключей: удаляет запись в CRM, отправляет письмо, читает файл. Открытый без авторизации сервер позволяет делать это любому, кто знает адрес.

  • Авторизация обязательна.
  • Никакого проброса токенов.
  • Минимум прав.
  • Осторожно с инструментами, которые ходят по ссылкам: через них возможна подделка запросов к внутренним адресам (SSRF).

Сколько ресурсов нужно MCP-серверу на VPS

Протокол лёгкий: ресурсы потребляют инструменты, а не MCP. Сервер с запросами к API живёт на младшей конфигурации, браузер или обработка документов требуют памяти. У Docker есть каталог готовых MCP-серверов в контейнерах и шлюз MCP Toolkit, но и для них правила выше не меняются.

Вопросы и ответы

Как развернуть MCP-сервер, чтобы им пользовались из Claude или Cursor с разных компьютеров?

Запустить его на транспорте Streamable HTTP, поставить перед ним HTTPS-прокси с авторизацией и прописать в клиенте адрес вида https://mcp.example.com/mcp с токеном.

Чем ИИ-агент отличается от MCP-сервера?

Агент планирует и принимает решения с помощью модели. MCP-сервер ничего не решает: он по стандартному протоколу даёт агенту инструменты и данные.

Нужен ли MCP-серверу мощный VPS?

Обычно нет: сам протокол почти не тратит ресурсов. Мощность нужна, если инструмент запускает браузер, обрабатывает файлы или рядом работает модель.
