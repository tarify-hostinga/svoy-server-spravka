Nuxt: хостинг, установка и деплой на сервер, коротко и с данными

Конспект страницы: 6 разделов коротко, данные на 14 октября 2026 и ответы на 5 вопросов. Полный разбор с примерами: Nuxt: хостинг, установка и деплой на сервер.

Коротко

Nuxt хостинг зависит от режима сборки: статический сайт после nuxt generate отдаётся любым веб-сервером, а сайту с серверным рендерингом (SSR) нужен постоянно работающий процесс Node.js. Nuxt входит в список фреймворков платформы деплоя из Git, а для SSR на своём сервере хватает PM2 и Nginx. Статический Nuxt проще отдать платформе деплоя из Git, SSR запускают как процесс Node.js в Docker или под PM2 на VPS.

Конспект по разделам

Какой хостинг нужен Nuxt: статика, SSR или гибрид

Серверный рендеринг собирает HTML на сервере при каждом запросе, то есть сначала приходит готовая страница, а уже потом оживает скрипт. Это важно для сайтов, которые индексируют поисковики, но стоит процесса Node.js и памяти. Статика дешевле и проще: страницы готовы заранее.

Установка Nuxt: создание проекта и первая сборка

Перед установкой поставьте Node.js: порядок описан на странице установка Node.js. Дальше три команды: Режим разработки открывает сайт на порту 3000. Для сервера выполняют npm run build: в каталоге.output появляется готовый сервер с зависимостями внутри.

Nuxt на App Platform: деплой из Git

В списке фреймворков платформы деплоя Таймвеб Клауд значатся Angular, Ember, Next.js, Nuxt, Preact, React, Svelte, Vue и обычный HTML/CSS/JS. Репозиторий подключают с GitHub, GitLab, Bitbucket или по адресу любого git. SSL выпускается и продлевается автоматически, свой домен привязывается, прошлую версию можно вернуть одной кнопкой, логи доступны в панели.

Nuxt на VPS: PM2, кластерный режим и Nginx

Документация Nuxt предлагает запускать сервер под PM2 с файлом ecosystem.config.cjs: Запуск: pm2 start ecosystem.config.cjs, затем pm2 save и pm2 startup для автозапуска. Значение instances: 'max' создаёт процесс на каждое ядро; на небольшом сервере лучше два процесса, так как каждый держит свою копию приложения в памяти. Снаружи ставят Nginx или Caddy, который принимает HTTPS и передаёт запросы на порт 3000.

Nuxt в Docker: Dockerfile для SSR-сборки

Второй этап копирует только каталог.output, поэтому в итоговом образе нет исходников и node_modules. Если контейнер недоступен снаружи, проверьте публикацию порта в команде docker run -p 3000:3000 и то, что приложение слушает 0.0.0.0, а не 127.0.0.1.

Вопросы и ответы

Какой хостинг подойдёт для сайта на Nuxt?

Для статики любой: платформа деплоя, веб-сервер или CDN. Для SSR нужен хостинг с постоянным процессом Node.js: платформа с Docker или VPS.

Чем nuxt generate отличается от nuxt build?

Первая команда создаёт готовые HTML-файлы в.output/public, вторая собирает сервер в.output/server. Выбор зависит от режима рендеринга сайта.

Как запустить Nuxt на сервере после сборки?

Командой node.output/server/index.mjs, лучше под PM2 или systemd, чтобы процесс поднимался после сбоя и перезагрузки.

Сколько памяти нужно Nuxt на VPS?

Для старта SSR хватит 1-2 ГБ: процесс небольшого сайта обычно занимает сотни мегабайт, а сборка требует больше, поэтому её лучше выполнять вне рабочего сервера.

Можно ли запустить Nuxt вместе с базой и Redis через Docker Compose?

Да. Описывают сервисы nuxt, db и redis, а порт Nuxt публикуют только на локальном адресе, чтобы наружу сайт выходил через прокси.
