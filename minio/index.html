Коротко

Установка MinIO в 2026 году устроена иначе, чем в старых инструкциях: по README репозитория community-версия распространяется только исходным кодом, готовых бинарников нет, а сам репозиторий помечен как неподдерживаемый и заархивирован 25 апреля 2026. Поставить MinIO как свой S3 всё ещё можно, но обновления безопасности от разработчиков ждать не придётся. Свой S3 на MinIO поднимается за несколько команд, но проект больше не обновляется.

Конспект по разделам

Что случилось с MinIO и стоит ли ставить его сейчас

MinIO это объектное хранилище, совместимое с протоколом Amazon S3: приложения складывают в него файлы по ключам так же, как в облачный S3. Лицензия исходного кода AGPLv3. По README репозитория на 15 октября 2026: community-версия распространяется только исходным кодом, готовых бинарников больше не будет, старые остаются на GitHub и dl.min.io без обновлений.

Что нужно для установки MinIO из исходников

Готовых требований по железу в README нет, зато есть требование к сборке: минимальная версия Go 1.24. Дальше всё определяет диск: MinIO в одиночном режиме хранит объекты как обычные файлы в каталоге, который вы указываете при запуске. Объём данных и число клиентов, которые будут обращаться к хранилищу

Установка MinIO на Ubuntu: сборка, ключи и служба systemd

Вместо службы можно собрать образ Docker: README описывает последовательность из команды go build в корне исходников и затем docker build -t myminio:minio.. Образ из публичного реестра без обновлений ставить не стоит: вы не узнаете, какие исправления в нём уже есть, а каких нет.

  • Поставьте Go не ниже 1.24 с go.dev/dl: версия из репозитория Ubuntu может оказаться старше.
  • Соберите программу командой go install github.com/minio/minio@latest.
  • Создайте пользователя и каталог для данных, например /data/minio.
  • Задайте ключи в файле /etc/default/minio: MINIO_ROOT_USER и длинный MINIO_ROOT_PASSWORD.

Доступ к MinIO: порты 9000 и 9001, HTTPS и ключи для приложений

Приложениям нужен адрес S3 API с HTTPS, консоли нужен отдельный закрытый вход. Поставьте перед MinIO Caddy с двумя поддоменами: s3.example.com на порт 9000 и console.example.com на порт 9001, второй закройте по IP или паролем. Для приложений не используйте корневой ключ.

Чем заменить MinIO: AIStor, управляемый S3 и другие самостоятельные хранилища

Для копий серверов, вложений и файлов приложений чаще всего нужен просто адрес S3, а не сам сервер хранилища. Вопросы и ответы

Можно ли ещё устанавливать MinIO в 2026 году?

Можно собрать из исходников: README требует Go 1.24 и команду go install. Но проект не поддерживается, готовых бинарников нет, а старые бинарники больше не получают обновлений.

На каких портах работает MinIO?

S3 API слушает порт 9000. Веб-консоль работает на случайном порту, пока вы не зададите флаг --console-address, обычно выбирают 9001.

Чем заменить MinIO для хранения копий?

Управляемым S3 у провайдера, AIStor Free от разработчиков MinIO или другим S3-совместимым проектом с открытым кодом. Для копий управляемое хранилище проще всего в обслуживании.

Какая лицензия у MinIO?

Исходный код MinIO распространяется по лицензии GNU AGPLv3, документация по CC BY 4.0. Поддержка в README описана как best-effort через GitHub и Slack.
