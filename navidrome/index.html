Navidrome в Docker на своём сервере: коротко и с данными

Конспект страницы: 6 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Navidrome в Docker на своём сервере.

Коротко

Главная / Self-hosted / Navidrome Navidrome в Docker превращает папку с вашей музыкой в личный стриминговый сервис: один контейнер deluan/navidrome, порт 4533 и два тома, для данных и для музыки. Слушать можно в браузере или в любом плеере с поддержкой API Subsonic на телефоне и компьютере. Navidrome хватает 1 ядра и 1 ГБ памяти, сервер выбирают по размеру коллекции.

Конспект по разделам

Что такое Navidrome и зачем свой музыкальный сервер

Navidrome это музыкальный сервер с открытым кодом под лицензией GPL-3.0. Он сканирует папку с вашими альбомами, читает теги и обложки, следит за новыми файлами и отдаёт музыку в веб-плеер и в приложения. Каждому члену семьи можно завести свою учётную запись с плейлистами и избранным.

Сколько ресурсов нужно Navidrome на VPS

Официального минимума у Navidrome нет: разработчики пишут о низком потреблении ресурсов и поддержке очень больших коллекций. На практике всё решает диск: тот же альбом во FLAC весит в несколько раз больше, чем в MP3, так что lossless-коллекция быстро упирается в объём NVMe. Перед переездом посчитайте размер папки с музыкой командой du -sh и добавьте запас на новые покупки.

Установка Navidrome через Docker Compose

Обновление: docker compose pull и docker compose up -d. База, пользователи и плейлисты лежат в томе data, именно его нужно включить в резервные копии.

  • Загрузите музыку в /srv/music по SFTP или rsync, по папке на исполнителя и альбом.
  • Проверьте права: пользователь 1000 должен владеть каталогом data и читать каталог с музыкой.
  • Запустите docker compose up -d и откройте адрес сервера: первый вход создаёт администратора.
  • Подключите домен через Caddy или Nginx, чтобы плееры ходили по HTTPS, а не по голому порту.

Чем слушать Navidrome на телефоне и компьютере

Веб-интерфейс Navidrome работает в браузере телефона, но для прослушивания в дороге удобнее приложение с офлайн-кэшем. Подойдёт любой плеер с поддержкой API Subsonic, а в документации Navidrome есть отдельный список проверенных клиентов для Android, iOS, Windows, macOS и Linux. В приложении указывают адрес сервера, логин и пароль Navidrome.

Navidrome или Audiobookshelf для аудиокниг и подкастов

Navidrome рассчитан на музыку. Для аудиокниг и подкастов есть Audiobookshelf: он запоминает позицию прослушивания в каждой книге, синхронизирует её между устройствами и ведёт библиотеку подкастов. Лицензия тоже GPL-3.0, приложения для Android и iOS пока в статусе бета.

Вопросы и ответы

Какой порт у Navidrome в Docker?

4533. Наружу его лучше не открывать, а отдавать Navidrome через обратный прокси с HTTPS.

Какие приложения работают с Navidrome?

Любые плееры с поддержкой API Subsonic, а также веб-интерфейс самого Navidrome. Список проверенных клиентов есть в документации проекта.

Подходит ли Navidrome для аудиокниг?

Играть их он сможет, но интерфейс и плееры рассчитаны на музыку. Для книг с главами и подкастов удобнее Audiobookshelf, его можно поставить на тот же сервер.

Где Navidrome хранит базу и плейлисты?

В томе /data: там база, настройки пользователей и кэш. Папка с музыкой подключается отдельно и может быть только для чтения.
