Установка ClickHouse на свой сервер или в облаке: коротко и с данными

Конспект страницы: 7 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Установка ClickHouse на свой сервер или в облаке.

Коротко

Главная / Разработка / ClickHouse Установка ClickHouse на VPS делается пакетами clickhouse-server и clickhouse-client или официальным образом Docker с тегом lts, а запросы принимают порты 8123 (HTTP) и 9000 (родной клиент). База хранит данные по столбцам и подходит для аналитики по миллионам строк, но не заменяет PostgreSQL в роли основной базы приложения. ClickHouse нужен для отчётов и аналитики по большим таблицам, где PostgreSQL начинает задыхаться.

Конспект по разделам

Для чего нужен ClickHouse и когда хватит PostgreSQL

ClickHouse это колоночная база с открытым кодом под лицензией Apache 2.0. Данные в ней лежат по столбцам, поэтому запрос «сумма заказов по дням за три года» читает только нужные два столбца, а не все строки целиком. Так работают веб-аналитика, логи, метрики, события из приложений и отчёты.

Где запускать ClickHouse: свой VPS или управляемая база

Для проверки идеи или небольшой аналитики хватает одного сервера: ClickHouse работает на одном узле без кластера. Управляемая база нужна там, где отчёты читает вся компания и простой базы заметят. Кластер из нескольких узлов с репликацией требует ClickHouse Keeper, службы согласования,, поэтому начинайте без него.

Установка ClickHouse на Ubuntu и Debian пакетами

Родной сборки для Windows у ClickHouse нет: для разработки его запускают в WSL2 или в Docker Desktop. Настройки лежат в /etc/clickhouse-server/, данные в /var/lib/clickhouse/, а журналы в /var/log/clickhouse-server/.

  • Подключите репозиторий packages.clickhouse.com по инструкции из документации ClickHouse: она даёт ключ подписи и строку источника.
  • Поставьте пакеты сервера и клиента.
  • Запустите службу и откройте клиент: он подключается к порту 9000.
  • Проверьте HTTP-интерфейс запросом на порт 8123.

ClickHouse в Docker: образ clickhouse и лимит файлов

Образ clickhouse открывает порты 8123 и 9000 и хранит данные в /var/lib/clickhouse/. Пользователь default без пароля закрыт для сети, пока вы не зададите CLICKHOUSE_USER или CLICKHOUSE_PASSWORD. Документация образа советует поднять лимит открытых файлов до 262144: ClickHouse держит много файлов открытыми.

Как создать первую таблицу ClickHouse и вставлять данные

Основной движок таблиц называется MergeTree. Порядок сортировки, который вы задаёте в ORDER BY, одновременно служит основным индексом, поэтому его выбирают по полям, по которым фильтруют чаще всего. Каждая вставка создаёт в хранилище отдельную часть, которую затем сливает фоновый процесс.

Доступ к ClickHouse по сети и резервные копии

Порты 8123 и 9000 не публикуют в интернет. С другой машины подключайтесь через SSH-туннель или по внутреннему адресу, а на файрволе открывайте их только для известных адресов. Приложению заведите отдельного пользователя с правами на одну базу, пользователя default оставьте администратору.

Вопросы и ответы

Как развернуть ClickHouse локально для проверки?

Запустите образ clickhouse командой docker run с портами 8123 и 9000, паролем в CLICKHOUSE_PASSWORD и лимитом nofile=262144. Откройте клиент: docker exec -it контейнер clickhouse-client.

Можно ли установить ClickHouse на Windows?

Родной версии для Windows нет. Запускайте ClickHouse в WSL2 или в контейнере Docker Desktop, а для рабочей базы берите Linux-сервер.

Сколько памяти нужно ClickHouse для начала работы?

Для небольших таблиц хватает 4 ГБ, но сложные запросы с группировками и соединениями быстро занимают память. Сервер по умолчанию ограничивает себя девятью десятыми от доступной памяти, лимит можно снизить.

Нужен ли ClickHouse кластер для начала?

Нет. Один сервер справляется с миллионами строк. Кластер с репликацией и ClickHouse Keeper добавляют, когда одного узла по объёму или доступности мало.
