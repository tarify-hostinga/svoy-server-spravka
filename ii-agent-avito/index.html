Покупатели в чатах объявлений задают одни и те же вопросы: «ещё продаётся?», «последняя цена?», «есть доставка?», «где забрать?». На большую часть из них можно ответить по данным объявления. Что делегировать агенту, видно из таблицы:

Как ИИ-агент получает и отправляет сообщения Авито через API

У Авито есть API для бизнес-аккаунтов, в том числе с доступом к мессенджеру: приложение может читать сообщения и отвечать от имени аккаунта. Условия подключения, лимиты и список возможностей меняются, поэтому сверяйтесь с документацией для разработчиков на сайте Авито и с настройками личного кабинета. Сценарий удобно собирать в n8n: он держит ключи, ходит в API и вызывает агента.

  • Получите доступ к API в кабинете бизнес-аккаунта и сохраните ключи в менеджере секретов сценария, а не в тексте шагов.
  • Примите новое сообщение.
  • Передайте агенту вопрос вместе с историей чата и данными объявления.
  • Отправьте ответ обратно в чат или положите его черновиком в канал менеджера.

Что положить в базу знаний ИИ-агента для Авито

Агент отвечает ровно настолько хорошо, насколько точна ваша таблица. Заведите таблицу объявлений: номер объявления, название, цена, остаток, срок отправки, условия доставки, адрес самовывоза. Загрузите её файлом в базу знаний платформы или отдавайте агенту строку нужного объявления вместе с вопросом.

Вопросы и ответы

Можно ли подключить ИИ-агента к чатам Авито?

Да, если у вас бизнес-аккаунт и доступ к API с мессенджером. Сценарий принимает сообщения, передаёт вопрос агенту и отправляет ответ обратно. Условия доступа сверяйте с документацией Авито.

Может ли ИИ-агент на Авито договариваться о цене?

Лучше не давать ему это. Агент называет цену из объявления, а торг, скидку и предоплату передаёт менеджеру: решение о деньгах принимает человек.

Нужен ли свой сервер для ИИ-агента на Авито?

Для сценария да: ему нужны ключи API и, возможно, постоянный HTTPS-адрес для уведомлений. Модель и базу знаний можно взять на платформе без сервера.

Как избежать неверных ответов ИИ-агента на Авито?

Держите таблицу цен и наличия актуальной, запретите агенту отвечать вне таблицы и в первые недели проверяйте черновики. Все диалоги сохраняйте, чтобы находить ошибки.
