Что ИИ-агент делает с 1С и чего ему делать нельзя

Общий принцип «агент предлагает, человек подтверждает» описан на странице ИИ-агент или чат-бот, а для работы с договорами и письмами есть агент для документов.

Как подключить ИИ-агента к 1С через OData или HTTP-сервис

HTTP-сервис выгоднее для агента, когда нужны сводные данные: он отдаёт десять полей вместо сотни. Это меньше токенов в запросе к модели и меньше лишних данных за пределами базы.

  • Опубликуйте базу на веб-сервере и включите стандартный интерфейс OData для нужных объектов или опубликуйте свой HTTP-сервис.
  • Заведите пользователя «ИИ-агент» с ролью только на чтение нужных справочников и документов.
  • Проверьте запрос из командной строки с логином и паролем этого пользователя.
  • Добавьте запрос в сценарий как инструмент: в агенте n8n для этого есть узел HTTP Request.

Где разместить ИИ-агента рядом с 1С и как защитить данные

Агент и база должны видеть друг друга по сети. Если 1С стоит в офисе, проще запустить n8n на сервере в той же сети: наружу база не открывается. Если агент работает на VPS, опубликуйте 1С по HTTPS и разрешите доступ только с IP-адреса сервера агента либо соедините сети защищённым туннелем, например WireGuard.

ИИ-агент внутри 1С: вызов модели из кода конфигурации

Разработчик может вызвать модель прямо из кода 1С через HTTP-соединение, например чтобы предложить текст ответа клиенту в форме документа. Для такой задачи отдельный агент не нужен. Цикл «модель решает, какой инструмент вызвать» удобнее держать снаружи, в n8n или на платформе: там есть память, журнал и подтверждение инструментов.

Вопросы и ответы

Как подключить ИИ-агента к 1С через OData?

Опубликуйте базу на веб-сервере, включите стандартный интерфейс OData для нужных объектов, заведите пользователя с ролью только на чтение и вызывайте адреса из сценария агента с его логином и паролем.

Может ли ИИ-агент проводить документы в 1С?

Технически можно, но не нужно. Модель ошибается, а проведённый документ меняет учёт. Безопасная схема: агент создаёт черновик, бухгалтер проверяет и проводит.

Нужен ли программист 1С для ИИ-агента?

Для чтения через стандартный OData хватит администратора. Для своих методов, черновиков документов и сводных данных нужен программист 1С, который напишет HTTP-сервис.

Какие данные 1С можно передавать модели ИИ-агента?

Только поля, нужные для ответа. Персональные данные сотрудников и клиентов подпадают под 152-ФЗ, поэтому, если их нельзя отправлять внешнему API, берите локальную модель.
