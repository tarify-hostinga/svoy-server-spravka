Установка BigBlueButton на свой сервер: коротко и с данными

Конспект страницы: 7 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Установка BigBlueButton на свой сервер.

Коротко

Главная / Для офиса / BigBlueButton Установка BigBlueButton занимает один скрипт на чистой Ubuntu, но сервер для него нужен мощный: документация просит 8 ядер и 16 ГБ памяти. Это система для онлайн-уроков и вебинаров со слайдами, доской, комнатами для групп и записью, а не просто комната для звонка. Для рабочего сервера документация называет 8 ядер, 16 ГБ памяти и 50 ГБ диска без записи.

Конспект по разделам

Чем BigBlueButton отличается от Jitsi Meet и LiveKit

BigBlueButton задуман для занятий: преподаватель загружает презентацию, рисует на доске, делит класс на группы, проводит опрос и записывает урок. К Moodle и другим учебным системам он подключается готовым плагином. Для обычных рабочих созвонов он избыточен.

Какой сервер нужен для BigBlueButton

Ubuntu 20.04 и 22.04, которые ищут в запросах, относятся к прежним веткам 2.x и 3.0. Прямое обновление с них на 4.0 не поддерживается, нужен чистый сервер. Откройте страницу установки той версии, которую ставите.

Как поставить BigBlueButton по шагам

Значение для -v и полную команду берите со страницы установки: в этом примере стоит заглушка. Другого способа установки на рабочий сервер документация не описывает. Готовые образы Docker для BigBlueButton делает сообщество, они годятся для разработки и проб.

  • Возьмите чистую Ubuntu нужной версии и направьте A-запись домена, например bbb.example.com, на IP сервера.
  • Проверьте порты.
  • Запустите скрипт bbb-install из ветки вашей версии: ключ -s задаёт домен, -e почту для сертификата Let's Encrypt, -g ставит Greenlight, интерфейс для комнат.
  • Дождитесь конца установки, она занимает заметное время: скрипт ставит десятки пакетов и контейнеры.

Домен, порты и HTTPS для BigBlueButton

Сертификат скрипт выпускает сам, поэтому в Certbot или Caddy для него нет нужды. Они и мешают: порты 80 и 443 заняты самим BigBlueButton. Если на сервере нужен ещё и обычный сайт, держите его на другом сервере.

Greenlight, пользователи и подключение BigBlueButton к Moodle

В самом BigBlueButton нет списка учётных записей. Людей и комнаты ведёт внешний интерфейс. По умолчанию это Greenlight: в нём регистрируются преподаватели, у каждого есть свои комнаты, а администратор управляет пользователями и ролями.

Копии записей и обновление BigBlueButton

Записи уроков лежат в каталоге /var/bigbluebutton, настройки в /etc/bigbluebutton, учётные записи Greenlight в базе внутри его контейнера. Перенос на новый сервер это копия этих трёх мест. Записи быстро растут, поэтому раз в неделю выносите их в хранилище, схема в разборе сервер для бэкапов.

Вопросы и ответы

Какую Ubuntu нужно для установки BigBlueButton?

Для ветки 4.0 страница установки называет Ubuntu 24.04 и ядро 6.x. Более старые Ubuntu 20.04 и 22.04 относятся к прежним веткам, прямое обновление с них не поддерживается.

Можно ли установить BigBlueButton в Docker?

Для рабочего сервера документация описывает только скрипт bbb-install на чистой Ubuntu. Образы Docker от сообщества подходят для проб и разработки, а Docker внутри BigBlueButton нужен для изоляции LibreOffice.

Почему в BigBlueButton не слышно участников?

Чаще всего закрыт диапазон UDP-портов 16384-32768 на сервере или у провайдера. Откройте его и выполните bbb-conf --check.

Хватит ли BigBlueButton сервера на 4 ядра и 8 ГБ?

По документации это конфигурация для разработки. Для рабочих встреч указано 8 ядер и 16 ГБ памяти, при записи ещё 500 ГБ диска.
