Коротко

VSCode Server в Docker обычно означает code-server: открытую сборку VS Code, которая работает на сервере и открывается в браузере на порту 8080. Код, терминал и расширения живут на VPS, а вы заходите в редактор с любого компьютера или планшета. Для code-server хватит 2 ядер и 2 ГБ памяти, больше просят языковые серверы и сборка.

Конспект по разделам

VS Code Server от Microsoft и code-server: в чём разница

Под названием «VS Code Server» прячутся два разных продукта. Если вы работаете из установленного VS Code, серверная часть Microsoft ставится сама при подключении по Remote-SSH. Если нужен редактор именно в браузере и в контейнере, берите code-server.

Запуск code-server в Docker и docker compose

Официальная команда из документации, порт привязан к локальному адресу сервера: Та же конфигурация в виде compose-файла, чтобы контейнер поднимался после перезагрузки: Пароль для входа лежит в файле config.yaml в подключённом каталоге настроек (.config/code-server/config.yaml ). Поменяйте его на свой и перезапустите контейнер. Образ собран для amd64 и arm64.

Как открыть code-server снаружи: SSH-туннель или домен с HTTPS

Разработчики code-server настоятельно советуют проброс порта по SSH: ничего не публикуется, пароль не уходит в сеть открытым текстом. Для постоянного адреса направьте поддомен на сервер и поставьте перед code-server обратный прокси, то есть сервер, который принимает HTTPS и передаёт запросы редактору. В руководстве разобраны два варианта с Let's Encrypt: Caddy и Nginx.

Расширения и ИИ-агенты в code-server

Магазин расширений Microsoft по своим условиям работает только с продуктами Microsoft, поэтому code-server к нему не подключается. Часть расширений найдётся в другом каталоге, остальные ставятся вручную из файла.vsix. Терминальные агенты от этого не зависят.

Вопросы и ответы

Где взять пароль code-server после запуска в Docker?

В файле config.yaml в каталоге.config/code-server, который подключён в контейнер томом. Смените пароль там и перезапустите контейнер.

Сколько памяти нужно code-server?

Разработчики называют минимум 1 ГБ памяти и 2 ядра. Для TypeScript, Java или сборки в Docker закладывайте 4 ГБ и больше.

Почему в code-server нет некоторых расширений VS Code?

Условия магазина Microsoft разрешают его только продуктам Microsoft. Недостающие расширения ставят вручную из файла.vsix.

Есть ли code-server для Windows-сервера?

Нет, сборки для Windows разработчики не публикуют. Ставьте code-server на Linux или в Docker.
