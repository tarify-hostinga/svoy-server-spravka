Конспект по разделам

Что такое Matrix Synapse, Element и федерация серверов

Matrix это открытый протокол обмена сообщениями, Synapse его сервер на Python, а Element самый известный клиент. Серверы Matrix умеют общаться между собой: ваш Synapse принимает приглашения от пользователей чужих серверов и входит в комнаты на них. Эта возможность называется федерацией, и она отличает Matrix от Mattermost и Rocket.Chat.

Сколько ресурсов нужно Matrix Synapse и сколько людей он выдержит

Synapse написан на Python и растёт в памяти вместе с числом комнат, в которых состоят ваши пользователи. Закрытый сервер на 20-50 человек уложится в 2 ядра и 4 ГБ. Ситуация меняется, когда люди вступают в большие публичные комнаты на чужих серверах: состояние этих комнат хранится у вас, и база растёт заметно.

Как установить Matrix Synapse через Docker с PostgreSQL по шагам

Короткий путь: создать сервер из маркетплейса, где есть связка Synapse с Element (371 установка на 14 октября 2026). Для ручной установки на Ubuntu или другой Linux нужны только Docker и домен. Имя сервера выбирают один раз Значение SYNAPSE_SERVER_NAME попадает в каждый идентификатор пользователя и комнаты.

  • Создайте файл настроек командой generate: она запишет homeserver.yaml и ключи в каталог data.
  • Положите рядом compose-файл с двумя сервисами, Synapse и PostgreSQL.
  • Замените блок database в homeserver.yaml: вместо SQLite укажите psycopg2 и хост db.
  • Проверьте registration_shared_secret в том же файле, он нужен для создания пользователей из консоли.

Домен, HTTPS и.well-known для Matrix Synapse

Перед портом 8008 ставят обратный прокси, то есть сервер, который принимает HTTPS и передаёт запросы Synapse. С Caddy хватит записи matrix.example.com { reverse_proxy localhost:8008 }, а сертификат он выпустит сам. Если на сервере уже стоит Nginx, сертификат для него выпускает Certbot.

Element для браузера и телефонов: подключение к своему Synapse

Element Web это статический сайт: его раздаёт любой веб-сервер или контейнер, а в config.json указывают адрес вашего Synapse в параметре base_url. Приложения Element для Android и iOS при входе спрашивают домен вашего сервера, отдельных настроек в магазинах не нужно. Push-уведомления устроены так: приложение регистрирует на Synapse адрес push-шлюза, и сервер отправляет уведомления туда.

Что копировать у Matrix Synapse: база, медиа и ключ сервера

Состояние Synapse лежит в трёх местах: база PostgreSQL, каталог media_store с загруженными файлами и ключ подписи сервера вместе с homeserver.yaml в каталоге data. Потеря ключа ломает идентичность сервера в федерации, поэтому храните его копию отдельно от дампа базы. Выгружайте базу командой pg_dump по расписанию, схемы хранения описаны в разделе сервер для бэкапов.

Вопросы и ответы

Как установить Matrix Synapse через Docker?

Выполните команду generate образа matrixdotorg/synapse с переменными SYNAPSE_SERVER_NAME и SYNAPSE_REPORT_STATS, подключите PostgreSQL в homeserver.yaml и запустите compose-файл. Приложение слушает порт 8008.

Какой порт использует Matrix Synapse?

В контейнере Synapse слушает HTTP на порту 8008. Снаружи нужны 80 и 443 на обратном прокси, а порт 8008 держите на локальном адресе.

Как создать пользователя в Matrix Synapse в Docker?

Убедитесь, что в homeserver.yaml задан registration_shared_secret, и выполните register_new_matrix_user внутри контейнера с адресом http://localhost:8008 и путём к конфигу /data/homeserver.yaml. Ключ -a делает пользователя администратором.

Подойдёт ли SQLite для Matrix Synapse?

SQLite стоит в настройках по умолчанию, но документация образа советует для рабочего сервера подключить отдельную базу PostgreSQL.

Нужен ли Element, чтобы пользоваться Synapse?

Нет, Synapse это сервер, а клиентом может быть любое приложение Matrix. Element самый распространённый и ставится вместе с Synapse из маркетплейса.
