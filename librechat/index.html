LibreChat: установка на свой сервер, коротко и с данными

Конспект страницы: 5 разделов коротко, данные на 14 октября 2026 и ответы на 3 вопроса. Полный разбор с примерами: LibreChat: установка на свой сервер.

Коротко

LibreChat установка через Docker занимает четыре команды: клонировать репозиторий, скопировать.env.example в.env и выполнить docker compose up -d, после чего чат открывается на порту 3080. Ценность LibreChat в том, что в одном окне живут модели разных провайдеров и локальные модели из Ollama. Для команды до 10 человек с моделями по API хватит сервера на 2 ядра и 4 ГБ.

Конспект по разделам

Из чего состоит LibreChat и зачем ему шесть контейнеров

LibreChat это открытый чат в стиле ChatGPT, куда подключают OpenAI, Anthropic, Google, локальные модели и любые OpenAI-совместимые API. Пользователь выбирает модель в выпадающем списке, история и файлы хранятся на вашем сервере. Поиск по файлам устроен по схеме RAG, векторы лежат в pgvector.

Сколько памяти нужно LibreChat со всеми сервисами

Официальной минимальной конфигурации у LibreChat нет, а считать приходится весь набор контейнеров. Для старта хватит 2 ядер и 4 ГБ, если модели работают по API; файлы для поиска добавляют нагрузку на rag_api и базу векторов. Установка LibreChat через docker compose

Если порт 3080 занят, его меняют в docker-compose.override.yml, например на "3081:3080". Если контейнер MongoDB не стартует на процессоре сервера, документация предлагает в том же файле указать образ mongo:4.4.18.

  • Поставьте Docker с плагином compose и git.
  • Скачайте проект: git clone https://github.com/LibreChat-AI/LibreChat.git и cd LibreChat.
  • Создайте файл окружения: cp.env.example.env.
  • Запустите: docker compose up -d.

Как подключить к LibreChat Ollama и OpenAI-совместимый API

Провайдеры описываются в файле librechat.yaml, который подключают в контейнер через docker-compose.override.yml, а затем перезапускают: docker compose down && docker compose up -d. Пример для Ollama на том же сервере: Ollama ключ не проверяет, но поле обязано быть заполнено. Так же подключается AI Gateway Таймвеб Клауд: свой name, адрес API из панели в baseURL и ключ в apiKey.

Регистрация, секреты и обновление LibreChat

Обновление: git pull, docker compose pull и docker compose up -d. Данные MongoDB лежат в папке data-node рядом с проектом, её и копируйте перед обновлением. Доступ по домену с HTTPS настраивают через Nginx, в репозитории для этого есть отдельный deploy-compose.

Вопросы и ответы

Как обновить LibreChat в Docker?

В папке проекта выполнить git pull, затем docker compose pull и docker compose up -d. Перед этим скопируйте папку data-node с базой MongoDB.

Можно ли запустить LibreChat без MongoDB?

Нет, пользователи и чаты хранятся только в MongoDB. В стандартном compose она поднимается автоматически отдельным контейнером.

Как закрыть регистрацию в LibreChat?

В файле.env поставить ALLOW_REGISTRATION=false и перезапустить контейнеры. Вход по почте и паролю для уже созданных аккаунтов останется.
