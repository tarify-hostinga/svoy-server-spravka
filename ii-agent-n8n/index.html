Как создать ИИ-агента в n8n: коротко и с данными

Конспект страницы: 5 разделов коротко, данные на 14 октября 2026 и ответы на 3 вопроса. Полный разбор с примерами: Как создать ИИ-агента в n8n.

Коротко

Главная / ИИ-агенты / Агент в n8n Как создать ИИ-агента в n8n: поставить узел Chat Trigger, за ним узел AI Agent и подключить к агенту модель, память и хотя бы один инструмент. Модель берётся по OpenAI-совместимому API, например через AI Gateway с оплатой в рублях, поэтому видеокарта на сервере с n8n не нужна. Агент в n8n это Chat Trigger, узел AI Agent, модель, память и инструмент.

Конспект по разделам

Из каких узлов состоит ИИ-агент в n8n

В n8n агент собирается из корневого узла AI Agent и подключённых к нему вспомогательных узлов. Каждый отвечает за своё, и заменить можно любой, не трогая остальные. Без инструмента узел AI Agent не запустится: документация n8n требует подключить хотя бы один.

Как подключить модель к агенту n8n через OpenAI-совместимый API

Узел OpenAI Chat Model работает с любым сервисом, который отвечает в формате OpenAI. В учётных данных OpenAI есть поле Base URL: по умолчанию там стоит https://api.openai.com/v1, и его можно заменить адресом другого провайдера. Так к n8n подключается AI Gateway Таймвеб Клауд: шлюз отвечает в формате OpenAI и берёт оплату рублями за токены.

  • Создайте учётные данные OpenAI в разделе Credentials.
  • Вставьте ключ провайдера в поле API Key.
  • Замените Base URL на адрес OpenAI-совместимого API провайдера.
  • В узле OpenAI Chat Model выберите эти учётные данные и укажите имя модели.

ИИ-агент в n8n по шагам: от чата до первого инструмента

Simple Memory не работает в режиме очереди Если n8n запущен в queue mode с несколькими исполнителями, Simple Memory в активном сценарии отказывает: сообщения одного диалога попадают на разные воркеры. Для такого режима берите Postgres Chat Memory: таблицу для истории узел создаст сам в базе PostgreSQL.

  • Поднимите n8n на сервере с доменом и HTTPS, порядок описан на странице установка n8n.
  • Добавьте Chat Trigger.
  • Поставьте AI Agent и напишите System Message: кто агент, на какие вопросы отвечает, что говорить, если данных нет.
  • Подключите модель ко входу Chat Model.

Где агенту n8n нужен человек: подтверждение инструментов

n8n умеет ставить проверку человеком (human-in-the-loop) перед отдельными инструментами. Когда агент собирается отправить письмо клиенту или удалить запись, сценарий встаёт на паузу, проверяющий видит имя инструмента и параметры и нажимает Approve или Deny. При отказе действие не выполняется, а агент узнаёт, что его отклонили.

Сколько стоит агент в n8n: сервер и токены

Расходы делятся на две части. Сервер с n8n агент почти не нагружает, потому что модель работает у провайдера; конфигурацию под число сценариев подбирает калькулятор на странице установки n8n. Токены модели расходуются на каждом шаге: вместе с вопросом уходят System Message, история из памяти и ответы инструментов.

Вопросы и ответы

Почему ИИ-агент в n8n не помнит прошлые сообщения?

Проверьте две вещи: подключена ли память к узлу AI Agent и не меняется ли ключ сессии (Session Key) между сообщениями. Если в Chat Trigger включена загрузка прошлой сессии (Load Previous Session: From Memory), память подключают и к триггеру, и к агенту.

Можно ли подключить к агенту n8n локальную модель вместо API?

Да, для Ollama в n8n есть отдельный узел Ollama Chat Model. Агенту нужны длинный контекст и поддержка вызова инструментов, а на сервере без видеокарты локальная модель будет отвечать медленно.

Где взять готовые шаблоны ИИ-агентов для n8n?

В галерее шаблонов на сайте n8n есть сценарии с узлом AI Agent: импортируете JSON, подставляете свои учётные данные и модель. Перед запуском перечитайте System Message и список инструментов, шаблон писали под чужие задачи.
