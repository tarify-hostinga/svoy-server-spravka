Главная / Разработка / Docker registry Self hosted Docker registry поднимается одним контейнером registry:3 на порту 5000, но без пароля, HTTPS и очистки это только склад слоёв. Решите заранее, нужен ли вам такой склад, готовый Harbor или управляемый реестр контейнеров провайдера: у них разный объём обслуживания. Один контейнер registry:3 с паролем и HTTPS подходит одной команде.

HTTPS и пароль для вашего Docker registry

Docker-клиент не отправит образы в реестр по голому HTTP, пока вы не внесёте адрес в список «небезопасных». Правильнее поставить перед реестром обратный прокси с настоящим сертификатом. Интерфейс и очистка места в своём Docker registry

У registry:3 нет веб-страницы со списком образов. Если нужен интерфейс, ставят отдельный проект, например Joxit docker-registry-ui, и разрешают ему доступ в настройках реестра. Альтернатива без лишней сборки: Harbor, где интерфейс встроен.

Вопросы и ответы

Чем self hosted Docker registry отличается от Harbor?

Реестр registry:3 только принимает и отдаёт образы, у него нет интерфейса и ролей. Harbor добавляет проекты, роли, сканирование Trivy, репликацию и очистку, но требует сервер от 4 ГБ памяти.

Как защитить свой Docker registry паролем?

Создать файл htpasswd с записями bcrypt (ключ -B), подключить его переменными REGISTRY_AUTH_HTPASSWD_PATH и REGISTRY_AUTH_HTPASSWD_REALM и вынести реестр за HTTPS-прокси. Вход потом идёт командой docker login.

Есть ли у registry:3 веб-интерфейс?

Нет. Для списка образов ставят отдельный проект с интерфейсом либо берут Harbor, в котором интерфейс уже есть.

Сколько стоит облачный реестр контейнеров вместо своего?

У Таймвеб Клауд хранилище на 5 ГБ стоит 80 ₽ в месяц, 100 ГБ стоит 400 ₽ (цены на 14 октября 2026). Сервер под свой реестр обслуживаете вы сами.

Как удалить образ из своего Docker registry и освободить место?

Включить REGISTRY_STORAGE_DELETE_ENABLED, удалить манифест через API, затем запустить garbage-collect при остановленной записи. Без сборки мусора слои остаются на диске.
