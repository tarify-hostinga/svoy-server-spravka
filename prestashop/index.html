Главная / Разработка / PrestaShop Установка PrestaShop 9 начинается с проверки сервера: документация перечисляет PHP с 8.1 по 8.5 (рекомендуют 8.5), базу MySQL 5.7 или MariaDB 10.2 и выше, Apache 2.4 или Nginx и лимит памяти PHP не ниже 512 МБ. Лимит памяти высокий, поэтому под рабочий магазин берут VPS, а не самый дешёвый общий хостинг. Ниже требования, шаги установки и запуск в Docker.

Данные взяты из документации разработчиков PrestaShop 9 на 16 октября 2026. Расширение Intl есть не на каждом хостинге, а лимит 512 МБ на скрипт редко выставляют на дешёвых тарифах. Оба пункта стоит выяснить до оплаты.

Хостинг или VPS для PrestaShop: что выбрать

PrestaShop расходует много памяти: её съедают модули, комбинации товаров, несколько языков и кэш. Поэтому виртуальный хостинг годится для пробы и совсем небольшого каталога, а рабочему магазину удобнее VPS. Готовый тариф MSK Ultra 50 в Таймвеб Клауд (2 vCPU, 4 ГБ памяти, 50 ГБ NVMe) стоит 5 480 ₽ в месяц на 14 октября 2026: такой объём памяти комфортен для магазина с модулями.

Установка PrestaShop на VPS: архив, база и мастер

Реквизиты базы после установки лежат в файле app/config/parameters.php. Если установка остановилась на проверке, мастер покажет, какого расширения PHP не хватает: поставьте его и обновите страницу.

  • Подготовьте стек: Apache или Nginx с PHP-FPM, нужные расширения, MariaDB.
  • Создайте базу и отдельного пользователя для магазина.
  • Скачайте архив со страницы загрузки PrestaShop и распакуйте его в корень сайта.
  • Откройте адрес сайта: мастер проверит версию PHP и расширения, спросит язык, данные магазина и базы.

PrestaShop в Docker: образ prestashop/prestashop

У PrestaShop есть официальный образ prestashop/prestashop с Apache и PHP внутри. Для автоматической установки в нём задают переменные: адрес базы, данные доступа и домен, а флаг PS_INSTALL_AUTO=1 запускает установку без мастера. Для рабочего магазина замените latest на конкретный тег версии.

HTTPS и резервные копии магазина PrestaShop

Покупатели вводят в магазине адреса и платёжные данные, поэтому HTTPS нужен на всех страницах. Сертификат на VPS выпускает Certbot; если перед контейнером стоит прокси, его берёт на себя Caddy. В настройках магазина включите SSL для всех страниц, а при работе за прокси убедитесь, что магазин получает признак защищённого соединения.

Вопросы и ответы

Какая версия PHP нужна для PrestaShop 9?

Документация перечисляет PHP с 8.1 по 8.5 и рекомендует 8.5. Лимит памяти скрипта советуют не ниже 512 МБ, а allow_url_fopen должна быть включена.

Можно ли установить PrestaShop на дешёвый хостинг?

Можно, если там есть PHP нужной версии, расширение Intl и лимит памяти 512 МБ. Рабочему магазину с модулями удобнее VPS, где эти параметры задаёте вы.

Есть ли официальный Docker-образ PrestaShop?

Да, prestashop/prestashop на Docker Hub. С переменной PS_INSTALL_AUTO=1 он устанавливает магазин сам, рядом нужен контейнер MariaDB или MySQL.

Какая база нужна для PrestaShop?

MySQL не ниже 5.7 или MariaDB не ниже 10.2, рекомендуют более свежие версии. Подключение идёт через PDO с драйвером MySQL.
