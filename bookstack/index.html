Установка BookStack на свой сервер: коротко и с данными

Конспект страницы: 7 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Установка BookStack на свой сервер.

Коротко

Главная / Для офиса / BookStack Установка BookStack на свой сервер занимает два контейнера: приложение на PHP и база MariaDB или MySQL. Вики раскладывает знания по полкам, книгам и главам, поэтому новичку понятна без обучения, а лицензия MIT позволяет пользоваться ею без ограничений. BookStack просит PHP 8.2 и MySQL 8.0 или MariaDB 10.6, остальное делает готовый образ.

Конспект по разделам

Что такое BookStack и кому подойдёт его структура из книг

BookStack устроен как библиотека: полки собирают книги, книги делятся на главы, главы содержат страницы. Можно писать в визуальном редакторе или в Markdown, вставлять схемы из diagrams.net и экспортировать книгу в PDF, HTML или текст. Регламенты, инструкции для сотрудников и описание процессов в такой иерархии находятся быстро.

Какие требования у BookStack: PHP 8.2 и MySQL или MariaDB

Образ Docker скрывает почти все эти пункты, вам остаётся база. Для старта хватит младшей готовой конфигурации Таймвеб Клауд (1 vCPU, 1 ГБ, 15 ГБ NVMe, 1 920 ₽ в месяц на 14 октября 2026), если база и вики невелики. Как только появятся сотни страниц и вложения, переходите на 2 ГБ.

Установка BookStack в Docker на Ubuntu по шагам

Имена переменных базы сверяйте В разных версиях образа LinuxServer имена вида DB_USER и DB_USERNAME менялись. Откройте актуальный пример на странице образа и приведите файл к нему, прежде чем запускать. Без Docker документация предлагает скрипт установки для Ubuntu LTS: он ставит всё сам и в конце печатает случайный пароль администратора.

  • Установите движок Docker и Compose официальным скриптом curl -fsSL https://get.docker.com | sh.
  • Сгенерируйте ключ приложения командой из документации образа LinuxServer: он нужен для шифрования сессий и вписывается в APP_KEY.
  • Создайте файл docker-compose.yml ниже, поставив свой адрес в APP_URL и свои пароли.
  • Запустите docker compose up -d и откройте http://IP-сервера:6875.

Домен, APP_URL и HTTPS для BookStack

Параметр APP_URL должен совпадать с адресом, по которому вики открывают люди, вместе с https. Если указать там IP или http, картинки, стили и ссылки в письмах поедут. Поменяли домен позже: исправьте APP_URL и перезапустите контейнер.

Роли, права и вход сотрудников в BookStack

Из коробки есть роли Admin, Editor, Viewer и Public. Права назначаются двумя слоями: роль задаёт общие возможности, а на конкретную полку, книгу, главу или страницу можно выдать свои права. Так бухгалтерия видит свои регламенты, а остальные нет.

Копии и обновление BookStack без потери книг

В копию входят дамп базы и загруженные файлы: у образа LinuxServer всё нужное лежит в базе и в томе /config. Дамп делает mysqldump внутри контейнера базы, а том копируют целиком. Планировать копии удобно по схеме со страницы сервер для бэкапов.

Вопросы и ответы

Какие требования у BookStack к серверу?

PHP 8.2 и выше, MySQL 8.0 или MariaDB 10.6 и выше, Git и Composer для ручной установки. Объём памяти документация не называет, для малой вики хватает недорогого сервера.

Какой пароль у BookStack после установки?

Вход admin@admin.com с паролем password. Замените оба значения при первом входе. Скрипт установки для Ubuntu из документации вместо этого печатает случайный пароль.

Как установить BookStack в Docker?

Взять образ LinuxServer, добавить контейнер MariaDB, указать APP_URL, ключ APP_KEY и параметры базы, затем выполнить docker compose up -d. Приложение откроется на порту 6875.

Почему BookStack грузится без стилей и картинок?

Почти всегда в APP_URL указан не тот адрес, например http вместо https или IP вместо домена. Исправьте значение и перезапустите контейнер.
