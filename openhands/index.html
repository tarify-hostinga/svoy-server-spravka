OpenHands: установка на свой сервер, коротко и с данными

Конспект страницы: 6 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: OpenHands: установка на свой сервер.

Коротко

OpenHands установка на сервер идёт через лаунчер uv или одну команду docker run, после чего веб-интерфейс открывается на порту 3000. Агент выполняет задачи в отдельных контейнерах, поэтому ему нужен Docker, доступ к его сокету и от 4 ГБ памяти. Для одной задачи за раз хватит 2 ядер и 4 ГБ памяти, но песочницы с проектом быстро съедают диск.

Конспект по разделам

OpenHands: агент, который работает в своей песочнице

OpenHands: открытая платформа агентов для разработки. В веб-интерфейсе вы ставите задачу, агент пишет код, запускает команды и тесты внутри отдельного контейнера, а вы смотрите за ходом работы. Есть и терминальная версия, и режим без интерфейса для скриптов и CI.

Сколько памяти и что нужно серверу для OpenHands

OpenHands запускает каждую задачу в контейнере, поэтому считаем с запасом на Docker

Установка OpenHands через uv и через docker run

Через uv (рекомендует документация). Лаунчер сам проверит Docker, скачает образы и поднимет интерфейс: Обновление: uv tool upgrade openhands --python 3.12. Флаг --gpu пробрасывает видеокарту и требует NVIDIA Container Toolkit, о нём на странице CUDA.

Как подключить модель к OpenHands

После первого входа OpenHands требует выбрать провайдера, модель и ввести ключ API. Если нужной модели нет в списке, включите расширенные настройки во вкладке LLM и укажите модель вручную. Для OpenAI-совместимого API документация даёт простое правило: в поле Custom Model пишете openai/имя-модели, в поле Base URL адрес сервиса.

Как закрыть OpenHands от чужих на VPS

OpenHands получает сокет Docker, а это права, сравнимые с правами администратора сервера. Поэтому интерфейс не должен быть доступен из интернета.

  • Привяжите порт к 127.0.0.1, как в команде выше, и подключайтесь туннелем: ssh -L 3000:127.0.0.1:3000 user@сервер, затем откройте http://localhost:3000 у себя.
  • Терминальная версия запускает веб-доступ командой openhands web на порту 12000 и по умолчанию слушает все адреса.
  • Держите на этом сервере только проекты для агента, без чужих данных и боевых ключей.

Вопросы и ответы

Можно ли запустить OpenHands через docker compose?

Готового файла в документации нет, но параметры команды docker run (сокет Docker, том ~/.openhands, порт 3000, host.docker.internal) переносятся в compose без изменений.

Как сменить порт OpenHands?

В лаунчере openhands serve порт 3000 не настраивается. При запуске через docker run меняют левую часть параметра -p, например 127.0.0.1:8300:3000.

Нужна ли видеокарта для OpenHands?

Нет, если модель работает у провайдера по API. Видеокарта нужна, только если вы запускаете свою модель или задачи агента используют GPU.

Как подключить OpenHands к OpenAI-совместимому API?

В расширенных настройках LLM укажите модель с префиксом openai/ и адрес сервиса в поле Base URL.
