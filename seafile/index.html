Установка Seafile на свой сервер: коротко и с данными

Конспект страницы: 6 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Установка Seafile на свой сервер.

Коротко

Главная / Self-hosted / Seafile Установка Seafile на свой сервер сейчас идёт через Docker Compose: разработчики дают готовый файл.env и три compose-файла, где уже есть MariaDB, Redis и Caddy для HTTPS. Seafile делает одну вещь, синхронизацию файлов, и передаёт по сети только изменённые части каждого файла. Seafile выбирают, когда нужна быстрая синхронизация папок, а календарь и чаты не нужны.

Конспект по разделам

Чем Seafile отличается от Nextcloud и ownCloud

Seafile хранит файлы в библиотеках, а внутри разбивает их на блоки и ведёт историю изменений, похоже на Git. Поэтому синхронизация передаёт только изменённые части, а любую версию файла можно вернуть. Обратная сторона: на диске сервера лежат не ваши документы, а служебные блоки, и просто скопировать папку с сервера не получится.

Сколько ресурсов нужно Seafile

Требования из руководства администратора Seafile: В набор Community входят Seafile, MariaDB 10.11, Redis, сервер документов SeaDoc и Caddy. Профессиональной редакции нужен поисковый движок, поэтому она тяжелее. Три ответа, и калькулятор подберёт конфигурацию

Установка Seafile через Docker Compose

Данные по умолчанию лежат в /opt/seafile-data, база в /opt/seafile-mysql/db. Если диск под файлы отдельный, поменяйте BASIC_STORAGE_PATH в.env до первого запуска.

  • Поставьте Docker на чистую Ubuntu или Debian.
  • Скачайте файлы в каталог /opt/seafile:.env, seafile-server.yml, caddy.yml и seadoc.yml из руководства для версии 13.0.
  • Заполните.env: домен в SEAFILE_SERVER_HOSTNAME, протокол https, пароль базы, почту и пароль первого администратора, ключ JWT_PRIVATE_KEY длиной от 32 символов.
  • Запустите docker compose up -d и дождитесь в журнале строки о создании администратора.

Домен и HTTPS для Seafile

Caddy из комплекта сам получает сертификат Let's Encrypt для домена из.env, если протокол указан как https. Откройте на сервере порты 80 и 443 и направьте A-запись домена на IP. Когда на сервере уже есть свой обратный прокси, то есть программа, которая принимает HTTPS и передаёт запросы приложениям, уберите caddy.yml из списка COMPOSE_FILE и пробросьте Seafile через Nginx или Traefik.

Резервные копии и сборка мусора в Seafile

Удалённые файлы не исчезают с диска сразу: их блоки остаются, пока не пройдёт сборка мусора. Запускайте её по расписанию, иначе диск будет заполняться даже при неизменном объёме библиотек. Копия Seafile состоит из двух частей, снятых в одно время: дамп трёх баз MariaDB (ccnet_db, seafile_db, seahub_db) и каталог seafile-data.

Вопросы и ответы

Можно ли установить Seafile на Windows?

Серверную часть разработчики выпускают для Linux в Docker. На Windows её запускают только в Docker Desktop для проб, а клиенты Seafile для Windows работают без ограничений.

Почему на сервере Seafile не видно моих файлов?

Seafile хранит их блоками с историей версий. Посмотреть файлы можно через веб-интерфейс, клиент или SeaDrive, а не через каталог на диске.

Как обновить Seafile в Docker до новой версии?

Прочитайте заметки к выпуску, сделайте копию баз и данных, поменяйте тег образа в.env и выполните docker compose pull и docker compose up -d. При смене основной версии в руководстве есть отдельная инструкция по миграции.

Seafile или ownCloud: что взять для синхронизации файлов?

Seafile передаёт только изменённые блоки и умеет шифровать библиотеки на клиенте. ownCloud Infinite Scale ближе к Nextcloud по набору функций общего доступа и распространяется под Apache-2.0.
