Конспект по разделам

Чем OpenSearch отличается от Elasticsearch

OpenSearch выделился из Elasticsearch в 2021 году, когда Elastic сменила лицензию, и остался на Apache 2.0. Проект развивается под крылом Linux Foundation, а Dashboards это ответвление Kibana. Безопасность, управление жизненным циклом индексов (ISM) и алерты входят в сборку, отдельных подписок не нужно.

Сколько памяти и диска нужно OpenSearch

Конкретных минимумов здесь не называем: цифры зависят от версии образа, поэтому сверьтесь со страницей установки в Docker в документации OpenSearch. Практический ориентир для пробы одного узла: от 4 ГБ памяти, куча JVM (параметр OPENSEARCH_JAVA_OPTS ) не больше половины. Параметр ядра vm.max_map_count нужно поднять до 262144, как и для Elasticsearch.

Установка OpenSearch в Docker с Dashboards

Переменная OPENSEARCH_INITIAL_ADMIN_PASSWORD обязательна для образов новых версий: без неё контейнер останавливается при старте. Для рабочего сервера закрепите номер версии вместо latest, чтобы обновление не наступило само при перезапуске.

  • Поднимите параметр ядра: sudo sysctl -w vm.max_map_count=262144, и сохраните его в /etc/sysctl.d.
  • Задайте пароль администратора в файле.env: OS_ADMIN_PASSWORD=Сложный_Пароль_1!.
  • Создайте compose-файл по примеру ниже и поднимите оба сервиса: docker compose up -d.
  • Проверьте узел: curl -k -u admin:ПАРОЛЬ https://localhost:9200, затем откройте Dashboards через SSH-туннель на порт 5601.

Срок хранения, снимки и HTTPS в OpenSearch

Удаление старых индексов настраивают политикой ISM: например, закрывать индексы через неделю и удалять через тридцать дней. Копии делают снимками (snapshot) в каталог или S3-совместимое хранилище, копирование каталога данных на ходу не годится. Порядок копий для сервера: сервер для бэкапов.

Вопросы и ответы

Чем OpenSearch отличается от Elasticsearch по лицензии и клиентам?

OpenSearch выпускается под Apache 2.0, Elasticsearch сейчас доступен ещё и по SSPL, Elastic License и AGPL. Клиентские библиотеки лучше брать от OpenSearch: официальные клиенты Elasticsearch могут не принять его ответ.

Сколько стоит управляемый OpenSearch в Таймвеб Клауд?

От 2 000 ₽ в месяц на 14 октября 2026. Автоматические резервные копии стоят 6 ₽ в месяц за 1 ГБ, публичный IP 200 ₽.

Почему OpenSearch в Docker не запускается без пароля администратора?

В образах новых версий демо-безопасность требует переменную OPENSEARCH_INITIAL_ADMIN_PASSWORD со сложным значением. Без неё установка прерывается.
