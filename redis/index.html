Установка Redis на свой сервер и замена на Valkey: коротко и с данными

Конспект страницы: 7 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Установка Redis на свой сервер и замена на Valkey.

Коротко

Установка Redis на сервер занимает пару минут: пакет redis-server для Ubuntu или официальный образ Docker, порт 6379 и пароль. Отдельный вопрос появился после 2024 года: лицензия Redis менялась, а свободной заменой стал Valkey, который Таймвеб Клауд предлагает как управляемую базу. Для кода приложения разницы почти нет, оба говорят на одном протоколе.

Конспект по разделам

Где запускать Redis: свой VPS или управляемый Valkey

Redis работает как кэш, хранилище сессий, брокер очередей и счётчик в реальном времени. Держат его двумя способами. Кэш на одном сервере с приложением даёт минимальную задержку.

Что случилось с лицензией Redis и при чём тут Valkey

В марте 2024 года Redis сменил открытую лицензию BSD на двойную: RSALv2 и SSPLv1. Обе ограничивают облачные сервисы, и Open Source Initiative не признаёт SSPL открытой. В ответ проекты под эгидой Linux Foundation, при участии AWS и Google, выпустили форк Valkey с прежней свободной лицензией.

Установка Redis на Ubuntu и Debian из пакета

Версия в репозитории дистрибутива может быть старше актуальной ветки, смотрите её командой redis-server --version. Под Windows официальной сборки Redis нет: для разработки запускают его в WSL2 или в Docker Desktop. Переменная REDISCLI_AUTH избавляет от пароля в строке команды, где его видно в истории.

  • Поставьте пакет redis-server: служба стартует сама и слушает локальный адрес.
  • Задайте пароль параметром requirepass в /etc/redis/redis.conf и перезапустите службу.
  • Ограничьте память параметром maxmemory и выберите политику вытеснения.
  • Проверьте ответ командой redis-cli ping: ожидаемый ответ PONG.

Redis в Docker: compose-файл с паролем и сохранением данных

Образ redis хранит данные в каталоге /data. По умолчанию Redis пишет снимки RDB, то есть периодические слепки памяти. Если нельзя потерять последние секунды записей, включают журнал AOF флагом --appendonly yes.

Сколько памяти нужно Redis и зачем лимит maxmemory

Redis целиком держит данные в оперативной памяти, поэтому объём ключей плюс накладные расходы определяют размер сервера. Оценку лучше брать с запасом: служебные структуры добавляют заметную долю к размеру значений, а при сохранении снимка процесс копирует себя и использует больше памяти. Три ответа про данные в памяти, калькулятор подберёт конфигурацию

  • maxmemory ставьте ниже физической памяти, чтобы система не убила процесс.
  • vm.overcommit_memory = 1 в /etc/sysctl.conf: об этом Redis предупреждает в журнале при старте, без параметра сохранение снимка может не удаться.
  • Диск нужен под RDB и AOF, по размеру не меньше объёма данных.

Как закрыть Redis от интернета и открыть его приложению

Открытый Redis без пароля позволяет прочитать, стереть и подменить все данные, а иногда и записать файл на сервер через команды конфигурации. Минимальная защита: порт слушает только локальный адрес или внутреннюю сеть, включён requirepass, а файрвол пускает конкретные адреса. Для нескольких приложений заведите отдельных пользователей командой ACL SETUSER: каждому свой пароль и список ключей.

Вопросы и ответы

Как развернуть Redis в Docker с паролем и сохранением данных?

Запустите образ redis с флагами --requirepass и --appendonly yes, подключите том к /data и опубликуйте порт только на 127.0.0.1. Пароль держите в файле.env.

Чем Valkey отличается от Redis и можно ли их заменять?

Valkey это форк Redis под свободной лицензией, протокол и основные команды совпадают. Для кэша, сессий и очередей замена проходит без правок кода; новые функции Redis 8 стоит проверить отдельно.

Нужен ли Redis на Windows и как его поставить?

Официальной сборки под Windows нет. Для разработки запускают Redis в WSL2 или в контейнере Docker Desktop, а на рабочем сервере берут Linux.
