Установка Flowise на свой сервер: коротко и с данными

Конспект страницы: 6 разделов коротко, данные на 14 октября 2026 и ответы на 3 вопроса. Полный разбор с примерами: Установка Flowise на свой сервер.

Коротко

Установка Flowise на сервер сводится к docker compose из официального репозитория: конструктор открывается на порту 3000 и хранит базу, ключи и файлы в каталоге ~/.flowise. Остальное нужно для работы в проде: домен с HTTPS, учётная запись администратора и копия этого каталога. Для старта хватит 1 ядра и 2 ГБ памяти, если модель работает по API.

Конспект по разделам

Что собирают в Flowise и кому он нужен

Flowise это визуальный конструктор ИИ-приложений на Node.js: чат-ботов, агентов и цепочек поиска по документам. Блоки соединяют мышкой на холсте, а готовый поток вызывают по API или ставят на сайт как окно чата. Исходный код открыт под Apache 2.0, отдельные корпоративные функции включаются ключом Enterprise.

Какой сервер нужен Flowise

Сам Flowise лёгкий, память съедают загрузка документов, разбиение их на фрагменты и векторный поиск. Если вы планируете локальную модель, считайте её отдельно: Flowise только отправляет запросы, а память нужна той программе, которая модель запускает. Установка Flowise через Docker Compose

Compose-файл берёт образ flowiseai/flowise:latest и проверяет здоровье контейнера запросом к /api/v1/ping. Статус видно в docker compose ps.

  • Поставьте Docker и Compose v2: на Ubuntu хватит официального скрипта get.docker.com.
  • Скачайте репозиторий и перейдите в папку docker, там лежат compose-файл и пример настроек.
  • Скопируйте.env.example в.env.
  • Подготовьте каталог данных.

Домен и HTTPS для Flowise

Чат на сайте и вызовы API должны идти по HTTPS, иначе браузер посетителя заблокирует смешанный контент. Проще всего поставить на сервер Caddy: он сам получит сертификат Let's Encrypt и будет передавать запросы конструктору.

  • В docker-compose.yml опубликуйте порт только на локальном адресе: 127.0.0.1:3000:3000.
  • В.env пропишите внешний адрес в APP_URL, чтобы ссылки в письмах сброса пароля вели на домен, а не на localhost.
  • Для писем нужен SMTP: переменные SMTP_HOST, SMTP_USER, SMTP_PASSWORD.

Когда Flowise нужны PostgreSQL и Redis

Без настроек Flowise создаёт файл database.sqlite в каталоге данных. Для одного администратора и десятка потоков этого хватает. На PostgreSQL переходят, когда в конструкторе работает несколько человек или история диалогов растёт: выставьте DATABASE_TYPE=postgres и параметры подключения в.env.

Вопросы и ответы

Где Flowise хранит потоки и ключи доступа к моделям?

В каталоге ~/.flowise, который монтируется в контейнер как /home/node/.flowise: там база SQLite, ключ шифрования сохранённых доступов, журналы и загруженные файлы.

Как подключить Flowise к локальной модели?

Поставьте Ollama на этот или соседний сервер и выберите в потоке узел ChatOllama с адресом её API. Для облачной модели подойдёт любой OpenAI-совместимый API, включая AI Gateway с оплатой в рублях.

Можно ли запустить Flowise без Docker?

Да: npm install -g flowise и npx flowise start при Node.js 20 и новее. На сервере Docker удобнее: обновление сводится к новой версии образа, а данные остаются в томе.
