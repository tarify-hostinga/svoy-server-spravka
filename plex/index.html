Установка Plex на свой сервер: коротко и с данными

Конспект страницы: 6 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Установка Plex на свой сервер.

Коротко

Установка Plex на свой сервер в Docker занимает одну команду, но сервер сразу привязывается к вашему аккаунту Plex через токен PLEX_CLAIM. Перед тем как ставить Plex на VPS, проверьте условия удалённого просмотра: с 29 апреля 2025 года для видео из другой сети нужна подписка. Plex на VPS удобен, но каждый просмотр видео с такого сервера считается удалённым.

Конспект по разделам

Что такое Plex Media Server и зачем ему аккаунт

Plex Media Server раскладывает вашу коллекцию фильмов, сериалов, музыки и фото по библиотекам и раздаёт её на телевизоры, телефоны и браузер. Код у Plex закрытый, а сервер работает в связке с облаком Plex: вход, поиск сервера клиентами и общий доступ для друзей идут через аккаунт на plex.tv. Поэтому сервер при установке нужно «заявить»: получить на plex.tv/claim токен и передать его контейнеру.

Что в Plex требует платной подписки

Бесплатно Plex умеет организовать библиотеку и показывать её в домашней сети. Две вещи привязаны к подписке: «Удалённый» здесь значит, что клиент и сервер не в одной локальной сети. Для сервера в облаке это любой просмотр.

  • Аппаратное перекодирование на видеокарте или Intel Quick Sync требует активного Plex Pass.
  • Удалённый просмотр видео с 29 апреля 2025 года требует одного из трёх: Plex Pass у администратора сервера, Plex Pass у зрителя или Remote Watch Pass у зрителя.

Сколько процессора нужно Plex для перекодирования

Plex не называет минимальную конфигурацию, а даёт ориентир по баллам теста PassMark на одно полное перекодирование: Памяти по справке Plex обычно хватает 4 ГБ, а установки на Linux живут и с меньшим объёмом. У облачного сервера нет Quick Sync, поэтому без GPU всё перекодирование идёт программно. Для 4K понадобятся сервер с видеокартой и Plex Pass.

Установка Plex через Docker

Для аппаратного перекодирования на Intel добавьте --device=/dev/dri:/dev/dri и включите параметр в настройках, при условии что у вас есть Plex Pass.

  • Получите токен на странице plex.tv/claim, войдя в свой аккаунт.
  • Запустите контейнер официального образа plexinc/pms-docker командой ниже, подставив токен и пути.
  • Откройте http://IP-сервера:32400/web, дайте серверу имя и добавьте библиотеки из /data.
  • Включите удалённый доступ в настройках сервера: без него клиенты из других сетей Plex не увидят.

Удалённый доступ к Plex на VPS

Порт 32400 главный: README образа называет его обязательным для работы сервера. В режиме сети bridge Plex не может сам настроить проброс портов, поэтому адрес сервера задают переменной ADVERTISE_IP, а порт открывают в файрволе. Если хочется отдавать Plex по своему домену с HTTPS, поставьте впереди Nginx или Caddy и пропишите этот адрес в настройках сети сервера.

Вопросы и ответы

Нужен ли Plex Pass, если Plex стоит на VPS?

Для просмотра видео да: с сервера в облаке любой просмотр считается удалённым. Подойдёт Plex Pass у владельца сервера или Remote Watch Pass у каждого зрителя.

Можно ли пользоваться Plex без аккаунта?

Сервер Plex рассчитан на вход в аккаунт: токен PLEX_CLAIM привязывает его к plex.tv. Без аккаунта остаётся только Jellyfin или другой открытый медиасервер.

Какой порт открыть для Plex в Docker?

Обязателен 32400/TCP. Остальные порты из README образа нужны для поиска сервера в локальной сети и DLNA, на VPS их обычно не открывают.

Сколько памяти нужно Plex Media Server?

По справке Plex для обычной установки 4 ГБ с запасом. Основной расход идёт на процессор во время перекодирования, а не на память.
