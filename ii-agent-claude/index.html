Конспект по разделам

Какие модели Claude подходят для ИИ-агента

В текущей линейке Anthropic четыре модели. У всех одинаковое окно контекста в 1 млн токенов и до 128 тысяч токенов в одном ответе, а различаются они скоростью и глубиной рассуждений. Если не знаете, с чего начать, Anthropic советует Opus 5.5.

Как Claude вызывает инструменты агента

Вызов инструментов (tool use, он же function calling) устроен так: вы описываете функцию с параметрами, модель решает, когда её вызвать, и возвращает блок tool_use с аргументами. Ваш код выполняет действие и отправляет результат блоком tool_result, после чего модель продолжает ответ. Для своего кода есть Claude Agent SDK на Python и TypeScript с тем же циклом агента.

  • Клиентские инструменты выполняются у вас: запрос в CRM, поиск по базе, команды bash.
  • Серверные инструменты выполняет сама Anthropic, например веб-поиск: результаты с цитатами приходят в том же ответе.
  • MCP (Model Context Protocol) это открытый стандарт Anthropic для подключения ассистентов к системам, где лежат данные.

Где взять Claude для агента: платформа ИИ-агентов и AI Gateway

Для каких агентов Claude подходит, а где хватит модели попроще

Сильные стороны Claude видны там, где агенту нужно держать в контексте много текста и делать длинные цепочки шагов: разбор договоров и переписки, программирование, исследование по десяткам источников. Готовый агент-программист на этих моделях называется Claude Code. Для коротких типовых ответов большая модель избыточна: Haiku 5.5 ответит быстрее, а на платформе есть и модели других семейств, сравнить можно на странице ИИ-агент на DeepSeek.

Вопросы и ответы

Как создать ИИ-агента на Claude без программирования?

На платформе ИИ-агентов: выберите модель Claude, загрузите файлы базы знаний, напишите инструкцию агенту и вставьте JS-скрипт виджета на сайт. Программирование понадобится, только когда агенту нужны действия во внешних системах.

Чем Claude Code отличается от своего ИИ-агента на Claude?

Claude Code это готовый агент Anthropic для программирования в терминале со своими инструментами для файлов и git. Свой агент на Claude вы собираете под другую задачу (поддержка, документы, продажи) и сами решаете, какие инструменты ему дать.

Сколько текста помещается в контекст Claude?

У текущих моделей окно 1 млн токенов. Для сравнения: прежние модели с окном 200 тысяч токенов, по оценке Anthropic, вмещали около 150 тысяч слов, то есть новое окно в пять раз больше.
