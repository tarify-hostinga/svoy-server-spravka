Установка Codex CLI на сервер: коротко и с данными

Конспект страницы: 6 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Установка Codex CLI на сервер.

Коротко

Установка Codex CLI на сервер делается скриптом OpenAI или командой npm, после чего агент работает в терминале по SSH. Главная особенность сервера: войти в ChatGPT через обычный браузерный поток не получится, для этого есть вход по device code и вход по ключу API. Codex CLI ставится за минуту и не просит мощного сервера: для бэкенда хватит 1 ядра и 2 ГБ памяти, больше нужно только сборке проекта.

Конспект по разделам

Что делает Codex CLI и зачем ему отдельная машина

Codex CLI: агент OpenAI, который работает в терминале. Вы описываете задачу словами, он читает код, предлагает правки, запускает тесты и команды. Насколько свободно он действует, задают режим одобрения и песочница в файле настроек.

Установка Codex CLI на Ubuntu: скрипт или npm

У OpenAI три пути для Linux: отдельный установщик, npm и Homebrew. Для сервера проще первый, он не требует Node.js. Готового официального Docker-образа на странице установки нет.

  • Создайте пользователя без root и поставьте Codex от его имени.
  • Склонируйте репозиторий и перейдите в его каталог.
  • Запустите codex и пройдите вход (раздел ниже).
  • Обновляйтесь той же командой, которой ставили: для обоих способов документация даёт одинаковые команды установки и обновления.

Вход в Codex CLI на сервере без браузера

Codex поддерживает два способа входа для моделей OpenAI: аккаунт ChatGPT и ключ API. Обычный вход через ChatGPT открывает браузер и ждёт ответа на локальном адресе, а на удалённой машине это не работает. Для device code сначала включите вход по коду устройства в настройках безопасности ChatGPT, иначе команда откажет.

Можно ли подключить Codex CLI к другому провайдеру моделей

Да, в файле ~/.codex/config.toml описывают свои провайдеры в разделе model_providers: адрес, имя переменной с ключом и заголовки. Ограничение одно и важное: справочник настроек называет responses единственным поддерживаемым протоколом. Шлюз, который умеет только Chat Completions, Codex не подойдёт.

Как держать сессию Codex CLI на сервере живой

Запускайте Codex внутри tmux: tmux new -s codex, потом codex. Сочетание Ctrl+B и D отцепит вас от сессии, агент продолжит работу, а tmux attach -t codex вернёт к ней с любого компьютера. Правки агента проверяйте как чужой пул-реквест: git diff перед коммитом и отдельная ветка на каждую задачу.

Вопросы и ответы

Как установить Codex CLI на Windows?

OpenAI даёт установщик для PowerShell, а также пакет npm. Для работы с удалённым сервером Windows не нужна: Codex ставится на Linux-сервер и открывается по SSH.

Как войти в Codex CLI на сервере по SSH?

Выполните codex login --device-auth и подтвердите код на любом устройстве с браузером, предварительно включив вход по коду устройства в настройках ChatGPT. Либо передайте ключ API командой codex login --with-api-key.

Можно ли запустить Codex CLI в Docker?

Официального образа на странице установки нет, но пакет @openai/codex ставится через npm в любой образ с Node.js. Каталог проекта и ~/.codex подключают томами.

Работает ли Codex CLI с OpenAI-совместимым шлюзом?

Только если шлюз поддерживает Responses API: другие протоколы для своих провайдеров Codex не принимает.
